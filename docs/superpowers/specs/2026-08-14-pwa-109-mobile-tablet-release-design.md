# PWA 1.0.9 手机和平板发布设计

## 发布基线

用户手机当前版本为 `1.0.6`。本次发布必须包含并适配 `1.0.6` 之后的全部工具改动：图鉴收藏与延迟展示、答题搜索后展示、兵法分区、关卡掉落默认橙装表、神兵装备数据修正、典籍累计计算与最高阶汇总、全装备搜索、典籍进阶详情气泡及属性列对齐。

## 适配策略

- 图鉴收藏：在不改变星号视觉状态的前提下，将手机和平板触控区域提升到至少 44 像素。
- 兵法：手机和平板将表单和结果改为单列；筛选与操作按钮具备触控高度；手机输入框使用 16 像素字号以避免 iOS 聚焦放大；资料表允许横向滚动并冻结首列。
- 关卡掉落：默认橙装表使用固定两列和自动换行，手机收紧内边距，不依赖横向滚动。
- 装备属性：手机使用现有卡片结果，不渲染桌面表格；典籍累计标签使用统一宽度，属性与“进阶详情”保持同一左起点；按钮扩大触控区。
- 典籍气泡：手机使用视口宽度，内容高度受动态视口限制并在气泡内部滚动；平板继续使用冻结前三列的横向表格，气泡固定在可视区域内。

## PWA 发布

- 版本统一提升为 `1.0.9`：`index.html` 初始版本、`js/pwa.js` 显示版本、`service-worker.js` 缓存版本必须一致。
- 预缓存清单继续包含全部运行时 HTML、CSS、数据脚本、业务脚本、图标和楼兰棋阵图片；兵法资源必须在清单中。
- 新 Service Worker 激活后清理旧 `qinshi-site-*` 缓存。
- 推送本地 `master` 到 GitHub `origin/main`，由既有 GitHub Pages 工作流部署。

## 不在范围内

- 不修改业务数据、计算结果或本地保存格式。
- 不提交用户本地 Excel 和图片文件。
- 不运行测试、lint、格式化或浏览器验收；验证由用户按项目约定手动完成。

## 手动验收重点

- 手机从 `1.0.6` 更新后显示 `1.0.9`，所有新增分区和功能均可进入。
- 图鉴收藏、兵法筛选与操作、典籍进阶详情在手机上可直接点击且不触发页面放大。
- 兵法资料表和平板典籍表可横向查看，冻结列不透出底层内容。
- 典籍气泡不超出屏幕，阶段属性可在气泡内部滚动查看。

# 铭文查询工作区与资料图表 1.0.81

用户已确认方案；本次明确授权完整自动测试，通过后合并本地 master、更新 PWA 并推送 GitHub。

## 范围与选择

采用独立查询工作区，共用模拟现场。拒绝两套模拟背包/现场，避免重复库存；拒绝混用一个筛选对象，避免查询互相覆盖。资料图表仅局部重构，不改变个人进度、规则、概率或数值。

## 查询与模拟

- 路径查询有 direct/reverse 两个子分区，分别保留目标、筛选、结果、路线及异步生成状态。
- 模拟有 direct/reverse 两个定位子分区，筛选草稿独立；下方材料、结果、历史、背包共用一个现场。
- 筛选及切换子分区不改变现场；点击应用到模拟才改变现场。不兼容材料先确认，取消不写现场。
- 每个账号分别保存定位状态。旧路径目标迁移到 direct，旧反查草稿迁移到 reverse；现有模拟和背包文件不改格式、不清空。
- 目标属性最多三种，允许重复，数量依品质；沿用现有合法性校验和未知 X 规则。

## 反查结果

- 默认隐藏普通弟子，神将在前。可勾选显示普通；分类 all/formation/common/other、天位、遁位、姓名搜索只过滤结果。
- 对具体弟子先过滤再合并。常用/合阵身份不跨对应弟子传播。
- 对应关系复用 FORBIDDEN_DATA.discipleAtlasTargets 明确映射，叠加忽略开头神/神·后的完整姓名相同关系。空图鉴映射不禁止铭文配对；不使用称号截断或模糊匹配。
- 同一对应组、天位、遁位、目标品质、词条/档位/数值完全相同才合并；词条顺序无关。卡片内选择具体弟子，优先神将，应用所选组合。
- 不展示弟子品质，仍显示目标铭文品质。分页针对合并后卡片；筛选变更回第一页。

## 资料图表

四个独立导航：副属性与来源、紫二仅洗练词条、升级同档成长、品质与材料。默认只显示当前内容，使用黑金 UI 与品质色数值。

- 副属性采用属性行/档位列矩阵，支持品质、遁位、属性关键词、来源过滤；不分档独立列，缺失为 —，来源逐条计算。
- 紫二仅洗练保留九遁卡片，属性和值对齐，低档说明不反复堆叠。
- 成长展示属性/档位/升级前/升级后，差值可开关；百分数使用百分点，速度/追加伤害为原值；蓝二速度不可辨保留所有可能，不虚构概率。
- 品质材料保留七品质基础表，五天位主属性默认单品质，可双品质比较，保留全品质总览；绿一显示无法置换。
- 单项/双品质/双遁位互斥，最多两组；每分区仅显示适用控件。资料不写真实库存。
- 移动端局部表格滚动，页面不可横向溢出；平板/桌面利用宽度并排对照。

# 其他资料目录与模块入口整理

**Goal:** 将机师、战匣丹囊、答题、逐鹿、楼兰棋阵、合阵、设置归入其他资料，增加名称搜索和本设备自定义排序，发布1.1.36。

**Architecture:** 保留原模块DOM、路由、生命周期和业务计算。目录新增入口，通过现有主路由打开原页面；模块顶部提供返回目录，主导航高亮其他资料。六堂已有嵌入方式保持不变。目录排序以独立本地UI偏好存储，不改账号存储格式。

**Tech Stack:** 现有原生JS/CSS、目录数据、懒加载、localStorage。

## 方案选择

复用原页面并归类入口，而不搬移七个有业务交互的DOM或复制页面，避免破坏控件、焦点、局部刷新和设置权限。用户已约定明确方案直接推进，不重复确认。移动控件采用上移/下移，兼容手机和键盘；排序模式关闭名称搜索并清空筛选，避免隐藏项造成次序歧义。

## 边界

- 仅移动入口与新增目录展示功能，不改游戏资料、计算、账户权限或个人进度。
- 去重用户重复列出的逐鹿；共七个模块，目录总计17项。
- 搜索仅匹配分区名称；排序自动保存至本设备，失败显示必要错误，不影响打开模块。
- 保留旧链接、模块间跳转和六堂原有表单DOM。
- 按AGENTS不运行测试、lint或浏览器；补充未执行回归源码与手动验收点。

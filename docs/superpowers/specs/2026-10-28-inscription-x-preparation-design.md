# 铭文杂词与常规材料准备修正

## 目标与范围

具体 X 可选：留空按 A，使用同一种合法不分档词条作为符号模板，图中保持“杂词条 X（同一个）”，概率只对这一条件成立；选定具体属性和档位按 B，逐阶段校验来源与词条合法性，按既有规则重新计算。未指定 X 不应强迫用户选择，指定后不可偷偷换成另一词条。

保留当前最终可见组合等概率模型、蓝二速度档位不可辨模型及完整模拟引擎。不修改 Rules.signature 的物理材料含义，不扩大合成规则。洗练为当前品质独立材料准备，不补画蓝二链，不编造洗练概率。

## 已选方法

曾考虑仅使用符号模板 A，以及必须指定具体 X 的 B；用户最终选择两者并存，以空选项切换 A/B。实现继续复用现有原生下拉、规划器、SVG 与账号收藏存储，不引入新依赖。

## 路线与概率

- 常规三档目标：合成紫二高中档材料，另行洗练紫二低档＋X，再合橙一；不把难洗的紫二高＋低作为主动准备的常规方案。已有高低材料仍可在模拟器使用。
- 保留两类紫二高中档来源：紫一高中档×3；紫一中档＋X 与高档＋同一个 X 按2＋1投料。后者不得被局部100%剪枝删除。
- 以鬼遁速度或龙遁PVP速度为例，前者双蓝速度得到紫一高中速概率为1/17；后者蓝速度＋具体合法X得到中速＋X或高速＋X，各50%，再三选二得到紫二高中速为1/3。各步100%只代表材料备齐后的条件概率。
- 将上述准备角色泛化至其他合法属性组合，保留有意义的准备族，不穷举所有材料子树。
- X 的同一性是属性＋档位，数值随品质变化。具体X不能用于某阶段时剔除对应路线，保留可行路线并说明限制；若无可行路线明确报错。

## 符号来源与复用

仅显式 X 起始或洗练材料建立符号来源，合成与失败产物只传播继承的 X。没有 X 输入的随机补词条仍显示实际属性、数值和档位。元数据放在节点而非规则词条内，避免规则归一化丢失；失败品关联保留生产步骤，避免同物理产物误连来源。

失败品复用以三枚合法同品质材料的去重候选池覆盖目标为准，同种可重复，不强制A+B+C。四条候选包含三条所需词条时显示“四个候选词条中必须有三个是所需词条，四选三”，再显示实际计算概率。三类失败品A/B/C中2＋1也可覆盖，AAA等缺目标的不成立。

## 数据与界面

查询新增“具体杂词 X（可选）”，留空为A，选择固定属性档位为B。切换遁位/目标属性会处理不再合法的选择并提示。查询X不应清空模拟投料现场。收藏记录保留X选择、符号来源、失败品生产关联；旧收藏原数据保留，重新校验，不静默换成新路线。

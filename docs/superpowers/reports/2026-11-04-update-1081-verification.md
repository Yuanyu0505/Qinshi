# 1.0.81 铭文查询工作区与资料图表

## 本次改动

- 路径查询、模拟定位各拆成“按弟子／遁位查询”和“按属性反查”，各自保存查询草稿；模拟材料、结果、历史与虚拟背包仍共用一个现场。
- 反查默认只显示神将；可显示普通弟子。按具体弟子筛选后，使用既有明确映射及去除神前缀后的完整同名关系合并相同位置、品质和搭配，卡片内仍可选择具体身份。
- 反查结果增加分类、天位、遁位和姓名过滤，不显示弟子品质；定位组合必须显式应用后才改变模拟现场。
- 仅重构资料图表布局，分为副属性与来源、紫二仅洗练词条、升级同档成长、品质与材料。支持两组对比与同档差值，绿一标明无法置换。
- 保留现有铭文规则、属性值、概率、个人进度、背包及旧模拟格式；异常旧目标只提示并保留原文，不静默覆盖。

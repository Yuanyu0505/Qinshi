# 铭文工作流、收藏及合阵搜索

## 已确认行为

- 查询只保留常规、互补、有实际配料差异的路线，剔除绕远或依赖随机补目标的方案；不可避免的蓝二速度解释保留概率。模拟器规则和17种等概率模型不变。
- 图中不同用途材料分开绘制，不再共用×N标签；洗练支线从当前品质开始，文案“另行置换合成素材铭文”。失败明细完全具体，素材/成功节点非目标词条可用一致的X。词条数值降序，失败展开按钮置于缩放旁，默认90%。通用文案按用户指定。
- 每条完整路线星标收藏，账号独立；查询收藏置于全部未收藏之前，新“收藏合成路径”按弟子、品质、天位、遁位、无序但保留重复次数的属性1/2/3筛选。通用路线不绑定弟子/天位。存紧凑结构和版本，重算概率，不合法则保留并标失效，不静默替换。
- 查询分类：全部/合阵/常用/其他；合阵取资料全部候选，与常用可重叠，其他排除两类并集。
- 个人进度搜索框与下拉对齐；品质星级合一为蓝一/蓝二/紫一/紫二/橙一/橙二；副属性固定合法词条选择，显示4速（中档），不手填。蓝1槽紫2槽橙3槽，互斥词条、两高上限、来源合法性均校验。切品质有词条时确认清空，取消保持。历史异常保留直到用户修正；不猜同值档位。蓝一只用于记录，不添加合成配方，未知主属性不套橙色。
- 新增红色神将“神镜仙端木蓉”，与其他端木蓉独立；天府地遁、天相神遁、天同云遁、天梁人遁、天机风遁，不默认常用。
- 合阵搜索支持阵名及弟子名，列出所有匹配阵供点选，切换未保存内容前确认，不修改存档。

## 架构

复用 Rules 作为合成规则源。个人蓝一记录使用独立参考规则适配器，不改变合成qualities。收藏独立账号键，避免模拟CAS冲突。全量备份/同步继续使用现有托管键规则。现有弟子/存档键保持稳定，不批量改写旧存档。

## 审阅重点

旧自由文本不可无声丢弃；蓝一同值档位不可猜；收藏取消/切账号/写失败/无效收藏；材料份数与失败复用连线；搜索跳转保留脏编辑确认；弟子姓名精确对应。

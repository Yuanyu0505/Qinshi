# 流程图紧凑布局

将目标产物的当前概率并入对应操作框（包括蓝二速度特殊合成和失败品复用）；独立洗练写当前概率未知。失败合计移至失败框标题，单项概率仍在各行，非目标合计在其结果框内，不再用独立概率气泡占据层间空间。

晋升材料不再分配远端独立全局列，按其参与配方的材料位置安排。同层节点紧凑排列，优先按真实前级连接顺序排列并让晋升材料贴近同配方材料；画布宽度由最宽层的实际节点总宽确定，不保留虚空列。横向间距 40px 改为 18px，层间距 112px 改为 60px，并按层底对齐；保留投料数量、单行词条、品质色、连续图及滚动缩放。

只读审阅后将投料数量标签放在节点下方 20px、连线横段放在下方 44px，为标签和横向连线保留不同通道。晋升材料邻近采用排序启发式，不保证复杂多配方布局的全局最短连线。

布局只改变显示，不改概率、规则、配方或存档。按前述范围只合并本地，不更新 PWA 或推送。不执行测试/构建/lint/实机验收；请人工重点检查概率与操作对应、晋升材料位置、投料标签及复杂复用图的连线和滚动。

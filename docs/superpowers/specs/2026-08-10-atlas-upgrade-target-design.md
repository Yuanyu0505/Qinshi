# 图鉴目标等级升级统计与阶段箭头设计

## 1. 目标

基于《图鉴汇总》工作表 `T50:X70` 的统一升级成本表，为图鉴增加可调整的全局目标等级。页面需要显示每名弟子及当前筛选结果整体升至目标等级所需的明鬼绳结、魂魄、实际装备和可获得成长值。

同时高亮“所属图鉴”名称，并把橙装锻造和图鉴中表示升级的阶段文案统一改为箭头形式，例如 `9→10`。

## 2. 源数据规则

`图鉴汇总!T50:X70` 定义如下：

| 列 | 含义 |
| --- | --- |
| T | 图鉴升级阶段，`1-2` 表示 `1→2` |
| U | 需要明鬼绳结 |
| V | 需要魂魄 |
| W | 需要装备标记 |
| X | 获得成长值 |

- 成本表覆盖 `1→2` 至 `19→20`。
- `5→6`、`7→8`、`9→10` 的 W 列标记需要装备；具体装备名称和品质以图鉴弟子记录现有的阶段装备为准。
- `14→15` 及之后的成长值为 0，因此任何目标等级下的成长值只累计至 14 级；页面固定提示“14级后不再获得成长值”。

## 3. 目标等级与存储

- 在图鉴筛选面板增加“目标等级”数字输入，允许 `1` 至升级表定义的最高等级（当前为 20）。
- 默认目标等级为 19，因为当前源数据中的最高已有图鉴等级为 19。
- 目标等级保存到新的浏览器本地存储键 `qinshi_atlas_target_level_v1`，不改变现有 `qinshi_atlas_levels_v1` 中的个人等级记录。
- 当前等级大于或等于目标等级时，该弟子显示“已达到目标等级”，升级成本均为 0。

## 4. 统计范围

### 单条图鉴弟子结果

每张图鉴弟子卡片新增“升至目标等级”摘要，包含：

- 当前等级与目标等级；
- 待消耗明鬼绳结与魂魄；
- 可获得成长值，并显示“14级后不再获得成长值”；
- 该当前等级到目标等级之间实际需要的装备，按 `5→6`、`7→8`、`9→10` 等阶段展示，保留品质；
- 达标状态。

装备阶段只在 `当前等级 < 阶段结束等级 <= 目标等级` 时纳入，避免目标等级低于某阶段时显示超出目标的装备。

### 当前筛选结果总汇

在图鉴结果上方新增“当前结果升至目标等级汇总”：

- 仅统计当前图鉴分区、等级筛选和关键词筛选后的结果；
- 仅计入尚未达到目标等级的弟子；
- 汇总明鬼绳结、魂魄、成长值和实际装备数量；
- 装备按“名称 + 品质”聚合，且标出对应数量。

## 5. 架构与数据流

### 数据构建

`tools/build_atlas.py` 从 `T51:X69` 解析统一升级阶段，写入 `ATLAS_DATA.meta.upgradeStages`：

```js
{
  key: "1→2",
  from: 1,
  to: 2,
  knots: 35,
  souls: 20,
  needsEquipment: false,
  growth: 1
}
```

元信息同时包含 `maxLevel` 与默认目标等级。图鉴装备阶段键改为 `5→6`、`7→8`、`9→10`。

### 图鉴逻辑

`js/atlas.js` 增加纯逻辑函数，根据当前等级、目标等级和升级阶段数据计算单条弟子的升级计划与多条结果的汇总。装备统计复用图鉴记录中的真实阶段装备，而不是把 W 列标记误当作装备名称。

### 页面渲染

`js/app.js` 维护目标等级状态、保存目标等级、渲染全局汇总和单卡摘要。所属图鉴的值使用独立 CSS 类高亮。

## 6. 阶段箭头统一

以下仅限“升级”语义的阶段标签：

- 图鉴：`5--6`、`7--8`、`9--10` 及升级成本表的 `1-2` 至 `19-20`，统一为 `5→6`、`7→8`、`9→10` 等；
- 橙装锻造：`0-1锻` 至 `9-10锻` 统一为 `0→1锻` 至 `9→10锻`，`10锻-红金` 统一为 `10锻→红金`；
- 对应构建脚本、生成数据和测试样例同步更新。

关卡编号、关卡掉落、获取途径等非升级文本保留原有连字符形式。

## 7. 兼容与异常处理

- 不修改 Excel 源文件。
- 不改变现有图鉴名称、获取途径、所属图鉴、装备关键词和等级搜索语义。
- 旧版本图鉴等级本地存储继续有效；目标等级存储缺失、损坏或超出范围时回退到默认目标等级。
- 升级表数据缺失时，不显示错误成本，改为显示升级数据缺失提示。

## 8. 用户手动验证建议

- 目标等级 19 下，当前为 19 的图鉴显示已完成且成本为 0。
- 当前为 5 的图鉴升至 19 时，汇总 `5→6`、`7→8`、`9→10` 的装备及 `5→19` 的绳结、魂魄。
- 将目标等级设为 7 时，不应显示 `7→8` 或之后阶段的装备和成本。
- 成长值在目标等级超过 14 时不再增加，并显示提示。
- 当前筛选结果汇总会随图鉴分区、关键词和等级筛选更新。
- 所属图鉴名称高亮可见。
- 橙装锻造与图鉴的升级阶段全部显示箭头，关卡编号保持不变。

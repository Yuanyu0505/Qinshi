# 装备属性多装备对比设计

## 目标

在装备属性分区中增加临时多装备对比工作台。玩家可以从搜索或筛选结果加入同一大类的任意数量装备，选择统一品质档位和一个或多个副属性维度，查看最高值及其他装备与最高值的差距。同时删除机关兽结果中的“最优方案”和“目标流派阶数计算”两处冗余文字。

## 范围与约束

- 对比状态只存在于当前页面会话；切换分区保留，刷新页面清空。
- 不修改 `data/special-equipment.js`，不改变现有搜索、筛选或排序口径。
- 本次实现同时覆盖桌面、手机和平板布局。
- 本次不更新 PWA，不推送 GitHub；完成后提交并合并本地 `master`。
- 项目验证由用户手动执行，代码侧补充纯逻辑与静态页面契约。

## 大分类规则

首件装备锁定当前对比大类，清空全部装备后解除锁定：

- `武器`、`神兵武器`归入武器大类；
- `防具`、`神兵防具`归入防具大类；
- `饰品`、`神兵饰品`归入饰品大类；
- 初始紫色典籍、初始橙色典籍和神兵典籍归入典籍大类。

不属于已锁定大类的搜索结果仍可查看，但“加入对比”按钮禁用并显示类别不一致。同一装备不能重复加入。装备从搜索结果消失后仍保留在对比区，直到单独移除或清空全部。

## 档位与典籍取值

对比档位统一选择，默认`红金`，可切换`紫色`、`橙色`、`橙金`、`红色`、`红金`。

- 普通装备读取 `item.tiers[档位]`。
- 典籍读取同品质的最高阶累计值：紫色、橙色取10阶累计；橙金、红色、红金取15阶累计。实现复用 `QSQuery.finalBookStage()`。
- 装备完全没有所选档位时显示“该档位无数据”，且不参与该档位各维度最高值计算。
- 装备有所选档位但不含某个已选维度时按0参与比较。

## 维度生成与计算

维度只来自当前已选装备在当前档位中的数值副属性。固定顺序为：

`攻 → 血 → 防 → 攻防血 → 穿透 → 暴击 → 暴伤 → 技免 → 抗暴 → 速 → 闪避 → 招架 → 敌方减攻 → 敌方减防 → 敌方减血`

默认不选维度，支持单选、多选、全选与清空维度。切换档位或移除装备时重新生成可用维度：仍存在的选择保留，消失的选择取消，新出现的维度不自动选择。

复合属性规则：

- 比较`攻`、`血`或`防`单项时，`10%攻防血`分别向三项贡献10%；同档位独立同类词条继续累加。
- 比较`攻防血`维度时，只读取原始`攻防血`词条。`10%攻防血`的对比值为10%，不与独立攻、血、防相加，也不把三维求和。
- 其他维度按相同词条的数值合计。

同一维度的最高值全部使用鲜红色粗体。非最高值的原值使用普通白色，差值按`当前值 - 最高值`显示为绿色普通字重，例如`8%（-2%）`。速度差值使用`速`单位；敌方减攻、减防、减血沿用现有“敌方-数值%属性”格式。

## 核心模块

新增 `js/equipment-compare.js`，采用与现有查询核心一致的 UMD 结构，浏览器暴露 `window.QSEquipmentCompare`，Node 测试通过 `require` 使用。模块依赖 `QSQuery`，提供：

- `groupForCategory(category)`：返回武器／防具／饰品／典籍大类；
- `tokensForTier(item, tier)`：返回所选档位可比较的最终 token，缺档返回 `null`；
- `availableDimensions(items, tier)`：返回固定顺序的动态维度；
- `dimensionValue(item, tier, dimension)`：返回 `{ available, value }`；
- `compareItems(items, tier, dimensions)`：返回装备行、每维最高值、显示值和差值模型。

核心模块不接触 DOM、不写存储，所有计算均可独立验证。

## 页面状态与交互

`js/app.js` 增加会话状态：

```js
comparison: {
  itemIds: [],
  group: null,
  tier: "红金",
  dimensions: [],
  expanded: false,
  started: false
}
```

筛选面板下方、普通结果上方新增“装备对比（数量）”面板：

- 空状态默认折叠；
- 添加首件装备后自动展开；
- 显示已选装备标签、单件移除和清空全部；
- 显示档位选择、动态维度、全选／清空维度和“开始对比”；
- 少于2件装备或未选维度时显示明确提示；
- 开始对比后，调整档位、维度或移除装备会即时刷新结果。

搜索和筛选结果的桌面表格、移动端卡片均增加“加入对比”操作。已加入装备显示“已加入”，大类不兼容显示“类别不一致”。

## 结果布局

桌面端使用横向对比表：每个装备为一列，每个已选维度为一行；装备列头展示装备名、具体分类和主属性。数量较多时表格容器允许横向滚动，维度列保持清晰。

手机和平板端不依赖横向滚动，改为每件装备一张纵向卡片，按统一维度顺序列出值、最高状态或绿色差值。

## 异常与空状态

- 少于2件装备：`至少选择2件同类装备`；
- 未选择维度：`请选择一个或多个对比维度`；
- 当前档位全部无数据：`所选装备在该档位均无属性数据`；
- 单件缺档：卡片或表格对应列显示`该档位无数据`。

## 机关兽文字调整

- 单只机关兽计算结果删除“最优方案”；保留机关兽名称、目标等级和“计算结果”。
- 流派计算结果删除“目标流派阶数计算”；保留“自由等级方案／效果档位方案”等方案标题和右侧目标阶数摘要。

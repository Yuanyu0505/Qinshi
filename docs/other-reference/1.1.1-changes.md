依据用户2026-11-13本轮14张截图要求；该要求覆盖上一版保留资料审核UI和原图附加入口的决定。

| 用户项 | 实施内容 |
|---|---|
| 1 | 首页只显示“其他资料”，移除“·九分区”、只读说明及整块资料来源与修订记录生成代码 |
| 2 | 共用原图查看器删除新标签原始分辨率链接、href绑定、data-ref-original及对应样式 |
| 3 | 删除共用查看器的“来源原图”标题、原文件名元素/绑定/样式；原图按钮不再含完整路径tooltip或文件名说明 |
| 4 | 诸子卡表格/卡片统一投影去除“特别说明”；7列表首列24%、数值列统一居中及紧凑间距，手机局部横滚 |
| 5 | 诸子卡搜索仅属性名称及数值，排除备注列，提示改为“输入属性名称或属性数值”；攻略独立于属性搜索，其他分区搜索语义不改 |
| 6 | 只有布局确实独立时才提供“推荐视图”：来源聚合、窄容器速度/时间线/技能保留；与原表相同的场景不生成auto选项，容器切换时同步更新 |
| 7 | 共用“资料依据与审核详情”及其生成、路径列表和样式移除，保留必要的部分转录标记 |

| 9、10 | 诸子卡表格、攻略及目录不生成原图按钮/入口ID；攻略公共免责声明及合成保护尾注不再显示 |
| 11 | 概率章节删除反引号/引号及作者免责声明，保留原有概率和算式显示，不引入计算功能 |
| 12 | 卡册章节删除原图写/原图补充前缀、引号/括号及确认修订长说明；显示结构化已确认的单册和三册值，防御不倒退为6万 |
| 13 | 经验返还删除“原图写”及补图06操作提示，保留120/258个三级迷珏的资料值 |
| 14 | 各分区“本分区全部原图”索引生成代码及相关样式移除 |

## 范围与兼容

- 主要变更为`js/other-reference-ui.js`与`css/other-reference.css`。共同生成层调整覆盖所有其他资料子区；未扩散修改图鉴、机关兽等其他模块。
- 原始data、原图归档、来源关系和白名单保留；不删除文件。原始卡册资料仍在数据归档，页面只在攻略出现，不提供卡册查询选项。
- 诸子卡查找范围按上下文单独调整。其他区域仍可搜索弟子名称、来源等，不因本轮简化而丧失功能。
- 本次为展示与事件选择去重，不修改游戏计算、库存、个人进度、备份或持久化接口。
- 五个版本身份位置统一1.1.1：index.html、version.json、js/pwa.js、service-worker.js、js/partition-loader.js。

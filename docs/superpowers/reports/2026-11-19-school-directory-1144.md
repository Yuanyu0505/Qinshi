## 流派压力工具（尚未执行）

新增 `tools/benchmark-machine-school.cjs`，只使用构造库存，不读取账号或备份；仅在手动调用时运行：

```powershell
node tools/benchmark-machine-school.cjs
node tools/benchmark-machine-school.cjs --matrix
node tools/benchmark-machine-school.cjs --modified-domain
node tools/benchmark-machine-school.cjs --matrix --only hegemonic-3-plain-boundary-69.125 --timeout-ms 60000
```

默认三组代表样本：霸道默认、霸道混合高阶225级、非攻小数价格及充足共享神图。它们是本仓库新增可复现输入，并非声称与外部报告未提供的具体输入完全一致。

扩展矩阵48组：两流派13/14兽 × 3/5阶135/225级 × 允许/禁止新增改造 × 神图0/充足/临界 × 单价70/69.125。混合库存包含未改与初改/满神改的0、7、8、9、10阶。临界库存取同场景零库存基线费用方案神图需求减1，并输出基线需求及实际库存；不伪称它是所有可行解的全局最小神图阈值。

蓝紫只给合法0阶及该品质最高阶库存，0阶数量足以提供最大等级所需本体，避免225级样本被非法高阶库存归一化后必然无解。矩阵中的“允许改造”仅表示开关：生产规划器若无改可达，会按原策略跳过改造前沿。工具输出 `observedModifiedTypes`，不把开关次数冒充真实改造覆盖。另有 `--modified-domain` 两组显式调用各兽真实 `machineBeastCandidates(plainOnly:false)` 的候选域压力，记录实际改造类型/候选，并标记 `schoolPlanComputed:false`；它不是端到端两套流派结果，未观察到改造类型时以非零退出。

工具在隔离子进程的VM中向源码注入探针，不改生产求解器。记录候选、GCD、研究桶、核心前沿、每层组合/压缩前后状态、采样堆大小、整个Node进程峰值RSS、耗时、有效结果、实际总级和方案明细。数值含VM探针开销；采样堆峰值不是精确最大堆，Node RSS也不是浏览器Worker内存。

默认30秒仅为外部诊断观察限时，可用参数调整；超时输出 `timedOut:true`、保留最近完整采样、非零退出，不返回近似最优或把中止当无解。临界样本RSS含基线求解开销，最终 `solveMs` 不含该基线，`elapsedMs` 包含。

新增 `tests/machine-school-benchmark.test.js` 供用户检查48组输入覆盖，不自动启动昂贵基准。低内存真实设备及跨浏览器性能仍未测量，不能由构造场景或历史报告推断通过。

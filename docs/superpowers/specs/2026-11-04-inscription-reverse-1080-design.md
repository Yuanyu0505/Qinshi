# 铭文来源、属性反查与资料 1.0.80

用户已确认本方案，授权实施后完整测试、合并本地 master、PWA 更新及推送 GitHub，不再二次确认文档。

## 来源
- 今后增加虚拟库存，单一来源自动继承；多来源由当前来源选项决定，原有批次不改。未提供且无法唯一确定时拒绝写入，不猜测。
- 不迁移旧 manual 数量。不伪造新抽取记录，复制数量沿用来源配方，完整路线按实际使用次数汇总。无来源的手动库存仍手动。
- 校验同天位/遁位/品质/词条签名、占用、撤销和来源链，不能通过新参数引用不同铭文。

## 反查
- 两页分别保存待应用反查草稿，账号隔离，不能改动当前目标、背包或模拟现场。
- 在遁位后显示最多3个反查属性；蓝二1、紫色2、橙色3，允许重复，变更品质截去超限项。
- 属性候选与可选遁位双向过滤，重复次数是最低数量。根据整枚合法洗练或合成来源检查，含同属性同档唯一、最多两高档；不是逐条可用就合法。
- 尽量填满查询属性；按不同数量分配展示各自的最高合法组合，去除重复和被支配的组合。剩余词条用 null 表示“非查询词条X”。普通速/PVP速严格区分。
- 遁位选项标注各查询属性当前品质可用档位；蓝二速不可辨。
- 按钮位于清除所有选项前。全库反查，不受当前弟子限制；显示名字、弟子天遁位、最高值。
- 点击结果原子应用弟子/位置/品质/已确定目标属性，X留空。若模拟不兼容先确认；取消不改现场。必须绕过普通换上下文自动清空目标词条的逻辑，但不绕过存储/账号保护。
- 清除所有选项同时清除本页反查，不影响另一页。提示为“未指定弟子则无法选择此项或无需选择”。

## 资料与个人进度
- 复用既有规则而不是独立维护副属性。默认橙二，可选全部品质；各遁位列值/档位/来源，并附紫二仅洗练单条词条。
- 升级对照按真实同档成长；蓝二不可辨速度列可能情况，不猜具体档或概率。对照不等于完整投料配方。
- 新增集中基础数值：绿一/蓝一/蓝二/紫一/紫二/橙一/橙二单值1600/2700/4550/7700/13050/22150/37650；分解1/3/9/20/60/132/396；重铸null/1/1/2/5/12/40。
- 天机内力1护盾16，天相攻1内力2，天同内力1血16，天梁防2血8，天府防1攻2，乘单值。同步已有个人进度品质，不添加绿一进度或合成。
- 绿一未知副属性不推算。分解/重铸只做静态表，不做次数计算器、不扣真实库存。
- 沿用金黑UI、词条品质色及同属性分组排序；移动端不产生全页面横向溢出，宽表局部滚动。

## 方案取舍与边界
选择统一现有规则引擎+集中资料数值；不另写不一致的概率模型，不静默修复旧来源，不将X作为通配合成目标。反查草稿与当前目标分开，避免仅浏览就破坏模拟现场。真实合成概率保持原状。

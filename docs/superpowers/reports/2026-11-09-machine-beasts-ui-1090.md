# 1.0.90 机关兽布局与交互优化交付

## 范围

参考用户提供的《秦时机关兽_UI布局审查与改造方案_1.0.89.md》，实施P0和主要P1建议。仅修改HTML顺序、UI模板、表现层交互及CSS。计算器、求解器、游戏数据、资料值、Worker协议、账号API及已有库存/价格存储格式保持不变。

## 完成内容

### 个人进度
- 保留累计等级、当前/下阶效果及现有保存/取消流程。
- 新增仅影响展示的品质、库存/碎片筛选，不影响累计等级，不写账号存储。
- 卡片突出品质、名称、等级、当前效果及库存数量；来源和完整库存仍在可展开明细中。
- 编辑时高阶/改造显示选项重绘保留展开和同身份焦点；研发度输入旁的等级只读展示即时刷新。

### 方案计算
- 静态DOM为控件先、结果后，键盘与阅读顺序一致。
- 单兽输入分核心目标、材料库存、参考费用；单兽费用仍仅作展示，不参与排序。
- 流派按目标差额、策略价格、计算操作、参与兽分层。神图价格与库存摘要靠近目标，完整价格设置仍在原控件容器内。
- 流派操作条局部吸顶，不增加另一个固定底部工具栏；计算等待状态也显示在按钮附近。
- 库存与参与选择尽量只重画当前兽卡；数量输入只更新草稿和使用清单，避免重建正在编辑的库存输入。
- 使用稳定key保存details，焦点身份包括数据属性及radio的name/value。表现状态仅放内存/原有返回视图快照，不混入真实库存。
- 同对象搜索只定位/高亮，不取消Worker；实际换兽/换流派仍按原契约取消并失效旧结果。
- 价格改变继续使流派结果失效；单兽估价和新增概要同步刷新，不重新求解单兽。失效结果对应的查看链接同时隐藏。

### 结果阅读
- 顶部保留精确达标对照，窄容器改为两套摘要卡，较宽容器保留比较表。
- 突出目标/最终等级、已计价元宝、新增节点；同时展示两套方案的已计价金额与节点差异。
- 方案有稳定锚点，支持返回对照、返回设置；错误和已达标状态也有返回入口。
- 次级研发/折算/资源指标、费用、培养材料、全兽最高效果分组展开，原始明细不删除。
- 新增节点与最终生效档位仍分开，高档替换低档的既有展示语义保留。
- 定位使用原生锚点和焦点，并尊重减少动态效果设置。

### 资料图表
- 七个连续内容区均保留，新增目录和返回目录入口；第五区另有1–5阶定位。
- 搜索标签明确只筛选机关兽归属/研发效果，未新增或冒充全资料搜索。
- 搜索和流派切换仅重绘相关资料块，两套流派选择继续独立，不重置其他资料位置/展开。
- 窄容器按兽展开全部档位，宽容器保留完整效果卡；研发门槛按每5级分组，25级数据仍完整。
- 阶数与改造研发度用宽屏矩阵/窄屏逐阶详情展现；值仍直接来自原DATA。
- 原图研发材料、突破逐阶段和累计表保留原语义、名称、缺失标记及局部横向滚动。

### 样式与PWA
- `css/machine-beasts.css`集中模块规则和容器响应；旧`style.css`仅移出机关兽专属选择器，混合规则的其他模块选择器保留。
- 网格按实际内容区宽度自适应，而不是仅依赖平板viewport。控件/标签触达区域、说明字号和分组间距集中处理。
- 新CSS在共享响应式样式之后加载，加入Service Worker预缓存；Pages原有递归复制css已覆盖该文件。
- 版本资源号统一为1.0.90。没有新增第三方依赖。

## 静态审查与修正

独立审查仅阅读源码与diff，没有运行应用或测试。发现并已对应修改：

1. 恢复视图时，隐藏的旧DOM可能覆盖已保存的展开状态：恢复时清理待延迟重绘的旧内容，并在当前模式恢复期间禁止采集旧状态。
2. 精确跨模块导航可能被品质/库存筛选挡住：新导航临时重置这两个展示筛选，旧筛选仍在返回快照中。
3. radio缺少name/value身份会恢复到错误单选项：加入radio专用身份字段。
4. 价格改变后的“查看结果”链接可能指向隐藏结果：同步更新链接可见性。

本次审查不等同于运行时验证，也未扩展审查数学算法、原资料真实性或任意损坏数据兼容。

## 建议用户验收重点

1. 320/375/390/430/600/768/820/1024/1280/1366/1440/1920宽度，以及720高小屏PC、横屏与200%缩放；查看整页是否溢出、固定导航是否遮挡局部操作。
2. 单兽与流派库存展开后切换高阶/改造、输入数量、Tab前进、勾选参与；当前和邻卡状态应保留，未保存数据不能写入个人进度。
3. 同对象搜索期间Worker仍运行；真正切换对象后旧结果不回填；中文输入法不截断输入。
4. 改神图价格/库存、橙五价格时流派结果失效；单兽仅估价变化；单价预设选择不能取消单兽结果。
5. 两套方案相同/不同、已达标、无精确解等结果，展开全部指标/材料/费用/最终效果，确认信息可达且原数值未变。
6. 七个资料入口、各区返回、独立流派切换、手机详情/桌面矩阵、局部表横滚、—缺失语义与全部25级门槛。
7. 导航出去再返回，包含当时隐藏分区的展开状态；带筛选时跨模块导航到蓝兽/零库存兽不得空白。
8. 保存/取消、只读账号、账号切换、本地备份恢复与旧版一致；真实库存不被临时计算扣减。
9. PWA更新到1.0.90后离线进入机关兽，确认新增CSS可用；其他模块主题及布局未受CSS迁移影响。

# 典籍详情气泡属性列对齐设计

## 目标

让气泡中的 `0阶、5阶、10阶、15阶` 属性内容从同一垂直位置开始，消除阶段文字宽度不同造成的左右错位。

## 根因

当前每个 `.book-popover-stage-row` 都独立使用 `max-content` 计算阶段标签列宽。`0阶：` 与 `10阶：` 的字符宽度不同，因此每行第二列起点也不同。

## 方案

- 为所有阶段行设置统一的 `46px` 标签列。
- 阶段标签右对齐，属性列左对齐。
- 保持每个阶段独占一行，同阶段属性仍横向紧凑排列并可自然换行。
- 桌面与窄屏共用同一对齐规则。
- 不修改气泡尺寸、内容、累计逻辑、PWA 或其他分区。

## 验收重点

- `150速` 等每行首个属性的左边缘上下对齐。
- `10阶：`、`15阶：` 不被截断或换行。
- 气泡仍不撑高表格行。

按照项目约定，浏览器手动验收由用户执行。

# 1.0.91 机关兽操作条遮挡修正

截图现象：流派计算操作条覆盖下方研发度、等级与碎片输入区，底下文字透出。

源码原因：`.machine-calc-actionbar` 使用 sticky/top/z-index，滚动时浮于输入之上；背景引用未定义的 `--bg1`，因此没有有效的不透明底色。个人进度编辑按钮区也存在同类吸附/背景组合。

修改：两种按钮区改为正常文档流，移除吸顶/吸底偏移和层级，背景使用已定义的 `--panel`；同文件搜索条的无效背景引用一并更正。原有计算、读取、参与兽、查看结果与返回设置入口保留。

范围：仅机关兽CSS和用户待运行的回归用例、PWA1.0.91资源号。未修改计算逻辑、游戏数据、库存或账号保存。

按AGENTS.md未主动运行测试、lint或浏览器验收；新增遮挡回归用例尚未执行，不宣称已测试通过。建议用户在桌面与手机滚动流派输入页、展开库存、编辑个人进度，确认按钮不再悬浮覆盖输入、点击与锚点返回仍正常。

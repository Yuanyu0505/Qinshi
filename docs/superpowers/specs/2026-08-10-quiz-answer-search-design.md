# 答题正确答案查询设计

## 目标

新增独立“答题”分区，基于项目根目录的 `答题.jpg` 提供题目关键词搜索，并且只显示每题标红的正确答案。

## 数据

- 题库采用离线 JavaScript 数据文件 `data/quiz.js`。
- 每条记录仅包含 `question` 和 `answer` 两项；不保存错误选项，避免任何错误答案进入页面或搜索结果。
- `答题.jpg` 每行的第一列为题目，第二至第五列为选项；红色文字对应 `answer`。

## 交互与展示

- 顶部标签新增“答题”，与既有分区一致地切换页面。
- 搜索框输入关键词时，只对题目文字进行不区分大小写的包含匹配。
- 结果卡片仅展示“题目”和高亮的“正确答案”；无匹配时展示空结果提示。
- 空搜索显示全部题目，以便浏览。

## 范围限制

- 不展示原图，不展示四个选项，不提供答题作答、随机出题、收藏或历史记录。
- 不改变现有橙装锻造、图鉴、掉落、特殊属性装备和楼兰棋阵功能。
- 用户指定由其手动验证，本次不运行自动测试、lint 或浏览器自动检查。

## 人工验收

- 点击“答题”可打开分区，空搜索时显示题库记录。
- 搜索图片中任一题目的关键词，只返回题目包含该关键词的记录。
- 每条记录只含题目和红色高亮的正确答案，页面不显示其余三个选项。

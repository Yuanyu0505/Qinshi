# 1.0.82 修改与用户验收重点

## 修改范围

1. 铭文路径／模拟反查结果的搜索输入框在实时过滤时保留原节点，组合输入结束后再过滤，避免中文输入被重建打断。
2. 应用组合后收起反查结果；“重新选择”恢复原筛选。收起状态随本账号定位草稿保存，不影响共用模拟材料与背包。
3. 去除双品质、双遁位及主属性比较的差值开关和差值表；按已确认 A 保留升级成长差值，百分数使用 %。
4. 属性关键词下提供其他匹配遁位资料，沿用品质／来源条件，不改主查询遁位。
5. 升级表水平／垂直居中，增加升级后品质，仅展示配方可到达的更高品质；蓝二速度保留真实高／中档可能性。
6. 兵法材料使用截图默认购买包规格；已有库存、自定义价格及合法零价格保留。每包数量与价格默认只读，通过编辑／保存／取消修改，非法值与存储拒绝不替换原价。
7. 一键升至允许上限设置临时目标兵法15阶及对应真言上限，更新计划与参考资料，不写真实个人进度。
8. 五处 PWA 版本统一1.0.82。

## 验证状态

遵循项目 AGENTS，本次未主动运行测试、lint、格式检查、构建或浏览器／实机验收。仅做源码级检查并提供／更新回归用例，不能据此宣称功能已测试通过。上个版本1.0.81的测试结果不代表本次改动通过。

独立只读源码审查指出的关键词失焦重绘导致首击失效、升级表表头垂直对齐规则被覆盖两处问题已按源码修正；未进行运行验证。

## 建议用户检查

- 路径与模拟各自反查“盖聂”等中文，尝试连续输入、删除、拼音候选切换；搜索框应不丢字、不掉焦点。
- 应用组合后结果收起，重新选择、切分区、刷新后筛选保留；不点击“应用到模拟”则现场原样。
- 资料图表输入“技能穿透”并查看其他遁位；切换品质与来源；成长表选择蓝二→橙二、紫一→橙一，差值格式及列对齐正常。
- 双品质／双遁位／主属性对比不再出现差值开关或差值表，升级成长仍有差值选项。
- 兵法购买包默认价是否正确，点击编辑保存／取消，测试空白、负数、零价格和浏览器拒绝存储；旧库存不变。极真言保持未设置直至手工定价。
- 一键升至允许上限后，目标为15阶且各真言达到允许值，起点和真实个人进度不变；检查风林火山、阴、雷。
- 手机、平板查看资料表格局部滚动及兵法价格编辑布局。

可由用户执行：`npm test`、`npm run test:browser`。新回归文件为 `tests/update-1082.cjs`；另扩展铭文定位、成长数值和兵法默认价格单测。均未执行。

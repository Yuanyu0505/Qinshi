# 禁地用途标记与跨分区查询设计

日期：2026-09-10  
状态：需求已确认，直接进入实施

## 1. 目标

在不改变禁地奖励资料、活动排期和搜索语义的前提下，升级禁地中的个人需求管理与跨分区查询：

- 将“勾选需求”“设置用途”“点击名称跳转”拆成互不冲突的操作；
- 已勾选奖励可同时标记图鉴、锻造、机关兽多个用途；
- 支持按用途筛选，并清楚区分未勾选、已勾选、用途和搜索命中；
- 弟子精确跳转本体与对应神弟子图鉴；
- 装备及碎片跳转图鉴、橙装锻造和装备属性；
- 机关兽及神核跳转机关兽个人进度；
- 所有跳转沿用统一返回栈，恢复禁地筛选、展开状态和滚动位置；
- 兼容既有禁地勾选数据、备份导入和手机／平板布局。

本次不修改禁地资料内容，不增加奖励数量计算，不修改装备或机关兽业务数据。

## 2. 核心交互

### 2.1 复合名称组件

禁地中的弟子和奖励不再把整个彩色标签当作勾选区域，而是拆成：

1. 独立勾选按钮，只控制是否加入本期需求；
2. 名称按钮，只负责打开跳转菜单或直接跳转；
3. 已勾选奖励的“设置用途”按钮；
4. 已保存用途的彩色文字标签。

名称无论是否勾选都可以跳转。弟子不提供用途设置。

### 2.2 用途编辑

- 用途为多选；
- 奖励允许先勾选、暂不分类；
- 装备、典籍、饰品及其碎片可选“图鉴”“锻造”；
- 机关兽与神核只可选“机关兽”；
- 保存用途不自动跳转；
- 应用范围默认“仅本期”，可改为“全部同装备族”；
- “全部同装备族”是一次性同步，之后各期仍可独立修改；
- 面板提供“取消勾选”，并支持仅本期或全部同装备族；
- 快捷勾选按钮取消时只影响本期，并清除该期用途。

电脑和平板使用定位浮层，手机使用底部弹层。取消关闭不写入数据，保存后更新当前可见卡片与本期需求汇总。

## 3. 状态与视觉

| 状态 | 视觉规则 |
| --- | --- |
| 未勾选 | 现有橙色底和橙色边框，无勾号 |
| 已勾选、未分类 | 绿色底、绿色边框、勾号和“未分类”标签 |
| 图鉴用途 | 已勾选绿色主体内增加紫色实底“图鉴”标签 |
| 锻造用途 | 已勾选绿色主体内增加金橙色实底“锻造”标签 |
| 机关兽用途 | 已勾选绿色主体内增加蓝色实底“机关兽”标签 |
| 多用途 | 并列显示全部用途标签 |
| 搜索命中 | 保留主体状态，额外增加鲜红色粗外框与光晕 |

所有用途必须同时显示文字，不能只依赖颜色。搜索命中始终使用最外层红色强调，避免与绿色勾选或用途色混淆。

## 4. 用途筛选

工具栏新增单选筛选：全部用途、未分类、图鉴、锻造、机关兽。

- 可与关键词、大小禁地、仅看已勾选、完整预测表叠加；
- “未分类”只匹配已勾选且用途数组为空的奖励；
- 命中期次保留完整卡片内容；
- 不符合当前用途的卡片内部项目适当弱化，但保持可读与可操作；
- 本期需求汇总继续分为“需要的弟子”和“需要的奖励道具”；
- 一个奖励只显示一次，名称后并列显示其全部用途。

原始奖励区与本期需求汇总区共享状态、用途编辑和跳转逻辑。

## 5. 存储和装备族

新增版本化禁地需求模型。每一期保存：

- 弟子勾选名称；
- 奖励的稳定标识、显示名称、类别、是否勾选；
- `familyKey`；
- `purposes: ("atlas" | "forging" | "machine-beasts")[]`。

装备本体和对应碎片具有相同 `familyKey`，例如“月光耳坠”和“月光耳坠碎片”属于同一装备族。仅本期快捷操作仍按当前奖励记录修改；选择“全部同装备族”时，跨全部期次一次性同步勾选状态和用途。

机关兽本体与神核虽然解析到同一机关兽查询名称，但使用不同同步族，避免选中机关兽时连带选中神核。

旧 `qinshi_forbidden_needs_v1` 数据在读取时迁移：原弟子与奖励保持勾选，奖励用途为空。新键继续使用 `qinshi_` 前缀，因此现有设置备份会自动包含；导入只含旧键的备份时仍执行迁移。

## 6. 弟子图鉴跳转

点击弟子名称直接进入图鉴精确组合查询，不弹目标分区菜单。

- 搜索框显示“本体名＋神弟子名”；
- 结果只接受明确目标名称的精确匹配，不使用核心姓名模糊匹配；
- 手动修改搜索框后退出组合条件，恢复普通搜索；
- 一方不存在时展示现有结果，并提示缺失名称；
- 隐虎季布没有任何图鉴，跳转后显示未找到，不能误匹配普通季布。

实现使用完整显式映射表。特殊映射为：

- 肃杀真刚 → 神·真刚；
- 兵家王翦 → 神·王翦；
- 龙魂小黎 → 神·小黎；
- 隐虎季布 → 无图鉴目标；
- 人宗逍遥子 → 神·逍遥子。

其余禁地弟子按已确认的完整本体名与完整神弟子名一一映射，不在运行时通过删除前缀或模糊姓名推断。

## 7. 装备与碎片跳转

贡献奖励、排名奖励、装备碎片、刷出橙装及其他非机关兽奖励均显示统一菜单：

- 前往图鉴分区查询；
- 前往橙装锻造分区查询；
- 前往装备属性分区查询。

碎片跳转前移除“碎片”后缀并解析对应装备族。橙装锻造默认进入个人进度；手动切换主装备、素材装备或个人进度时继续使用同一装备族和同一返回关系。

所有进入橙装锻造的名称沿用普通锻造版本映射；鬼谷子和神兵鬼谷子保持两个独立装备族。目标分区不存在资料时仍显示跳转选项，并正常展示“未找到”。

## 8. 机关兽与神核跳转

点击机关兽或神核名称直接前往机关兽分区个人进度，并使用完整机关兽名称精确查询。短名称通过固定映射解析，例如：

- 王蛇 → 赤练王蛇；
- 三郎 → 破土三郎；
- 零号 → 零号白虎；
- 玄武 → 机关玄武；
- 年兽 → 机关年兽。

进入后手动切换方案计算或资料图表，继续保留同一机关兽查询条件和返回禁地关系。

## 9. 统一返回

跳转前保存禁地关键词、类型筛选、用途筛选、仅看已勾选、完整预测状态、卡片展开状态与滚动位置。返回时恢复来源视图。

图鉴、锻造、装备属性或机关兽页面中的手动切换和编辑不应使返回入口失效。目标视图完全未修改时，可以恢复其跳转前状态；目标视图已修改时保留玩家修改，不回滚持久化数据。

## 10. 响应式和性能约束

- 可点击控件在手机端至少 44px；
- 名称、用途标签和操作允许自然换行，不产生横向滚动；
- 手机用途面板贴底并避开安全区；
- 桌面／平板浮层限制在视口内；
- 使用事件委托，不为每个奖励单独注册监听器；
- 输入搜索沿用合并刷新队列；
- 单期操作优先局部更新卡片和汇总；
- 全装备族同步只重绘当前可见结果。

## 11. 用户验收重点

本次按用户要求不由 AI 主动运行测试、构建或实机验收。用户应重点验证：

1. 未勾选、勾选、三类用途和搜索命中可以同时辨识；
2. 多用途保存、仅本期同步、全部装备族同步和批量取消；
3. 弟子精确双图鉴与隐虎季布空结果；
4. 碎片按装备本体跳转，锻造默认个人进度；
5. 机关兽短名称精确跳转并跨模式保留查询；
6. 返回禁地后筛选、展开位置和滚动位置恢复；
7. 手机、平板无横向滚动，底部用途面板可完整操作。

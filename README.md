# Qin

图鉴、橙装锻造、关卡掉落、装备属性、禁地、铭文、机关兽、兵法、战匣丹囊、合阵、楼兰棋阵、逐鹿与答题综合攻略工具。支持 Windows 本地使用，也可作为 PWA 安装到 Android、iPhone 和 iPad；首次联网缓存完成后可整站离线运行。

## 在线地址

<https://yuanyu0505.github.io/Qinshi/>

## 手机和平板安装

### Android 手机或平板

1. 使用 Chrome 打开在线地址。
2. 打开浏览器菜单，选择“安装应用”或“添加到主屏幕”；也可以进入工具的“设置”分区点击“安装到设备”。
3. 首次打开并等待“全部工具资源已准备离线使用”后，即可断网使用。

### iPhone 或 iPad

1. 使用 Safari 打开在线地址。
2. 点击 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”，名称保持为“Qin”。
4. 从主屏幕打开一次并完成首次缓存，之后即可断网使用。

## 电脑使用

推荐使用上方在线地址并安装为 PWA；也可双击 `启动服务.bat`，再通过窗口自动打开的 `http://localhost:8000～8010` 地址使用。

直接双击 `index.html` 仍可使用本机查询、计算和进度保存，但浏览器会将本地文件标记为不可信来源，因此不支持云同步。已有本地文件数据只需迁移一次：先在设置页导出备份，再从在线版或 `启动服务.bat` 打开的页面导入；此后即可直接使用云同步。

## 手机访问

1. 双击 `启动服务.bat`（首次启动如遇 Windows 防火墙弹窗，选「允许」）
2. 手机连接与电脑相同的 Wi-Fi
3. 用手机浏览器打开窗口中显示的「手机访问」地址

局域网访问仍然保留，但推荐直接使用上方 GitHub Pages 地址安装 PWA。

## 离线、更新与本机进度

- 第一次访问需要联网下载全部查询数据、题库和楼兰棋阵图片；完成后整套工具可离线使用。
- 检测到新版本时页面会显示提示，点击“立即更新”后才会切换版本。
- 图鉴、橙装锻造、禁地、铭文、机关兽、兵法、战匣丹囊和合阵进度保存在当前设备的浏览器中，不会自动同步到其他设备。
- “设置”分区可导出 JSON 备份或导入备份；导入前会自动下载当前数据备份，再整体覆盖当前设备的进度。

## 跨设备云同步

- 设置页提供手动的设备快照同步；云同步只同步端到端加密的工具数据，不自动合并多台设备的内容。
- 云同步支持在线地址、已安装的在线 PWA，以及 `启动服务.bat` 打开的 `localhost` 地址；不支持直接双击 `index.html` 或将本地地址改成 `127.0.0.1`。
- 每次由用户明确选择“来源设备 → 当前设备”，用来源设备的完整快照覆盖当前设备；每台设备保留最近 3 份历史。
- 工具代码和新增功能由 PWA 更新单独分发。同步开始前会先确认 PWA 版本满足要求，数据同步本身不会更新网页代码。
- 云端后端限定使用 Workers Free 与 D1 Free。免费额度不可用时只暂停云同步，本地工具和 JSON 备份仍可使用；第三方计划、额度和定价可能变化，不承诺 Cloudflare 永远免费。
- 生产 Worker 已启用；公开配置仅包含 Worker HTTPS 地址，不包含任何密钥或账号凭据。免费边界、本地验证、配置隔离和安全发布顺序见 [`cloud-sync/worker/README.md`](cloud-sync/worker/README.md)。

## 查询功能

- 搜索：输入装备名或分类关键词（如：墨眉 / 武器 / 神兵饰品）
- 主属性筛选：不限 / 攻 / 防 / 血（默认不限，可单独筛选）
- 副属性筛选：点击属性芯片，最多同时选 2 个（AND；只匹配副属性，主属性不算）
- 排序：选中副属性后按副属性数值倒序；可切换排序属性与取值档位（最高值 / 红色 / 红金）

## 分区

- **装备属性**：装备查询（名称搜索 / 装备分类筛选 / 属性筛选 / 排序）
- **橙装锻造**：锻造材料总览 + 两种查找方式（作为主锻造装备 / 作为素材装备）+ 个人进度（分页展示：第一页全体汇总、之后每页一名弟子，左右翻页；管理弟子装备、记录锻造进度、自动汇总剩余材料；添加装备无需选分区，关键词自动匹配并归入对应分区；支持跨全部弟子模糊搜索装备，同时展示直接归属和尚未完成阶段的锻造材料需求）
- **关卡掉落**：输入道具关键字，统计普通关卡、英雄关卡、声望奖励三个分区的全部掉落方式，分区独立展示
- **图鉴**：支持全部/攻/血/内力/防分区、`0–20` 等级闭区间筛选，以及按弟子、图鉴、装备、获取途径或等级限定关键词搜索；图鉴等级为个人进度可自由调整，可设置目标等级并统计升至目标所需的明鬼绳结、魂魄、实际装备与成长值（14级后不再获得成长值）
- **禁地**：按日期、禁地大小、弟子、图鉴属性和奖励关键词查询活动预测；分行展示贡献、排行、装备碎片、机关兽、神核和橙装奖励，并可勾选保存每期需求。
- **楼兰棋阵**：楼兰（5 张）与棋阵（11 张）两个玩法的本地攻略图片，点击顶部标签切换
- **逐鹿**：查询 5～2500 进度奖励；按年月、典籍、品质和进度档位组合筛选赛季典籍；明确资料与十个月循环预测分组展示；典籍可继续查询出现赛季、橙装锻造个人进度或图鉴需求，不保存个人进度。
- **答题**：按题目关键词搜索答题图片中的题目，只展示每题标红的正确答案，不展示错误选项
- **铭文**：个人进度、品质/天位/盾位查询筛选、天位主属性与盾位副属性资料图表
- **兵法**：按风、林、火、山、阴、雷筛选；保存兵法及真言个人进度；自由设置计算起点和目标，汇总进阶材料、真言碎片和目标阶演练号角；查看0–15阶完整资料。
- **战匣丹囊**：按弟子独立保存战匣、丹囊等级及装备／内丹品质；按玩家等级和物品品质计算可达上限；支持多弟子目标规划、共享库存分配、购买补足与完整等级资料查询。
- **机关兽**：按霸道机关术、非攻机关术切换保存各机关兽累计研发度、阶数/改造库存和机关兽碎片；计算达到目标研发等级的最少投入方案、研发材料与贡献元宝；个人进度、方案计算和资料图表均可搜索并高亮机关兽，资料按归属效果、流派阶数、累计研发度、阶数改造研发度排列。
- **合阵**：查询官方合阵资料，保存弟子属性，并计算主将与助阵位置推荐。

桌面导航顺序为图鉴、橙装锻造、关卡掉落、装备属性、禁地、铭文、机关兽、兵法、战匣丹囊、合阵、楼兰棋阵、逐鹿、答题、设置；选中分区使用剑形背景。平板保留左侧导航并按窄栏尺寸适配剑形选中项；手机端继续使用底部导航，图鉴、橙装锻造、关卡掉落、装备属性为主导航，其余功能位于“更多”面板。

# 秦时主题视觉焕新设计说明

## 目标

在不修改数据、功能逻辑、存储结构和现有品质配色语义的前提下，将工具统一为“秦宫暗金 × 墨色竹简”视觉风格，使网页端更具《秦时明月》的古风氛围，同时保持手机和平板上的信息密度、触控尺寸和阅读效率。

## 视觉方向

- 背景：以墨黑、深褐为主，通过多层低对比度渐变模拟夜色、宣纸和远山，不使用大面积高亮图片。
- 容器：主要面板采用黑漆木与竹简质感，使用细暗金边、内阴影和轻微高光建立层次。
- 装饰：仅在一级面板、标题和桌面导航上使用秦纹、印章、铜钉等点缀；数据密集区不铺装饰图案。
- 状态色：朱砂红表示当前选中与重点命中，帝王金表示标题与关键数值，玉石绿表示保存、完成和已有状态。
- 品质色：紫色、橙色、红色装备及已有的搜索命中颜色继续沿用当前业务语义，不被主题色覆盖。

## 结构与交互

1. 桌面左侧导航保留现有剑形选中状态；未选中项增加纵向铜线与小型菱形铜钉，形成竹简目录感。
2. 页面标题使用楷体金字、细分隔线和小型朱砂印记；不新增工具名或重复分区标题。
3. 通用 `.panel`、汇总卡、结果卡、资料卡统一为黑漆渐变面板；一级面板使用克制的角纹，嵌套卡片只保留边框和层次。
4. 按钮、筛选器、输入框和下拉框统一边框、悬停、聚焦及选中状态；不改变原有尺寸逻辑和事件绑定。
5. 表格标题、分隔线、行悬停与滚动容器使用更清晰的暗金层级；不修改列宽、冻结、横向滚动等已有规则。
6. 动效仅包含短时悬停高光和焦点反馈，并在 `prefers-reduced-motion` 下关闭。

## 移动端与平板

- 低于 1024px 时降低背景纹理与阴影强度，减少圆角和装饰留白。
- 底部导航采用黑漆底与朱砂选中态，不显示桌面纵线、铜钉或剑形背景。
- 保留现有 44px 触控高度、卡片布局、冻结表格和底部安全区规则。
- 不增加横向滚动，不改变现有数据卡片的列折叠逻辑。

## 技术方案

- 在 `css/style.css` 末尾新增一个明确分区的主题覆盖层，以 CSS 自定义属性、渐变、伪元素和阴影完成视觉焕新。
- 不增加 JavaScript，不改 DOM，不新增图片资源；继续使用 `images/nav-sword.png`。
- 新样式只覆盖视觉属性，避免覆盖布局网格、定位、显示隐藏和业务状态类。
- PWA 版本和缓存清单本次不变，等待用户明确要求后再发布。

## 风险控制

- 使用低特异性通用规则和少量明确分区选择器，避免覆盖已有紫/橙/红品质标签。
- 所有伪元素设置 `pointer-events: none`，不遮挡按钮、搜索输入和可复制文本。
- 移动端单独清除桌面导航装饰，避免底部导航出现纵线或剑形错位。

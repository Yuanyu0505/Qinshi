# 连续铭文流程图与清除选项

用户要求直接实现并仅合并本地，不发布。保留规则、概率、品质色和原生下拉。

- 两个按钮统一为“清除所有选项”：两页共享的弟子、位置、独立遁位、目标属性及当前模拟材料/结果复位；品质恢复默认橙二。有模拟数据时确认，取消不改数据；不清空个人已保存铭文。
- 每个方案仅一张 SVG，材料产出直接连接后续操作，概率失败品直接连接复用操作及共同目标；保留图内缩放滚动，不再跨步骤拆图。
- 置换/洗练作为独立准备源，不再绘制原示例基础材料 → 洗练的依赖；同品质的置换材料和合成材料位于同一层，洗练框在其产物上方。另备同品质铭文，不消耗其他支线产物。
- 使用品质分层、同层节点间距和源端投料数量标签，避免把材料间的关系解释成串行消耗。重复材料按箭头数量备齐，概率以材料备齐为前提。

不推送 GitHub、不升级 PWA；不主动运行测试、构建、lint 或实机验收。建议人工检查清除及取消行为、M2/M3 平行关系、一方案一张图、失败分支复用及移动端缩放。

独立只读审查发现共同目标入线的概率标签会重叠，已将这些标签放到各自操作的出线端，未执行运行时验证。

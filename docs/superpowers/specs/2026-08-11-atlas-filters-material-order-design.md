# 图鉴复合筛选与材料排序设计

## 目标

- 图鉴支持全部分区、等级闭区间和限定字段关键词搜索，并让所有条件共同生效。
- 图鉴升级装备统一使用橙装锻造的高亮材料标签，按紫色优先、橙色其次，同品质按名称拼音升序。
- 橙装锻造个人进度的汇总与阶段材料改为紫色优先；全体汇总使用四列，阶段与材料保持上下对齐。

## 图鉴筛选

- 分区按钮顺序为：全部、攻图鉴、血图鉴、内力图鉴、防图鉴；默认选择“全部”。
- 等级筛选使用两个 `number` 输入框，范围均为 `0–20`，默认 `0–20`，筛选时包含最小值和最大值。
- 最小值大于最大值时结果为空，不自动交换用户输入。
- 搜索限制条件为：全部、弟子、图鉴、装备、获取途径、等级。
- “弟子”匹配弟子名；“图鉴”匹配所属图鉴名和攻/血/内力/防分区名；“装备”匹配升级所需装备；“获取途径”匹配获取途径；“等级”匹配当前个人图鉴等级。
- 等级限定搜索接受整数或“整数级”作为精确匹配，同时保留“整数级以下/以上”的既有语义。
- 分区、等级闭区间、搜索限制条件和关键词按交集筛选。

## 材料排序与样式

- 品质顺序固定为紫色、橙色；同品质使用 `localeCompare(..., "zh-Hans-CN")`。
- 图鉴单条阶段装备与当前结果汇总装备都使用 `.material-token`：白字、2px 品质色外框、品质色高亮背景。
- 橙装锻造的弟子汇总、全体汇总和每个阶段材料复用同一排序函数，避免不同页面顺序不一致。

## 布局

- 全体弟子剩余材料汇总增加专用四列网格；中等宽度降为两列，窄屏降为一列。
- 单个弟子的阶段表保持固定布局，阶段列为 36%，材料列为 64%；阶段内容使用统一变量向右移动，材料内容按相同距离向左移动，所有装备沿用相同列位置且不改变上下间距。
- 单个弟子的剩余材料汇总仍保持原有列数。

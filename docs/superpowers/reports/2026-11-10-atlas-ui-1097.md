## 确认的问题及修改

1. **P0 DOM重入**：聚焦等级数字框后派发change，可稳定复现 `replaceWith ... node ... no longer a child ... blur`；等级框失焦时重绘头部，还会吞掉紧接着的收藏点击。现在复用头部及原控件，仅刷新需求/资料/编辑区；提交栈使用有finally复位的重入保护。仍重新查询筛选和排序，不能用局部更新绕过结果重排。
2. **库存错误距离字段过远**：非法小数沿用原错误文案和整数规则，原位更新字段下方错误，不重建表单。增加唯一描述ID、aria-invalid和错误字段焦点；修正有效输入后去除错误。其他装备草稿不丢失。
3. **手机库存密集**：装备行按阶段/名称/拥有状态/备注分组；窄内容区状态、备注各有独立空间；宽屏保持四列表单，编辑卡跨双列。
4. **卡片缺少层级**：身份/收藏/置顶/等级始终可见，其后为目标与三项资源，完整资料与装备使用原生details。所有字段保留，同一模板，未新增独立密度模式或持久化UI格式。详情与汇总装备展开状态在重绘时保留。
5. **筛选及资源难扫描**：手机六分区均衡三列；搜索与等级条件成组；五项汇总数值分列，千分位仅用于展示。空查询只展示一个主要空状态，初始未激活仍不显示结果。
6. **菜单越界**：固定定位仍保留原DOM和多选选项，依据visualViewport、底部导航及上下空间定位，空间不足内部滚动，响应滚动/旋转，Escape关闭回焦点、外部点击关闭。保留多选后继续打开，避免重复开合；不改备注匹配语义。
7. **宽屏浏览效率**：实际图鉴容器达到1000px才双列，按DOM顺序自动排版，不用dense或绝对定位。低于该宽度保持单列；归并旧的图鉴手机/平板覆盖到专属容器样式。

# 战匣丹囊资料表与子页签修正设计

## 目标

修正战匣丹囊分区的子页签滚动行为、关键节点材料口径及资料表对齐方式，不改变个人进度、目标计算、等级数据或现有筛选交互。

## 子页签

- “个人进度／目标计算／资料图表”容器进入普通文档流，页面向下滚动时与其他内容一起被顶出视口。
- 移除这三个按钮外层容器的整体边框、背景、模糊效果和额外内边距。
- 三个按钮自身的边框、选中态和点击行为保持不变。

## 关键节点材料

- “全部等级”和“当前附近”继续显示从上一等级升到本等级的单级材料。
- “关键节点”保留 1、10、20、30、40、50、60、70、80、90 级。
- 1级材料表示0级升到1级的消耗。
- 10级材料累计2至10级；其后每个整十级节点累计前一关键节点之后到当前节点，例如20级累计11至20级。
- 战匣与丹囊的沧海珠、玄龟甲均使用同一套区间累计逻辑；属性列仍显示目标节点自身属性。
- 战匣列名“玩家对战免伤”统一改为“PVP免伤”。

## 表格布局

- 战匣、丹囊资料表使用固定列布局，所有表头和数据单元格水平居中、垂直居中。
- 首列不再单独左对齐；桌面和平板的列宽由表格平均分配，使列间距视觉一致。
- 手机端继续使用现有逐行卡片形式，标签与数值垂直居中，不恢复宽表横向滚动。

## 验证

- 核心单元测试用手算常量验证1级、10级、20级关键节点的区间材料累计。
- 页面测试验证新字段名称、关键节点调用参数和非冻结无外框样式。
- 完整测试覆盖战匣丹囊既有数据、规划计算与其他分区回归。

# 物品跨分区统一跳转设计

## 1. 目标

统一装备属性、橙装锻造、关卡掉落、图鉴、禁地和逐鹿之间的物品查询跳转。所有入口使用一致的操作菜单、名称解析、逐级返回和状态恢复规则，同时保留各分区原有的搜索、筛选、计算和本地进度功能。

本设计重点解决以下问题：

- 同一装备在装备属性中可能使用神兵名称，在橙装锻造及资料分区中使用普通锻造名称。
- 橙装锻造的主装备、素材装备和个人进度必须共用同一个普通锻造名称。
- 个人进度查询既要命中弟子直接持有的普通版或神兵版，也要命中尚未完成阶段中作为素材的普通装备。
- 连续跨越多个分区时需要逐级返回，并恢复每一级来源页面的原状态。
- 目标页面被手动修改后，返回入口仍然有效，但不能覆盖用户在目标页面进行的新操作。

## 2. 范围

### 2.1 包含

- 装备属性中的全部装备名称。
- 橙装锻造查询结果中的主锻造装备名称。
- 橙装锻造各锻造阶段中的装备素材名称。
- 关卡掉落默认橙装表和搜索结果中的道具名称。
- 逐鹿赛季典籍名称。
- 图鉴、禁地、关卡掉落、装备属性、逐鹿和橙装锻造的目标查询适配。
- 橙装锻造查询与同分区个人进度之间的跳转和返回。
- 任意层级的逐级返回导航栈。

### 2.2 不包含

- 不修改装备属性、锻造材料、关卡掉落、禁地或逐鹿资料数据。
- 不修改各分区自身面向用户的普通手动搜索规则。
- 不修改个人进度、收藏、图鉴库存和禁地需求的本地存储结构。
- 不让锻造阶段中的“—”等非装备内容具有跳转能力。
- 不在本功能中更新 PWA 版本或发布配置。

## 3. 核心名称模型

每个被点击的名称解析成一个导航物品对象：

```text
NavigationItem
  clickedName       用户实际点击并在菜单中展示的名称
  forgeKey          锻造资料使用的普通名称；鬼谷子例外保持双键
  equipmentName     装备属性优先查询的装备名称，通常为神兵版本
  familyKey         个人进度精确装备族使用的键，与 forgeKey 相同
```

目标分区不得自行猜测名称，必须从该对象选取对应字段。

| 目标 | 查询字段 |
|---|---|
| 橙装锻造－作为主锻造装备 | `forgeKey` |
| 橙装锻造－作为素材装备 | `forgeKey` |
| 橙装锻造－个人进度 | 输入框显示 `forgeKey`，内部使用 `familyKey` |
| 图鉴 | `forgeKey` |
| 关卡掉落 | `forgeKey` |
| 禁地 | `forgeKey` |
| 逐鹿 | `forgeKey` |
| 装备属性 | `equipmentName`；无映射时回退 `clickedName` |

### 3.1 锻造主键解析顺序

1. 优先使用已经确认的神兵与普通锻造名称一一对应表。
2. 如果点击名称本身就是锻造资料中的名称，直接使用该名称。
3. 其他以“神兵”开头的名称尝试去掉前缀，并确认普通名称存在于锻造资料中。
4. 没有任何锻造资料时使用点击原名，目标页面正常展示“未找到”。

示例：

| 点击名称 | `forgeKey` | `equipmentName` |
|---|---|---|
| 神兵月光 | 月光耳坠 | 神兵月光 |
| 月光耳坠 | 月光耳坠 | 神兵月光 |
| 神兵非攻 | 非攻九变 | 神兵非攻 |
| 非攻九变 | 非攻九变 | 神兵非攻 |
| 神兵白羽 | 白羽绸衣 | 神兵白羽 |
| 神兵墨眉 | 墨眉 | 神兵墨眉 |
| 墨眉 | 墨眉 | 神兵墨眉 |
| 秦时周年历 | 秦时周年历 | 秦时周年历 |
| 虎年勋章 | 虎年勋章 | 虎年勋章 |

秦时周年历和虎年勋章没有锻造资料，但仍显示“前往橙装锻造分区查询”，使用原名并正常显示空结果。

### 3.2 鬼谷子例外

鬼谷子和神兵鬼谷子是两个独立锻造主键，不合并为同一装备族：

| 点击名称 | `forgeKey` | `familyKey` |
|---|---|---|
| 鬼谷子 | 鬼谷子 | 鬼谷子 |
| 神兵鬼谷子 | 神兵鬼谷子 | 神兵鬼谷子 |

搜索鬼谷子不得命中神兵鬼谷子的直接持有记录或素材需求；搜索神兵鬼谷子也不得命中普通鬼谷子。

### 3.3 普通版与神兵版共用装备族

除鬼谷子外，普通版和神兵版使用同一个 `familyKey`。四件允许在个人进度中分别保存普通版和神兵版的稀缺装备也遵守这一查询规则：

- 地煞魔铠／神兵魔铠
- 月光耳坠／神兵月光
- 寒霜挂坠／神兵寒霜
- 百家杂记／神兵百家

它们是不同的持有记录，但属于同一个锻造装备族。搜索该普通锻造名称时，两种持有记录均可命中。

## 4. 个人进度的装备族搜索

### 4.1 两类结果必须同时计算

个人进度的装备查询继续展示两个结果区：

1. `owned`：弟子直接持有。
2. `required`：弟子装备尚未完成的锻造阶段需要该装备作为素材。

以 `月光耳坠` 为例：

- 弟子持有神兵月光时，其保存记录解析出的 `familyKey` 为月光耳坠，因此进入 `owned`。
- 弟子持有普通月光耳坠时，同样进入 `owned`。
- 任意弟子装备的未完成阶段含有名称为月光耳坠的素材时，进入 `required`。
- 仅名称中含有“月光”但不属于月光耳坠装备族的记录不得进入结果。

### 4.2 精确装备族模式

以下情况使用精确装备族模式：

- 从其他分区自动跳转到个人进度。
- 手动输入完整普通锻造名称。
- 手动输入完整神兵名称。
- 手动输入能够唯一解析到一个装备族的明确别名。

精确模式的判断规则：

```text
owned：保存记录解析后的 familyKey === 当前 familyKey
required：未完成阶段中素材解析后的 familyKey === 当前 familyKey
```

个人进度输入框始终显示普通锻造名称。例如点击神兵月光后进入个人进度，显示“月光耳坠”，不显示“神兵月光”。

### 4.3 普通关键词模式

当玩家输入的内容不能唯一指向一个装备族时，继续使用现有模糊搜索。例如“神兵”“战袍”“月”等宽泛关键词可以同时展示多个相关装备。

当玩家手动修改自动填入的关键词时，重新解析当前输入：

- 能唯一确定装备族时继续精确模式。
- 不能唯一确定时切换为普通关键词模式。

## 5. 操作菜单

### 5.1 装备属性

所有装备名称均可点击，菜单固定包含：

1. 前往图鉴分区查询
2. 前往橙装锻造分区查询
3. 前往关卡掉落分区查询
4. 前往禁地分区查询

进入橙装锻造时默认落在“查询／作为主锻造装备”，输入 `forgeKey`。

### 5.2 橙装锻造查询

主锻造装备名称和锻造阶段中的装备素材名称均可点击。菜单包含：

1. 前往个人进度查询
2. 前往图鉴分区查询
3. 前往关卡掉落分区查询
4. 前往装备属性分区查询
5. 前往禁地分区查询
6. 前往逐鹿分区查询

“前往个人进度查询”属于橙装锻造同分区跳转。输入框显示 `forgeKey`，内部按 `familyKey` 搜索。

### 5.3 关卡掉落

默认橙装表和全部搜索结果使用同一菜单：

1. 前往图鉴分区查询
2. 前往橙装锻造分区查询
3. 前往装备属性分区查询

现有三个橙装锻造选项合并为一项。从关卡掉落进入橙装锻造时，默认落在个人进度，输入 `forgeKey`。

### 5.4 逐鹿

菜单包含：

1. 查看出现赛季
2. 前往橙装锻造分区查询
3. 前往图鉴分区查询
4. 前往装备属性分区查询

“查看出现赛季”保持原行为和名称。从逐鹿进入橙装锻造时，默认落在个人进度，输入 `forgeKey`。

### 5.5 文案规则

所有跨分区选项统一使用“前往 XX 分区查询”。仅以下站内动作例外：

- 逐鹿：查看出现赛季。
- 橙装锻造：前往个人进度查询。

## 6. 目标分区适配

### 6.1 橙装锻造

- 从装备属性进入：默认查询／作为主锻造装备。
- 从关卡掉落或逐鹿进入：默认个人进度。
- 从橙装锻造查询进入个人进度：保持在同一分区并切换视图。
- 主装备、素材装备和个人进度三个模式始终显示同一个 `forgeKey`。
- 在目标页面手动切换三个模式或修改搜索词，不取消返回关系。

### 6.2 装备属性

- 查询 `equipmentName`。
- 清除分类、收藏限定、主属性、副属性、排序属性和取值档位。
- 保留“展示主属性”设置和装备对比内容。
- 没有映射或结果时使用原名并显示“未找到”。

### 6.3 图鉴

- 查询 `forgeKey`。
- 自动启用查询结果并切换到全部图鉴、全部字段。
- 清除收藏、魂魄、装备状态、备注来源、排序等会阻止结果出现的条件。
- 返回后可以恢复跳转前的完整图鉴查询状态。

### 6.4 关卡掉落

- 查询 `forgeKey`。
- 自动隐藏默认橙装表并显示搜索结果。
- 无结果时显示现有“未找到匹配道具”。

### 6.5 禁地

- 查询 `forgeKey`。
- 跳转时清除禁地规模、仅看已选择和预测表等限制，展开命中奖励所在卡片。
- 禁地需求勾选数据不受影响。
- 返回后恢复关键词、规模、仅看已选择、预测表、卡片展开状态和滚动位置。

### 6.6 逐鹿

- 查询 `forgeKey`。
- 从外部分区进入时切换到赛季典籍，清除年份、月份、品质和进度档位，仅按名称查看全部赛季。
- 普通武器、防具或饰品没有逐鹿结果时正常显示空结果。

## 7. 逐级返回导航

### 7.1 导航栈

使用后进先出的导航栈。每次跨分区或从橙装锻造查询进入同分区个人进度时，压入一个导航帧：

```text
NavigationFrame
  sourcePartition
  sourceView
  sourceScrollY
  destinationPartition
  destinationViewBeforeJump
  destinationAppliedFingerprint
  item
```

示例：

```text
装备属性 → 橙装锻造 → 图鉴
```

- 图鉴返回橙装锻造。
- 恢复橙装锻造离开时的模式、关键词、结果和位置。
- 橙装锻造继续显示返回装备属性。
- 再次返回时恢复最初的装备属性页面。

同样支持“关卡掉落 → 橙装锻造 → 逐鹿 → 图鉴”等更多层级。

### 7.2 返回规则

- 返回入口不会因为目标分区内的搜索、筛选或锻造模式切换而失效。
- 点击返回时始终恢复来源页面保存的状态和滚动位置。
- 如果目标状态与跳转刚完成时完全一致，则同时恢复目标分区跳转前的旧状态。
- 如果用户修改了目标状态，则保留修改后的目标状态，不能用跳转前旧状态覆盖。
- 橙装锻造查询与个人进度属于同分区跳转，返回时直接恢复跳转前的锻造视图、模式、关键词、结果和滚动位置。

### 7.3 清除导航栈

以下操作清除当前导航链和全部返回提示：

- 通过顶部主导航主动进入与当前返回路径无关的分区。
- 刷新或关闭页面。

在橙装锻造内部切换主装备、素材装备或个人进度，不属于清除条件。

### 7.4 返回入口

目标页面顶部显示当前一级来源，例如：

```text
由装备属性查询：神兵月光       [返回装备属性]
由橙装锻造查询：月光耳坠       [返回橙装锻造]
```

装备名称点击行为统一改为打开操作菜单。原有“再次点击同名装备直接返回”由顶部明确的返回按钮替代，避免一个名称同时承担“打开菜单”和“立即返回”两种冲突行为。

## 8. 状态适配器

统一导航核心只管理栈，不直接操作具体分区。每个分区提供：

```text
captureView()       保存查询、筛选、显示模式和必要的滚动信息
applyQuery(item)    根据 NavigationItem 设置目标查询
restoreView(view)   恢复来源或未修改目标的旧状态
fingerprint(view)   判断目标状态是否被用户修改
```

其中：

- 装备属性、橙装锻造、图鉴和关卡掉落由主页面适配。
- 逐鹿扩展现有 `captureView`、`restoreView`，增加按名称打开赛季查询的方法。
- 禁地补充公开的保存、恢复和自动查询接口。

本地持久数据不进入导航快照，避免返回时回滚玩家刚刚修改的库存、收藏、锻造进度或禁地需求。

## 9. 界面与无障碍

- 操作菜单沿用逐鹿和关卡掉落的浮层样式。
- 桌面端靠近点击名称显示；平板和手机端限制在可视区域内。
- 菜单按钮最小触控高度为 44px。
- 支持点击外部、滚动、窗口尺寸变化和 `Esc` 关闭。
- 键盘打开菜单后聚焦第一项；主动关闭时焦点回到原名称。
- 返回提示在手机端改为上下布局，按钮占满可用宽度。
- 原装备品质底色、锻造品质色和搜索命中样式保持不变。

## 10. 兼容与迁移

- 用统一导航栈替代 `forgeReturnSession`、`progressReturnSession`、`dropJumpSession` 和 `zhuluJumpSession` 的分散职责。
- 保留现有外部事件入口的兼容包装，逐步让装备、掉落和逐鹿菜单发送统一导航事件。
- 旧的本地存储数据无需迁移。
- 个人进度目录需要同时保留鬼谷子和神兵鬼谷子两个条目，不能再因存在神兵鬼谷子而移除普通鬼谷子。
- 四件稀缺装备继续保留普通版与神兵版两条可选记录，但两条记录共享普通锻造 `familyKey`。

## 11. 测试要求

需要补充以下自动化测试代码：

- 神兵名称、普通名称、明确别名和无资料装备的 `forgeKey` 解析。
- 鬼谷子与神兵鬼谷子互不匹配。
- 四件稀缺装备的普通／神兵记录归入同一装备族。
- 个人进度精确装备族搜索同时返回 `owned` 和 `required`。
- 月光耳坠搜索不包含其他不属于该装备族的结果。
- 宽泛关键词仍使用原模糊搜索。
- 各来源进入橙装锻造时的默认模式和普通名称查询词。
- 六个分区菜单的目标集合和统一文案。
- 导航栈多级压入、逐级弹出和来源恢复。
- 目标未修改时恢复旧目标状态；目标修改后保留新状态。
- 同分区查询到个人进度的返回。
- 禁地、图鉴、掉落、逐鹿和装备属性的空结果。

项目约定由用户执行功能测试、构建和手动验收。实现阶段补充测试代码，但不主动运行测试命令或实机验收。

## 12. 验收标准

1. 装备属性全部装备名称均可打开四项菜单。
2. 橙装锻造主装备及阶段装备名称均可打开六项菜单。
3. 关卡掉落的三个锻造入口合并为一个，并新增装备属性入口。
4. 逐鹿保留查看出现赛季，并增加统一命名的三个跨分区入口。
5. 所有进入橙装锻造的查询词均为普通锻造名称，鬼谷子除外保持双键。
6. 月光耳坠个人进度查询同时命中神兵月光持有记录和月光耳坠素材需求，不出现无关结果。
7. 玩家在橙装锻造中切换主装备、素材装备和个人进度后，返回关系仍然存在。
8. 连续多次跨分区后能够按原路径逐级返回。
9. 每次返回都恢复来源页面的筛选、结果和滚动位置。
10. 玩家修改过的目标页面状态不会被旧状态覆盖。
11. 原有各分区搜索规则、进度数据和本地存储内容不受影响。

# 六堂修订与PWA 1.1.39

## 变更

1. 取消堂口按钮组、资料卡的960px独立限宽，与上方四项导航同宽；手机继续三列堂口、两列导航。
2. 使用现有99名阵营神将名单搜索，唯一匹配堂口自动切换，多堂匹配可点击姓名定位，命中姓名高亮。保留输入节点和焦点，中文输入法组合结束后再查找。
3. 去除六堂查看图片按钮与派发事件，原图片文件和其他分区图片功能不变。
4. 升级资料按起点到终点区间筛选；40→50为10步，从40→41开始。0→50共50步；起止相等为0步。累计材料仍从0计算。
5. 用户本次确认的玩家门槛：六堂10—19级分别需要玩家50—59级，20级也需59级，21—50级分别需要60—89级。0—9级暂无门槛资料，不推断。
6. 控制器与计算核心复用同一超限校验，新增升级超限时显示“当前等级最大可升级至X级六堂，无法升级至您指定的目标等级”，不显示旧资源结果、不截断或覆盖用户输入。移除等级解锁状态、未解锁步骤及对应样式/状态代码。

## 数据保护

不改变50行材料数量、总量904/435、30项堂口加成、99名阵营神将、存储key/格式、账号权限或库存。已保存高于玩家门槛的当前进度不降级：目标等于当前等级时仍允许零成本查看，新增升级不得越限。玩家等级未填写时保留材料试算，不推断玩家等级。门槛字段按本次用户确认修订。

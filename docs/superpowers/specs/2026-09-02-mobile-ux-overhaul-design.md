# 手机端整体体验优化设计

## 目标

在不改变业务数据、筛选规则、计算结果和既有跨分区返回语义的前提下，统一优化手机端的布局、触控、导航、长表单和横向表格体验。桌面和平板原有信息架构继续保留。

## 设计原则

- 手机竖屏以 360–430px 为主要宽度；手机横屏覆盖 768–932px 且高度不超过 500px。
- 所有主要触控目标的可点击区域不小于 44×44px。
- 普通底栏切换回到目标分区顶部；浏览器返回恢复前一分区及其滚动位置。
- 装备属性与橙装锻造、锻造个人进度与装备属性之间的既有一次性返回会话保持不变。
- 不改变筛选字段、装备品质数据、兵法材料计算和本机存储格式。

## 导航与弹层

修复横屏下桌面导航最小高度覆盖手机底栏样式的问题。底栏在手机横竖屏都保持约 52–60px，不遮挡正文。

底栏用户切换写入 hash 历史；系统返回键可返回上一分区。普通点击分区后滚动到顶部，浏览器历史返回则恢复该分区最近滚动位置。进入次级分区时，“更多”按钮文字显示当前分区名。

“更多分区”弹层打开后焦点进入关闭按钮，背景进入 inert 状态，Tab 焦点限制在弹层内；关闭后焦点回到原触发按钮。

## 筛选与触控

图鉴保留分区、搜索、等级与目标等级作为常用条件，将库存筛选和排序放入手机端“高级筛选”折叠区。装备属性保留搜索、分类和主属性，将副属性和排序放入折叠区。桌面和平板继续直接展示完整筛选器。

手机端分段按钮、链接按钮、分页按钮、筛选按钮、关闭按钮及其标签点击区域统一提升到 44px。原生复选框保持视觉尺寸，但整个标签达到 44px。

## 长内容

装备属性的移动卡片将各品质改为折叠区；第一项默认展开，其余品质按需查看，收藏、装备名和加入对比仍保持现有行为。

兵法综合计算在手机端将六套兵法设置和材料库存改为折叠区，桌面和平板默认展开。增加悬浮“计算元宝”入口，计算后将结果放到页面前部并滚动到结果摘要。

禁地沿用现有卡片奖励展开机制，不改变需求勾选和奖励结构。

## 横向内容

橙装锻造材料表和铭文资料表增加统一的“左右滑动查看全部”提示、可聚焦滚动容器和边缘渐隐提示。第一列原有固定行为继续保留。

## 无障碍与反馈

搜索输入框补齐程序化标签；折叠按钮维护 `aria-expanded`；更多弹层维护焦点；横向表格提供说明性 `aria-label`。移动端输入字号继续保持至少 16px，数字输入继续只允许手动填写。

## 验收重点

- 360×800、390×844、430×932 无整页横向溢出。
- 844×390 横屏底栏不超过 60px且不遮挡内容。
- 普通分区点击回到顶部；浏览器返回恢复上一分区。
- 图鉴与装备高级筛选可折叠且不改变条件值。
- 装备品质、兵法卡片和材料区可展开收起。
- 锻造与铭文横向表格明确提示可滑动。
- 现有装备—锻造双向跳转和个人进度返回不受影响。

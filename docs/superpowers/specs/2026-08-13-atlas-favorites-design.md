# 图鉴收藏、优先排序与绿色高亮设计

## 目标

为图鉴增加可持久化收藏功能、“已收藏图鉴”分类，并在所有图鉴结果中优先展示收藏项，同时用绿色样式突出收藏图鉴。

## 收藏交互

- 每张图鉴卡片标题栏增加星号按钮。
- 未收藏状态为黄色星号、黄色外框、透明背景。
- 已收藏状态为红色填充背景、红色外框、浅色星号。
- 点击后立即切换收藏状态并重新生成当前结果和升级汇总。
- 在“已收藏图鉴”分类中取消收藏后，该图鉴立即从结果中消失。

## 分类、筛选与排序

- 图鉴分区新增“已收藏图鉴”分类，与全部、攻、血、内力、防并列。
- “已收藏图鉴”只展示收藏项，并继续叠加等级范围、关键词和限定字段搜索。
- 在任何图鉴分类和搜索条件下，收藏项排在未收藏项之前。
- 收藏组和未收藏组内部均保持现有数据顺序，不改变其他排序逻辑。

## 高亮样式

- 收藏卡片增加绿色强调边线。
- 卡片标题区域中的图鉴类型标识和弟子名称使用亮绿色强调，参考铭文个人进度已保存的视觉语义。
- 星号按钮仍保持红色收藏态，不与绿色标题高亮混用。

## 存储与备份

- 收藏 ID 使用新键 `qinshi_atlas_favorites_v1` 保存为字符串数组。
- 读取到损坏或非数组内容时回退为空收藏，不影响页面初始化。
- 现有备份会自动包含全部 `qinshi_` 键，因此无需改变备份格式即可在网页、手机和平板之间迁移收藏。

## 不变范围

不修改图鉴等级、目标等级、升级成本、剩余装备搜索、汇总计算、生成数据或其他分区。

## 回归场景

- 收藏和取消收藏能立即改变星号与卡片高亮。
- 所有分类中收藏项始终优先，组内原顺序不变。
- 已收藏分类只展示收藏项，搜索和等级范围继续生效。
- 已收藏分类取消收藏后项目立即消失。
- 收藏键能被现有备份导出和导入。

# 机关兽模块第二轮 UI/UX 优化报告（1.0.92）

基线：`40b95da` / 1.0.91。仅修改机关兽展示层和发布版本标记，不调整业务规则。

## 检查范围与实际改动

| 区域 | 问题与处理 | 主要实现 |
|---|---|---|
| 个人进度 | 原等级、库存、碎片分散且重复。改成名称/编辑 → 等级与库存/碎片 → 研发度与最高生效效果 → 来源与库存明细；桌面第二层并列，窄屏顺序阅读 | `beastCard()`、模块 CSS |
| 单兽设置 | 执行按钮在材料、价格之前。改成目标与进度 → 库存/使用上限 → 新增材料范围 → 价格 → 唯一执行按钮，仍在正常文档流 | `renderSingleCalculatorControls()` |
| 单兽结果 | 顶部明确当前/目标、预计最终等级、新增完整机关兽实物数量、神图缺口和费用；已有/新增材料仍分列，原本体折算、全部资源明细保留；新增最高生效效果文字 | `renderCalculatorResult()` |
| 流派设置 | 未参与兽默认显示紧凑卡。展开后仍可调整全部进度、库存和上限，重新参与不重置草稿；不参与者原等级仍计入累计；核心库存限制直接显示，详细说明可展开 | `renderSchoolBeastControl()`、现有折叠恢复与输入事件 |
| 流派结果 | 沿用对照组件补主要材料摘要。两套方案不同时按 `beastId` 对齐真实 `finalEffects`，展示最终等级差异及仅一套培养的机关兽；相同方案不生成空差异表 | `schoolComparison()`、`schoolMaterialSummary()` |
| 逐兽投入 | 名称/起止等级后优先显示节点数、已有/新增实物投入，研发度与全部资源保留在第二层 | `renderSchoolBeastPlan()` |
| 资料目录 | 七入口按机关兽/流派、材料/突破、等级/数值分组，原七区 ID、全部内容和返回导航不变 | `renderReference()` |
| 研发度资料 | 新增品质＋突破阶数速查，直接读取 `DATA.researchValues`；橙色展示原六个改造名称，蓝紫只展示资料实际存在的0改；缺失值显示“—”。完整桌面矩阵与窄屏分阶资料仍保留 | `researchReference()`、`updateResearchQuickLookup()` |

布局使用已有容器查询，考虑侧栏占用后的真实内容宽度；新增样式限制在 `#partition-machine-beasts`。没有新框架、浮动计算条、业务标签页或账号存储字段。

## 安全边界

- `data/*`、单兽核心、流派求解器、Worker/runner、账号/租约与存储实现相对基线无差异。
- 差异摘要只建立临时 Map/Set、读取返回结果，不修改 `plan`、`result` 或数组顺序。
- 实物数量只是汇总原材料列表中的 `count`，不替换原本体折算字段、不参与方案排序。
- 单兽最高效果调用原有只读 `CORE.activeBeastEffect()`；没有重写效果规则。
- 速查状态只放在既有 `presentation` 中，不写进个人进度、价格或库存。
- 未参与卡片内控件不删除，沿用原草稿与使用上限；研发度输入同步内外等级文本，不重绘输入。
- 保留正常计算取消、结果失效、中文搜索组合事件、历史恢复、只读账号规则。
- 测试为本地回环服务器和隔离浏览器账号；不读取或覆盖真实用户账号，不操作外部云端数据。
- 原有未提交 Excel、图片及导出目录未纳入本轮提交。

### 全量测试的例外与测试维护

原始 `npm test` 在未修改的 `js/inscription-route-favorites.test.js` 挂起；只结束明确定位的该测试子进程后，其余用例继续。独立60秒限时运行也在“write rejection, quota and read-only ownership…”等用例超时，本轮不更改铭文算法或断言。**不能宣称完整 npm test 全绿。**

发布版本更新期间运行中的旧全量进程出现版本快照不一致；版本固定后重新运行全部可完成文件：**1125 项全部通过，0失败**（明确排除上述单独记录的铭文收藏挂起文件，未删除或跳过其中断言来伪造完整通过）。

维护了两处既有测试入口，没有降低业务断言：

1. 原1.0.91真实渲染证实费用详情默认折叠；浏览器辅助函数先展开既有详情，再保留原金额、可见性及输入身份检查。
2. 原1.0.91已将机关兽样式从公共 `style.css` 抽到 `machine-beasts.css`；旧静态测试改为请求并检查实际专属资源，保留原布局断言及HTTP成功断言。

独立代码审查没有发现结果修改、重复事件或新增持久化写入；发现的“未参与卡外部等级不同步”已先通过新增测试复现，再修复并回归。

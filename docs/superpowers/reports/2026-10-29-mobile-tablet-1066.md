# 1.0.66 手机与平板适配及发布验收

## 范围

上次公开发布 `46ece3c`（1.0.65）以来的全部本地功能提交，重点覆盖铭文个人进度六品质、固定词条、合成查询/模拟、具体X、路径收藏、流程图、合阵搜索及新增神镜仙端木蓉。保留无关工作簿及未跟踪文件。

用户本次明确授权运行检查、测试并在通过后更新推送，覆盖项目默认“由用户验证”的约定。使用本机隔离测试账号及127.0.0.1，不操作真实游戏账号、不向同步生产接口发送请求。

## 发现与修正

- 1024px及1280px个人进度保存卡强制列宽导致副属性越界：改为可收缩网格，保留各品质条数。
- 320px失败结果按钮折为三行：手机独占整行，缩放按钮另行等宽；保留默认90%、一图到底及目标属性同一行。
- 手机/平板长图限制局部滚动区域高度，避免整个页面被长图拉长；SVG内容仍完整，可局部上下左右滚动。
- 合阵原生search重复触发相同关键词时替换结果DOM导致键盘焦点丢失：结果未变化时保留节点，清空时同步重置。
- Pages漏发布 `inscription-progress-rules.js`、`inscription-route-favorites.js`；SW漏5个新增资源：已补齐并新增4项资产合同。
- 修正上一批尚未执行测试中的多余右括号；铭文浏览器测试迁移至当前已确认界面，未恢复用户已删除的旧工作台功能。

## 验收环境及边界

Node v24.16.0、Playwright、headless Edge。视口含320/360/390/768/900/1024/1280/1440，以及844×390、1024×768横屏，启用触控模拟。另检查file直接打开、全局移动布局、真实Pages静态包、新装冷缓存和真实1.0.65升级。

这是浏览器设备/视口模拟，不是连接实体iOS/Android设备或真实Safari引擎验收。

Node实验Navigator Web Locks异常回调后不释放锁，用独立复现定位；unit进程临时关闭该实验接口，浏览器真实Web Locks仍保留并覆盖。测试进程临时增加Git安全目录，本机loopback经授权提权；未改全局配置。

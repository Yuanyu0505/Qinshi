# 可转换库存实施计划

**Goal:** 按已确认转换规则统一单只、流派及同等组合，验证后合并发布1.1.37。

**Spec:** docs/superpowers/specs/2026-11-18-machine-beast-convertible-stock-design.md

**Architecture:** 公用原形候选、0阶本体预算及结果来源分配；原阶候选有独立上限，加工候选共用总额度。搜索状态保留本体需求和资源消耗，费用仅对扣库存后的新增本体计算。旧保存格式和API默认路径兼容，界面统一启用转换模型。

## 重点边界

只允许同名本体转换；上限作用于原库存项；原阶改造与加工共享库存不能重复；高阶拆解可能留下0阶余量；混合库存/新增组成高阶时按本体数分别计账；同等方案重建不得绕过共享额度。禁止因状态简化删除真正最优候选。测试使用构造数据，不访问真实账号。

用户已确认方案并要求测试、合并、更新推送，本次可运行相关验证。此前单只库存优先本地修改随本次整合，尚未单独发布。

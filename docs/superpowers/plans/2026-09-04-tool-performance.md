# 全工具性能优化实施计划

> 执行方式：按 executing-plans 在本任务内逐项执行，不并行修改共享文件。

**目标：** 消除已复现的无效计算和重复渲染，交付换行与滚动待选清单。

**架构：** 保留原有查询和计算核心，只增加保守剪枝及可取消刷新队列；编辑使用现有委托事件局部更新。

**技术栈：** 原生 JavaScript、Node.js 测试、隔离 Edge 浏览器。

**设计：** `docs/superpowers/specs/2026-09-04-tool-performance-design.md`

## 全局约束

- 不修改换行、横向滚动布局、计算优先级或存储结构。
- 不读取真实个人进度，不提交用户原始资料，不发布或推送。
- 每项先新增会失败的行为测试，再实现，复测实际交互。

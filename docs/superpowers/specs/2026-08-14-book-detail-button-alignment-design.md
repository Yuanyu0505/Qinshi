# 典籍进阶详情按钮对齐设计

## 目标

- 将典籍品质栏下的默认按钮文字由“详情”改为“进阶详情”；展开后仍显示“收起”。
- 让按钮左边缘与最高阶累计属性的左边缘位于同一垂直基准线上。

## 方案

每个典籍品质单元继续使用两列结构：左列展示“10阶累计”或“15阶累计”，右列展示累计属性。按钮放在第二行、第二列，并左对齐，因此与右侧属性共享同一个水平起点。桌面表格和移动端卡片复用相同结构；移动端仅将右列设为可伸缩宽度。

气泡内容、展开与收起逻辑、典籍数据及排序逻辑均不改变。本次不更新 PWA。

## 验收重点

- 未展开时按钮显示“进阶详情”。
- 展开时按钮显示“收起”，关闭后恢复“进阶详情”。
- “进阶详情”按钮左边缘与累计属性文字左边缘对齐。
- 桌面表格与移动端卡片均保持上述对齐关系。

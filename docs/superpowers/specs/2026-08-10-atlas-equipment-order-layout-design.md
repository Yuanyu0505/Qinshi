# 图鉴装备排序与阶段布局设计

## 目标

改善图鉴升级结果的可读性：全局汇总按装备品质与名称排序；单张图鉴中每个升级阶段与其所需装备保持相邻。

## 排序规则

- 汇总装备先显示紫色装备，再显示橙色装备。
- 同一品质内，按装备中文名称的拼音字母序排序。
- 装备数量仅展示需求合计，不再影响排序。

## 布局规则

- 全局汇总的“所需装备”作为独立标题，下面显示连续的装备标签。
- 单张图鉴的“所需装备”作为独立标题。
- 每一个升级阶段和其对应的一个或多个装备标签组成不可拆分的行内组；空间不足时，整个组换行，避免阶段和装备分散。
- 不改变目标等级、材料统计、成长值或装备数据的计算方式。

## 影响范围

- `js/atlas.js`：只调整汇总装备列表的排序比较器。
- `js/app.js`：调整升级装备的 HTML 层级。
- `css/style.css`：为标题、阶段组和阶段内装备提供布局样式。
- `js/atlas.test.js`：增加排序规则的回归用例。

## 人工验收

- 设定一个含紫、橙装备的目标等级后，确认紫色全部位于橙色之前，且同色按名称拼音顺序排列。
- 在至少一个含 `5→6`、`7→8`、`9→10` 装备需求的图鉴卡片中，确认每个阶段紧邻其对应装备，并在窄窗口换行后仍不分离。

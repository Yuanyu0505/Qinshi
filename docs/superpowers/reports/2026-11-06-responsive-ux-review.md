# 全站响应式与交互审查

## 范围与方法

分支：`codex/responsive-audit-20261106`；基线：1.0.84。保留用户既有 Excel 修改及其他未跟踪文件。隔离 Edge 浏览器上下文仅连接本地测试服务器；同步使用现有模拟服务，不操作生产空间、真实账号或已有浏览器配置。

基础巡检覆盖 18 个分区：图鉴、橙装锻造、关卡掉落、装备属性、禁地、秘境、铭文、机关兽、机师、兵法、战匣丹囊、木人巷、合阵、六堂、楼兰棋阵、逐鹿、答题、设置。遍历可见二级模式，等待按需脚本初始化完成，记录控件与溢出几何、页面错误、代表截图。

视口：320×568、375×667、390×844、430×932、600×800（过渡宽度）、768×1024、820×1180、1024×1366、1024×768、1280×720、1366×768、1440×900、1920×1080、844×390（横屏）。基础状态不是全部数据组合；复杂场景由现有交互回归及新增用例补充。

## 发现与实施

| 实际使用问题 | 调整 | 保留的能力 |
| --- | --- | --- |
| 手机图鉴、装备筛选占据较长首屏，结果不容易进入视野 | 增加默认展开的手动收起/展开入口，保留同一组 DOM 和输入条件 | 不自动收起，不清空条件，桌面仍直接展示 |
| 小 PC、平板长侧栏中低位置分区需滚动查找 | 顶部增加 18 分区快速切换选择器（768–1366px），与现有分区状态联动 | 原侧栏和各入口不删除 |
| 兵法宽表在手机上需要跨列来回比较 | 手机默认逐阶卡片，当前/目标阶展开，其余可按需展开；一键切回完整表格 | 复制原表全部列与已格式化数值，不重新计算数据；桌面、平板保留对比表 |
| 平板兵法起点/终点纵向距离过大 | 起点、终点并排；内部表单按可用空间自动排布 | 所有字段与计算规则不变 |
| 短屏 PC 完整流程图过长，工具栏容易离开阅读位置 | 限定局部图面阅读高度，工具栏保持在阅读区域；原有缩放/总览/节点依赖仍保留 | 默认 90% 不改，不压缩节点字体，不改变合成逻辑 |
| 长页面反复返回顶部，小字说明与底部导航难读 | 手机长页面提供返回顶部，并将键盘焦点移到页面标题；窄屏说明字号/行高改善；底栏字号与间距配合 | 不持久化 UI 状态，不增加动画，遵守减少动态效果偏好 |
| 日期输入外观和触屏弹层可用空间不统一 | 日期输入暗色显示，公共弹层限制高度并允许内部滚动 | 保留同步手机全宽底部面板，不统一强制缩窄 |

实现集中在 `css/responsive-ux.css` 与 `js/responsive-ux.js`；兵法只增加展示层卡片及切换。没有新增依赖、存储键、数据迁移或游戏资料变更。新增资源已加入 service-worker 清单和 Pages 打包配置。最初交付未发布；用户随后明确要求「合并、更新、推送」，本次发布版本设为 1.0.85，发布结果另行记录。

## 迭代中实际捕获并修复的回归

1. 320px 卡片继承宽表真言碎片 `nowrap`，造成 14px 页面溢出：仅卡片中改为换行。
2. 公共弹层宽度限制使手机同步底部面板缩窄：撤回宽度限制，保留高度限制，复测全宽贴底约束。
3. 起终点并排后内部固定四列溢出：内部改为按可用宽度 auto-fit，不压缩输入。
4. 原表格单行测试读取到了新增的隐藏卡片副本：测试改为显式切换完整表格并只检查原表单行要求。
5. 服务测试沿用上一版禁地「全部同装备系列」旧文案：同步实际已有的「本期及之后每一期」断言。未改变禁地业务代码。

## 边界与后续

未声称已验证真实 iPhone/iPad/Android 硬件、系统键盘、Safari/WebKit 渲染或真实浏览器系统级缩放；本次使用 Edge 多视口、横屏及触控模拟。也没有穷举所有库存/账号数据和每一种异常组合。

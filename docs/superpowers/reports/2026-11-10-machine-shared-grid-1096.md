# 主/其他组合共用网格与资料列对齐（1.0.96）

本次仅调整UI模板与机关兽专属CSS，不修改计算核心、同等方案求解/计数、费用、资料数值或存储。

## 三处调整

1. 主材料与其他组合共同位于`machine-cultivation-layout`尺寸容器下。根据该公共容器宽度统一决定1/2/3列（728px两列、1096px三列），不再分别auto-fit导致主组合三列、其他组合两列。移除其他组合折叠区额外左右边框和内缩，令各卡片外边、内部列基准一致。保留折叠与分页功能。
2. 卡片内部摘要固定等分三列；研发度与资源使用相同的三轨比例和4px列间距。资源右侧字段跨后两轨，与“增加”起点一致；保留原四行资源subgrid。长文本只局部滚动/换行，不隐藏数值。
3. 三种品质桌面研发度表使用同一七列colgroup：首列84px，其余六列均分。蓝紫内容放前两列，对应橙色的阶数和0改；后五列明确保留空表头/单元格，沿用原表格背景和横向分隔线，不伪造资料或数值。紫色在上蓝色在下、不合并表格，小屏分阶卡片不变。

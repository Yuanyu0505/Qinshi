# 铭文词条统一显示

用户已确认：统一为“数值＋单位＋属性名（档位）”，例如 4速（高档）、4%技能穿透（高档）。真正不分档写（不分档）；蓝二速度的不可辨档仍写（档位不可辨），两者不能合并内部含义。保留所有系统原生选择控件，仅统一其纯文本；其他显示中的数值＋属性名按铭文品质着色并加粗，括号为普通字重。

采用共享展示模块，提供纯文本、HTML、SVG 所需的结构化描述，而非修改规则标签/签名或存档。蓝一/二蓝色、紫一/二紫色、橙一/二橙色；SVG 白底采用同色系的深色，提高可读性。属性名称沿用规则规范名，速/PVP速不写成速度/PVP速度。

范围：个人进度、编辑预览、已保存铭文查询、属性数值表、最优及替代组合、材料下拉、模拟结果、SVG 路线及失败品复用。主属性无高/中/低档，不新增档位，仅统一数值在前及品质色。无数值的属性筛选仍保持属性名。

历史记录仅在显示时根据原品质/遁位/属性/数值匹配合法档位；无法确定的旧文本保留原文并沿用警告，不伪造档位，不写回原数据。原生编辑数值输入及下拉 option value 仍保留原有数据格式。

不改数值、合成概率、签名、规则、存档、筛选和模拟行为。按项目约定不运行测试/构建/lint/实机验收。本次只确认了显示修改，未新请求发布，因此不主动推送或升级 PWA；后续发布可统一升版本。

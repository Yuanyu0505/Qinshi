# 铭文流程图连线与缩放

- 来源框采用易区分的深色连线，同来源箭头与线同色；同层循环使用八色，不以颜色替代箭头、投料数量及节点文字。
- 横向汇入通道在节点下方 40–52px 错开，减少不同来源连线完全重叠，保留数量标签的独立空间。
- 不再将各层分别整体居中。按前级材料的位置放置下级操作，单链优先保持中心对齐，节点碰撞时才向右避让。
- 多材料合成选实际材料为主干，不将晋升材料位置混入平均值；晋升材料排在配方材料右侧。汇入端口依来源左右顺序排列，减少反向穿插。
- 默认与重置比例统一为 90%，保留缩小、放大、完整连续图、词条单行和颜色。

仅修改展示，不改规则、概率、配方、账户数据。不保证任意复杂图完全没有交叉。按项目约定不执行测试、构建、lint 或实机验收；由用户重点查看单链直连、多材料汇入、复杂复用图的交叉与默认/重置缩放。仅合并本地，不更新 PWA、不推送。

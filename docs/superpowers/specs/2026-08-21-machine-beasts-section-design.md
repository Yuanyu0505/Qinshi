# 机关兽分区设计

## 目标

新增“机关兽”分区，为机关兽研发提供个人进度保存、最优投入方案计算和完整资料查阅，并同时适配桌面、手机和平板。实现完成后更新 PWA 版本、合并到本地 `master` 并推送 GitHub。

## 数据来源与口径

- `图片表格转换.xlsx` 的“研发数据”工作表提供蓝色、紫色、橙色机关兽各阶研发度、橙色改造研发度、1–25 级累计研发度门槛和材料换算。
- `秦时相关（更新贯侯钟离昧）20260618.xlsx` 的“机关觉醒”工作表 `B1:K32` 提供机关兽完整名称、所属流派、10/15/20/25 级效果，以及霸道机关术、非攻机关术 1–5 阶的三项效果。
- “机关觉醒”完整名单优先于研发表中的简称。`机关炎傀`、`机关岳獠` 均为橙五，研发上限 25 级，不能用贡献兑换机关兽碎片。
- 研发材料统一命名为“觉醒神图”和“机关破片”；机关兽本体进阶与兑换使用“机关兽碎片”。
- 机关兽效果取当前已达到的最高有效研发档位，不累计低档效果。

## 分区与导航

全局分区顺序调整为：

`图鉴 → 橙装锻造 → 关卡掉落 → 装备属性 → 铭文 → 机关兽 → 兵法 → 合阵 → 楼兰棋阵 → 答题`

“设置”继续保留在现有“更多”入口中。

机关兽分区内部顺序：

1. 个人进度（默认）
2. 方案计算
3. 资料图表

## 个人进度

### 流派汇总

个人进度按“霸道机关术”和“非攻机关术”分组。每组顶部展示：

- 当前流派累计觉醒等级；
- 1 阶进度：当前值/45、还差多少；
- 达到 45 后显示“1阶已达成”；
- 2–5 阶仅升阶等级要求显示“数据待补充”；
- 当前已达成阶数的流派加成、阵容特效、机关兽特效；
- 下一阶的流派加成、阵容特效、机关兽特效。

1 阶升阶要求为累计觉醒等级 45；2–5 阶的三项效果已有数据，必须正常展示，只有升阶等级要求暂无数据。未达到 1 阶时，下一阶预览显示 1 阶要求与三项效果；达到 1 阶后，下一阶预览显示 2 阶三项效果，并把升阶要求标记为“数据待补充”。达到 5 阶后显示“已达到当前最高阶”。

流派累计觉醒等级为该流派全部机关兽当前研发等级之和，未培养机关兽按 0 级计。

### 机关兽卡片

每张机关兽卡片展示：

- 完整名称、品质和档次；
- 当前研发等级、累计研发度、研发等级上限；
- 当前已生效的最高档机关兽效果；
- 现有库存摘要；
- 编辑按钮。

编辑状态保存：

- 当前累计研发度；
- 0–7 阶、0 改的现有机关兽数量；
- “显示8–10阶库存”开关及 8–10 阶库存；
- “显示改造库存”开关及初改、天改、仙改、圣改、满神改库存；
- 当前机关兽碎片数量。

累计研发度是主数据，当前研发等级由累计研发度门槛自动推导；提供“按等级最低研发度填入”辅助操作。所有库存和碎片数量均为非负整数。

个人进度使用新键 `qinshi_machine_beasts_progress_v1` 保存。现有备份模块会自动包含 `qinshi_` 前缀数据，同时把新增脚本加入 PWA 预缓存和 GitHub Pages 发布清单。

## 方案计算

### 计算入口

- 选择具体机关兽后自动读取该机关兽个人进度；
- 当前等级由累计研发度自动推导；
- 默认目标为当前等级之后最近的有效效果档位：10、15、20、25，并受该机关兽研发上限约束；
- 允许手动选择任意不低于当前等级且不超过研发上限的目标等级；
- 可临时调整读取到的库存，计算后可选择保存回个人进度。

### 候选范围

默认只使用 0–7 阶、0 改机关兽生成方案，只展示一套最优方案。

- 开启“显示8–10阶库存”后，可输入已有 8–10 阶库存；显示时统一折算为 7 阶本体等价数量，但研发度和研发材料按实际最终阶数计算。
- 7→8 阶需要 2 个 7 阶本体等价，8→9 阶需要 4 个，9→10 阶需要 8 个。
- 开启“显示改造库存”后，可输入已有初改、天改、仙改、圣改、满神改机关兽；已有改造机关兽按表格实际研发度参与候选，但系统新增缺口只推荐 0–7 阶、0 改机关兽，不推荐额外改造。
- 现有库存不是强制全部投入；计算器只选最优方案需要的部分，并列出未使用库存。

### 最优顺序

候选方案使用稳定、精确的组合优化，依次比较：

1. 投入研发的机关兽总只数最少；
2. 研发度溢出最少；
3. 新增机关兽本体/机关兽碎片缺口最少；
4. 贡献与元宝消耗最少；
5. 觉醒神图消耗最少；
6. 机关破片消耗最少。

完全相同时使用固定的阶数降序和数据表顺序作为稳定排序，不重复展示等价方案。

### 材料与兑换

- 每只最终投入的机关兽分别计算 `ceil(研发度 / 500)` 个觉醒神图；
- 每只最终投入的机关兽分别计算 `ceil(研发度 / 100)` 个机关破片；
- 蓝色 1 本体=10 机关兽碎片；紫色 1 本体=20 机关兽碎片；橙色 1 本体=40 机关兽碎片；
- 橙一、橙二每碎片 600 贡献；橙三 800；橙四 1000；
- 1 贡献=0.5 元宝，贡献和元宝结果向上取整、不保留小数；
- 蓝色、紫色、橙五只计算本体与机关兽碎片缺口，明确显示“不可通过贡献兑换”。

### 结果

计算后结果置于计算页最上方，展示：

- 当前等级、累计研发度、目标等级及目标累计研发度；
- 仍缺研发度；
- 最优投入组合，区分已有库存和新增缺口；
- 投入机关兽总只数、总投入研发度、溢出研发度；
- 觉醒神图与机关破片消耗；
- 本体等价、机关兽碎片缺口、贡献和元宝；
- 计算后预计等级；
- 未使用库存。

## 资料图表

1. 研发等级表：1–25 级累计研发度，突出 10/15/20/25 有效档位。
2. 研发度表：蓝色 0–2 阶、紫色 0–6 阶、橙色 0–10 阶及全部改造状态研发度。
3. 机关兽归属与效果表：完整名称、流派、品质档次、研发上限、10/15/20/25 级效果。
4. 流派阶数表：1–5 阶的升阶要求和三项效果；1 阶要求为 45，2–5 阶要求显示“数据待补充”，效果完整展示。

## 响应式与可用性

- 桌面端使用流派汇总卡、机关兽卡片和资料表格；
- 手机和平板使用单列卡片，编辑表单自动换行，不依赖页面级横向滚动；
- 宽资料表仅在自己的滚动容器内横向滚动，移动端冻结首列；
- 按钮与输入框满足触控尺寸，长效果文本自动换行；
- 编辑态与只读态分离，保存后恢复卡片展示；
- 非负整数校验、超上限校验和本地保存失败均显示明确错误。

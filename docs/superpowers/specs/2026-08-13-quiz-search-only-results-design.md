# 答题区仅搜索时展示结果设计

## 目标

答题分区默认不展示完整题库，只有输入有效关键词后才展示匹配题目和正确答案。

## 行为

- 首次进入答题分区时，结果区域隐藏且不渲染题目。
- 搜索框为空或只包含空格时，结果区域隐藏并清空。
- 输入有效关键词后显示匹配结果。
- 有效关键词无匹配时显示“未找到匹配的题目”。
- 清空关键词后立即恢复默认空白状态。
- 网页、手机和平板行为一致。

## 实现边界

`js/quiz.js` 提供统一的有效查询判断；`js/app.js` 在调用题库搜索前据此隐藏或显示结果容器。不修改题库数据、匹配算法、答案内容或存储格式。

## 回归场景

- 空字符串和纯空格不展示任何题目或无结果提示。
- 有效关键词展示匹配题目。
- 无匹配关键词显示无结果提示。
- 清空搜索框后所有结果消失。

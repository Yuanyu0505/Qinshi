# 铭文配料说明、编辑权恢复与卡片布局

用户要求直接实施并合并、更新 PWA、推送 GitHub。按当前 AGENTS.md 不主动运行测试、构建、lint 或实机验收，补充回归用例供用户运行；不声称验证通过。

## 方案与边界

- 流程图统一增加词条行之后的上下留白，字体大小不变，节点高度同步扩展，避免分隔线压住备料与下一步说明。
- 对非实录主线的三枚互补配方，比较两种材料的所有正整数配比。仅在规则引擎给出的完整结果池及概率均相同时，标注两种材料合计三枚、各至少一枚；保留具体配比明细。实际记录仍显示真实投料，不被改写成可互换说明。
- 不改合成规则、不重建收藏 ID、不修改材料库存。备料总数保留为主树示例配比，并明确不是互换配比的固定需求。
- 相比只修改“2+1”的文案，按规则比较能排除词条不足随机补充、档位不可辨等不等价情形；相比重写规划树或增设配料编辑器，影响范围更小。
- “存储拒绝写入”的 false 返回来自账号编辑租约。租约过期时原 renew 先要求 canWrite（含未过期）导致休眠后无法恢复。仅允许原标签页、原 token 的过期租约安全续期，不自动抢占其他标签页。BFCache 只恢复本页在 persisted pagehide 实际释放的租约；任何不同 token 即使过期也不自动接管。pageshow 及写入前核对持久注册表与 session 账号，失效上下文停止写入并提示重新加载。铭文写入失败区分只读与真正存储异常，保留存档乐观并发保护。
- 所有模拟材料卡使用同一上方操作栏：来源/当前占用说明在左，清空在右，移动端可换行；手填材料也使用这一位置。

## 建议用户验收

1. 鬼/龙遁互补两种紫一的 2+1 与 1+2 配方说明、实际概率；实录路线仍为实际配比。
2. 页面闲置/休眠超过五分钟，回到路径及模拟修改筛选；两个标签页接管后旧页面仍只读。
3. 返回缓存页面后的保存、真实存储拒绝时原数据不被误报保存、账号切换不串数据。
4. 手机、平板、桌面下提示留白和清空按钮位置，禁用状态及选材/背包占用不变。

# 关卡掉落展示与橙装锻造资料包 Implementation Plan

**Goal:** 同物品的碎片/本体及明确简称共用一张掉落卡，省略空来源；导出完整橙装锻造评审资料。
**Architecture:** 新增纯展示分组接口，旧findDrops/groupDrops保持兼容；展示保留原条目名、形态及原导航身份。锻造仅导出，不修改功能。
**Tech Stack:** 原生JS/CSS、Node只读资料导出、Markdown/HTML/JSON、ZIP。

## Constraints

- 基线1.1.15；不修改data/drops.js、游戏资料、锻造公式、账号或个人进度。
- 仅末尾“碎片”以及明确的醉梦/升雪/星云简称映射；不使用任意模糊字符串合并不同物品（魍魉和双剑魍魉不猜测合并）。
- 用户授权完成后合并更新推送；遵循AGENTS不主动运行测试/lint/浏览器，补充用例但不声称通过。
- 导出仅源码与公共数据，不能包含用户Excel、备份、个人存储、云同步配置或凭证。示意图明确不是真实截图。

## Tasks

- [ ] 检查查询/展示/导航，新增groupRelatedDrops与回归用例；省略空来源，保留碎片/本体或原名区别。
- [ ] 导出锻造查询/素材反查/总览/个人进度各分区、源码、实际有效增量数据、代码行号、布局示意及GPT指令；打包。
- [ ] 只读审查，版本1.1.16，限定提交本轮文件；合并master推送main并读取Pages结果。

## Review Focus

精确本体名或碎片名均能找回同组全部来源；不吞掉原位置/重复记录；昵称映射不变更原表；零来源不渲染；导航使用原名/规范名而非形态词；锻造导出包含九月/十月/十一月增量且不读取个人数据。

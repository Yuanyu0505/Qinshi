# 铭文模拟和机师资料精简（1.0.77）

## 要求及实现选择

- 用户最新补充要求主动运行本次修改的完整测试，一遍全部无误后才合并 master、更新 PWA 并推送；本次覆盖 AGENTS.md 的默认约定。先回归用例 RED/GREEN，再完整单元和浏览器回归。
- 洗练素材属于真实投料，连线显示实际数量（如该铭文×1）；晋升材料卡上已写数量，不重复标注。
- 已确认的背包材料卡在卡头下方可用空间内垂直居中。当前投料区右上新增清空全部材料（确认后仅清空本次所有槽位、保留阶段，不删除背包或历史），pending/legacy 状态禁用，沿用单槽保护。
- 库存不足根因：同款分组增加库存时创建独立手动批次，旧材料引用仍可能指向耗尽批次。只对失效的旧引用，在完全相同的前缀/遁位/品质/词条分组中重新分配可用批次；先保留仍有效的引用，不填未选择槽、不变更库存数量，不伪造来源。读取旧现场和相关库存操作均采用同一修复逻辑；确实不足仍提示。
- 实录图显示投影合并同款、同来源类型且制作配方/已观察结果相同的节点；展示边数量，保留实际 records、sourceKeys、需求和概率。不合并制作过程不同的材料，也不把实录改成假想概率分支。相比改写存档，投影合并影响更小且保留全部追溯。
- 机师初始“全部、无搜索”不渲染结果和计数；有分类、阶数、类别或关键词后渲染。返回全部并清空搜索再次隐藏。
- 移除页眉小标题、效果项下的“条件/语境”和“来源”附加行；保留实际效果正文中的必需条件。分类按钮采用全站 seg/active 风格；各机师类别按钮下方显示生效条件。四类身份标签不同底色。
- 仅删除指定的英布误印说明和龙且来源差异说明，不类推删除典庆、田赐等其他资料备注。技能进化、不同命名时装作为正文独立段落并保留文字。底部只保留“机师时装图名称”和9个名称，删除其他展示及备注；原资料出处元数据留作内部追溯，不显示。

## 用户验收重点

旧批次耗尽后增加同款库存、同款多个来源的实际追溯、真正库存不足、清空确认取消/确认、pending禁用、手机/平板材料卡居中与按钮布局、初始无结果与筛选出现结果、机师类别说明与不同底色、指定备注的精确删除。

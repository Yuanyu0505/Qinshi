# 战匣丹囊分区设计

## 目标

新增“战匣丹囊”主分区，为每位弟子分别保存战匣、丹囊进度及槽位品质，按玩家等级和槽位品质共同计算强化上限，并支持多弟子目标计算、账号共用库存分配、购买补足和完整资料查阅。分区需适配电脑、平板和手机，并在完成后更新渐进式网页应用、合并到本地 `master`、推送 GitHub。

## 数据来源与口径

- `秦时相关（更新贯侯钟离昧）20260618.xlsx` 的“战匣丹囊”工作表提供战匣、丹囊等级属性及材料需求。
- 材料列是从上一等级升级到该等级的单级消耗，不是累计消耗。例如战匣 51 级的沧海珠 217，表示 50 级升至 51 级需要 217 个沧海珠。
- 从当前等级 `L` 升到目标等级 `T`，累计 `L+1` 至 `T` 各行的沧海珠和玄龟甲。
- 战匣属性与等级一一对应。战匣 51 级的攻击、防御、血量分别为 49409、49409、395276。
- 丹囊属性与等级一一对应，以基础属性加成比例表示。
- 0 级属性和消耗均按 0 处理。
- 战匣 61 级血量采用已确认修正值 557660。

## 分区与导航

- 新增主分区“战匣丹囊”，位置在“兵法”之后、“合阵”之前。
- 分区内部包含三个子分区：个人进度、目标计算、资料图表。
- 默认进入个人进度。
- 不改变图鉴、装备属性、橙装锻造及其他现有分区的搜索、筛选和保存规则。

## 数据归属

### 账号共用数据

- 玩家等级；
- 沧海珠库存；
- 玄龟甲库存；
- 沧海珠每包数量和每包价格；
- 玄龟甲每包数量和每包价格；
- 最近使用的弟子优先顺序；
- 同一弟子内部的战匣、丹囊优先设置。

默认购买参数：

- 沧海珠每包 5 个，每包 20 元宝；
- 玄龟甲每包 10 个，每包 300 元宝；
- 每包数量和价格都允许手动修改；
- 包数向上取整。

### 弟子独立数据

每位弟子保存：

- 弟子稳定标识、名称和来源；
- 图鉴弟子保存图鉴关联标识，自由新增弟子不关联图鉴；
- 当前战匣等级；
- 当前丹囊等级；
- 武器、防具、饰品、典籍四个战匣槽位；
- 每个战匣槽位的装备名称、装备来源和品质；
- 八个丹囊槽位的空置状态和内丹品质；
- 最近使用的战匣、丹囊目标等级。

## 弟子添加规则

1. 输入名称时搜索现有 177 人图鉴弟子库。
2. 选择结果后建立关联图鉴的弟子档案。
3. 没有搜索结果时允许按当前名称自由新增。
4. 自由新增弟子只存在于战匣丹囊分区，不写入或反向关联图鉴。
5. 同一个图鉴弟子不能重复添加；完全同名的自由弟子也不能重复添加。
6. 新建弟子的战匣、丹囊当前等级均为 0 级。

## 战匣规则

### 槽位

- 固定四个槽位：武器、防具、饰品、典籍。
- 装备名称优先搜索现有装备属性库，找不到时允许自由输入。
- 装备库结果必须与槽位类型匹配；自由输入装备的类型由用户自行确认。
- 槽位允许为空。
- 放入装备时品质默认橙色，可手动修改。
- 不计算装备缘分效果，装备名称和品质仅用于档案记录及战匣上限计算。

### 品质增加上限

| 品质 | 增加上限 |
| --- | ---: |
| 绿色 | 2 |
| 蓝色 | 3 |
| 紫色 | 5 |
| 橙色 | 8 |
| 橙金 | 12 |
| 红色 | 15 |
| 红金 | 20 |

战匣物品上限为 `10 + 四个已放入装备的品质增量总和`。

### 玩家等级上限

| 玩家等级 | 战匣上限 |
| --- | ---: |
| 0–45 | 未解锁 |
| 46–53 | 70 |
| 54 及以上 | 90 |

## 丹囊规则

### 槽位

- 固定八个内丹槽位。
- 每个槽位只保存空置状态或内丹品质，不保存内丹名称和数字等级。
- 槽位允许为空。
- 放入内丹时品质默认橙色，可手动修改。

### 品质增加上限

| 品质 | 增加上限 |
| --- | ---: |
| 绿色 | 1 |
| 蓝色 | 2 |
| 紫色 | 3 |
| 橙色 | 4 |
| 天级 | 5 |
| 仙级 | 6 |
| 圣级 | 8 |
| 神级 | 10 |

丹囊物品上限为 `10 + 八个已放入内丹的品质增量总和`。

### 玩家等级上限

| 玩家等级 | 丹囊上限 |
| --- | ---: |
| 0–45 | 未解锁 |
| 46–56 | 40 |
| 57–59 | 50 |
| 60–66 | 60 |
| 67–73 | 70 |
| 74–79 | 80 |
| 80 及以上 | 90 |

## 槽位解锁临时规则

- 参考资料只说明槽位按玩家等级依次解锁，暂时没有准确的逐槽解锁等级。
- 当前版本不臆造逐槽阈值：玩家达到 46 级后，战匣四槽和丹囊八槽全部允许填写；低于 46 级时模块锁定。
- 资料图表中明确显示“槽位分级解锁规则待准确数据补充”。
- 保存结构保留版本号，后续获得准确阈值后可以平滑加入逐槽限制。

## 实际等级上限与超限处理

- 战匣实际等级上限为战匣玩家等级上限与战匣物品上限中的较小值。
- 丹囊实际等级上限为丹囊玩家等级上限与丹囊物品上限中的较小值。
- 玩家低于 46 级时，对应模块未解锁，不能执行升级计算。
- 改变玩家等级、槽位内容或品质后立即重新计算实际等级上限。
- 若当前等级超过新的实际等级上限，不自动降低或清除进度；保留原值、显示醒目警告并禁止继续升级。
- 玩家等级恢复或槽位品质补足后，超限状态自动解除。

## 个人进度

### 账号区域

顶部显示玩家等级、沧海珠库存、玄龟甲库存。账号数据自动保存，所有数字输入框只允许手动填写。

### 弟子卡片

每张卡片显示：

- 弟子名称与来源；
- 战匣当前等级、实际等级上限、超限或未解锁状态；
- 丹囊当前等级、实际等级上限、超限或未解锁状态；
- 编辑、加入计算、删除操作。

### 编辑详情

- 战匣四个槽位与丹囊八个槽位分区显示；
- 实时显示每个槽位增加上限、物品合计上限、玩家等级上限和最终实际等级上限；
- 当前等级只能手动填写非负整数；
- 修改只在点击“保存”后写入；
- “取消”放弃本次修改；
- 有未保存内容时退出需提示是否放弃；
- 删除弟子档案需二次确认。

## 目标计算

### 选择与目标

- 可选择一位或多位已保存弟子；
- 每位弟子分别设置战匣目标等级和丹囊目标等级；
- 战匣、丹囊可独立选择是否参与本次计算；
- 提供“一键全部设为各自实际等级上限”；
- 目标不得低于当前等级或高于实际等级上限；
- 超限项目不能继续向上计算。

### 库存分配

- 先按用户排列的弟子优先级分配账号共用库存；
- 同一弟子内部再按用户选择的“战匣优先”或“丹囊优先”分配；
- 对每个项目逐级检查两种材料是否同时足够，只有两种材料都满足才升级该级；
- 显示每个项目用现有库存可达到的等级以及首次不足的位置；
- 购买补足始终按所有已选弟子的完整目标计算，不受分配优先级影响。

### 结果

总览显示：

- 两种材料的总需求；
- 现有库存；
- 实际分配消耗；
- 剩余数量；
- 完整目标缺口；
- 购买包数、购买后剩余和元宝消耗。

每位弟子分别显示：

- 战匣与丹囊的当前等级、目标等级、用现有库存可达等级；
- 对应材料需求和实际分配数量；
- 战匣攻击、防御、血量、玩家对战免伤提升；
- 丹囊基础属性加成比例提升。

不同弟子的属性不相加，材料需求和缺口按账号汇总。

## 资料图表

资料图表包含：

1. 战匣等级表；
2. 丹囊等级表；
3. 玩家等级上限表；
4. 战匣装备品质增加上限表；
5. 丹囊内丹品质增加上限表；
6. 槽位解锁临时规则说明。

战匣、丹囊等级表支持：

- 当前附近；
- 关键节点；
- 全部等级。

可以选择一位已保存弟子作为参照：当前等级绿色、目标等级红色、实际等级上限金色、超限状态显示警告。不选择弟子时展示通用数据。

材料表头必须写明“上一等级升至本等级所需”。战匣表显示等级、攻击、防御、血量、玩家对战免伤、沧海珠、玄龟甲；丹囊表显示等级、基础属性加成比例、沧海珠、玄龟甲。

## 输入校验与保存

- 玩家等级、库存、当前等级、目标等级、每包数量和价格均为非负整数；每包数量必须大于 0。
- 数字输入框不显示上下按钮，不响应鼠标滚轮或触摸滑动加减。
- 名称去除首尾空格，空名称不能保存。
- 保存键使用 `qinshi_battle_box_pill_pouch_v1`，内容带内部版本号。
- 现有备份与恢复模块应包含该保存键。
- 页面刷新、离线打开和渐进式网页应用更新不得清除个人进度。
- 数据缺失或格式错误时按安全默认值归一化，并显示可理解的提示，不中断其他分区。

## 响应式与可用性

### 手机

- 单列弟子卡片；
- 编辑详情使用整页或接近整页的弹出层；
- 战匣四槽纵向排列；
- 丹囊八槽每行两个；
- 计算结果先总览后弟子明细；
- 资料数据使用等级卡片，不强制显示宽表格；
- 子分区导航固定在内容顶部并允许横向滚动。

### 平板

- 弟子卡片每行两个；
- 编辑详情左右分栏，战匣与丹囊各占一侧；
- 目标设置与结果可上下分区或左右分栏；
- 资料表格固定等级列并在自身容器内横向滚动。

### 通用交互

- 品质使用与装备属性一致的底色体系；
- 橙金、红金必须具有明显的金色高亮，与普通橙色、红色清楚区分；
- 空槽、已放入、未解锁、超限、材料不足等状态同时使用文字，不只依赖颜色；
- 所有主要操作满足触控点击范围；
- 弟子优先级支持拖动调整，并提供上移、下移按钮。

## 模块边界

- 静态等级与品质规则独立存放；
- 进度归一化、上限计算、材料累计、库存分配、属性差值和购买补足使用纯计算模块；
- 页面渲染、搜索、表单编辑、本地保存和响应式交互放在独立界面模块；
- 只复用图鉴弟子数据和装备属性数据，不修改它们的原始结构；
- 不计算装备缘分，不扩展内丹名称库，不臆造槽位逐级解锁数据。

## 验证范围

- 表格数据完整性、战匣 61 级修正值和 51 级示例；
- 玩家等级上限边界；
- 两套品质增加上限；
- 空槽、满槽和混合品质的实际上限；
- 降低品质或玩家等级后的保留进度与超限状态；
- 单级及跨多级材料累计；
- 多弟子、双分区、不同优先级的库存分配；
- 完整目标缺口与购买包数向上取整；
- 图鉴弟子搜索、自由弟子添加和重复拦截；
- 装备库搜索、类型限制和自由输入；
- 保存、刷新、备份恢复和离线加载；
- 手机、平板和电脑布局不产生页面级横向溢出。

## 渐进式网页应用与发布

- 渐进式网页应用版本由 `1.0.25` 更新为 `1.0.26`；
- 新增数据、计算和界面脚本加入预缓存及发布清单；
- 保留现有安装、离线和更新提示；
- 完成后合并到本地 `master`；
- 合并过程中保留工作区中用户未提交的工作簿、图片和其他个人文件；
- 推送到 GitHub，使线上页面和渐进式网页应用获得新版本。

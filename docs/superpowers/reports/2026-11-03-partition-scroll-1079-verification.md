# 1.0.79 分区切换防跳动验证

## 问题与修改

用户确认“闪屏”指内容突然上下跳动，而非白屏。修改范围限于通用分区导航、加载提示和移动菜单焦点：

- 分区显示及同步渲染后立即定位，取消下一帧才滚动的回调，避免新分区暂时沿用旧位置以及旧回调拉回后续滚动。
- 分区加载提示改为悬浮状态栏，不改变旧分区的文档高度；加载失败及重试提示保留。
- 移动菜单的延迟聚焦使用代次标识，关闭后取消旧聚焦；恢复原控件焦点时使用 preventScroll，兼顾键盘访问与防跳动。
- PWA 版本及 HTML 资源、懒加载脚本版本统一为 1.0.79。

## 旧版对照与修复回归

只读拦截旧版 fe2c67e 的 app.js/style.css，不替换工作区文件。新增三项断言在旧版均按预期失败：

1. 点击新分区后立即读取位置，仍为 900，而不是 0。
2. 新分区中滚动到 500 后，旧回调又将位置拉回 0。
3. 加载提示使测试文档高度由 3784 增至 3849，增加 65px。

修复版切换专项 18/18 通过，含浏览器前进/后退、快速切换、懒加载失败重试和菜单焦点。另在 768、1440 视口复用四项滚动/高度回归，各 4/4 通过。

合并前只读审查发现菜单选项选择后可能丢失可见焦点。新增真实键盘回归先复现失败，再保留 preventScroll 的焦点恢复，最终专项全部通过。

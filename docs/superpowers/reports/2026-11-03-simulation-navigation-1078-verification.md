# 1.0.78 验证记录

## 修改范围

- 重复当前阶段直接完成新一批合成；默认自动加入虚拟背包，可按账号关闭。开启时隐藏单独入包按钮；重新模拟替换当前结果，不累加消耗或产物。
- 结果后允许换料、清空或重新选择背包材料，保留之前的产物与来源历史。库存不足时事务整体回滚，不补造材料。
- 机师一级、二级筛选紧邻排列，搜索在其后，三行解释统一放到搜索下方；效果标题、行距与文字层次调整，不改资料内容。
- 合成子页只刷新当前视图，无变化切换保留 DOM；账户、存储、收藏及旧档变化正确失效。铭文查询采用可取消四卡分批渲染，排序复用中文 Collator。
- PWA 版本、预缓存、分区资源版本统一为 1.0.78。

## 性能检查

实测首轮查询同步构建约 57 万字符 HTML；合成子页切换重复刷新隐藏视图。优化改为有限批次与视图缓存，没有省略账号只读保护或安全通知。

本地 Edge、CPU 4 倍节流、390/768 视口下，四卡分批首次响应约 51–97 ms；全部 103 张卡完成约 2.07–2.58 秒，期间允许事件循环继续工作。旧同步对照在负载测试中首次响应约 556–695 ms。分批优化的是阻塞与响应性，不宣称总渲染耗时下降；仍存在少量 50 ms 以上任务，数据受宿主负载影响。

同一排序数据对照结果一致：逐次字符串本地化比较约 90–125 ms，复用 Collator 约 0.9–5.4 ms。

这是桌面浏览器响应式视口和节流验证，不是实体 iPhone/Android 平板验收；不承诺消除网络或设备负载导致的所有延迟。项目为静态站点，没有独立构建脚本，发布资产由单元、浏览器和 PWA 安装升级测试覆盖。

# 机师资料与铭文工作台修复设计

## 已确认范围
- 独立机师分区：全部／非机师／机师。按弟子身份归类；任一机师身份者全部资料归机师；允许多机师类别。
- 四张资料全部纳入：机师总表、神将突破第1／2／3篇。非机师筛15／20／25阶，机师筛背包／神将25阶／传统；支持名字、条件、效果关键词。
- 新增机关兽7—10阶突破参考表，不改变计算规则。
- 路径与模拟分别保存筛选，账号隔离；旧档不得阻塞查询。异常处理由用户选保留隔离或清空全部模拟（现场、历史、背包），清空二次确认，其他资料不动。
- 背包同天位、遁位、品质、词条合并展示，保留内部来源。多选数量总和受剩余材料空位限制，只填空位。
- 全部路线按配方相邻备料、分清合成批次、压缩多余空白；说明字体恢复放大前大小。
- 手机、平板适配；用户本次明确授权主动完整测试，覆盖旧档、账号隔离、背包、筛选、路线及新增资料。通过后合并本地master、更新PWA并推送远程main。

## 架构与取舍
选择独立筛选存储与共享规则引擎，而非继续让查询目标驱动模拟状态。查询只依赖合法目标，不依赖模拟有效性。模拟保留已有来源链和撤销机制，展示分组不破坏真实批次。
机师采用静态结构化数据＋懒加载查询页，沿用原站分区导航。资料不参与战斗计算，不凭空补充图片未提供的属性；同名普通／神弟子分开。
旧档保留原始快照，可只读查看；恢复安全字段后新建可操作现场。全清空只影响模拟，收藏和真实铭文进度保持原样。
贡献折算、铭文合成规则、抽数算法均不在本次调整范围。

## 数据与安全
无新外部服务或费用。迁移必须可恢复；不触碰用户工作簿和其他未提交文件；测试仅使用隔离测试账号／存储，不操作真实玩家数据。

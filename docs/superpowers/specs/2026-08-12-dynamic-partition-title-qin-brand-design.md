# 动态分区标题与 Qin 名称统一设计

## 目标

所有设备统一使用当前分区名作为页面唯一可见标题和浏览器标签标题，删除分区内部的重复标题；同时将安装、提示、设置、备份和文档中的工具名称统一为 `Qin`。

## 一、页面标题

- 页面顶部只保留一个标题元素，内容始终为当前选择的分区名。
- 初次打开默认分区为“图鉴”，页面顶部和浏览器标签均显示“图鉴”。
- 分区名称固定为：
  - 图鉴
  - 关卡掉落
  - 装备属性
  - 橙装锻造
  - 铭文
  - 答题
  - 楼兰棋阵
  - 设置
- 桌面左侧导航、手机底部导航和手机“更多”弹层切换分区时，统一通过现有 `switchPartition(name)` 更新顶部标题和 `document.title`。
- 浏览器标签只显示当前分区名，不追加 `Qin` 或其他工具名称。

## 二、删除重复分区标题

- 删除各分区内部的 `.partition-head` 标题节点，避免顶部标题和内容区重复显示同一分区名称。
- 装备属性、铭文和答题原标题旁的数量、版本信息不再展示。
- 既有计数元素可从 DOM 映射中移除；渲染逻辑改为在元素存在时才写入，或删除仅用于这些文字的写入，不影响搜索、筛选和数据计算。
- 不把数量、版本移动到其他位置。

## 三、工具名称统一为 Qin

以下位置统一由“秦时攻略站”改为 `Qin`：

- `manifest.webmanifest` 的 `name` 和 `short_name`。
- `index.html` 的 Apple 主屏幕应用名称元信息。
- 设置分区显示的应用名称。
- PWA 更新、安装完成和已安装提示。
- 设置模块导出的备份文件名和涉及产品名称的提示文字。
- `README.md` 中的产品标题、安装名称和相关说明。

页面 `<title>` 初始值设为默认分区名“图鉴”，运行后由分区切换逻辑继续维护。

## 四、兼容性与缓存

- 保留现有 `localStorage` 键名前缀 `qinshi_`、所有存储键和备份数据字段，避免个人进度、图鉴等级、铭文记录和设置丢失。
- 不修改应用图标、数据文件、筛选规则或各分区业务功能。
- 按现有 Service Worker 版本规则更新缓存版本，使部署后的客户端能识别新界面资源。
- 所有响应式端口共用同一标题逻辑，不分别维护手机和桌面标题。

## 五、建议用户手动验证

- 初次打开时顶部和浏览器标签均只显示“图鉴”。
- 依次切换八个分区，检查顶部和浏览器标签只显示当前分区名。
- 检查各内容区不再重复显示分区标题、数量或版本。
- 检查手机底部导航和“更多”弹层切换时标题同步。
- 检查安装名称、设置页、更新提示、安装提示和新导出的备份文件名均使用 `Qin`。
- 检查既有个人进度、图鉴等级、铭文记录和答题数据仍可读取。

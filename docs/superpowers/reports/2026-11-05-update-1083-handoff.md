# 1.0.83 界面调整交接

## 调整内容

- 铭文资料图表的筛选区统一使用自适应网格：控件最小高度 44px、输入字号 16px、常规列最小宽度 180px，窄屏自动换行。复选框保持横向显示。
- 装备属性的「清除全部条件」改用现有朱砂按钮样式，同时统一空结果区的同名按钮，事件及清除逻辑不变。
- 兵法资料表的当前阶整行内容标绿、目标阶整行内容标红，适用于普通兵法及特殊兵法的全部列；当前与目标同阶时保留原有双标记，不强行选一种颜色。
- PWA 版本及静态资源引用统一更新至 1.0.83。

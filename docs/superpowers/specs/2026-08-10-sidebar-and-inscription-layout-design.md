# 左侧导航与铭文布局优化设计

## 全局导航

- 分区顺序固定为：图鉴、关卡掉落、装备属性、橙装锻造、铭文、答题、楼兰棋阵。
- “特殊属性装备”的导航名称和分区标题统一改为“装备属性”。
- 桌面端使用左侧纵向导航，导航在页面滚动时保持可见。
- 页面整体最大宽度扩大，新增侧栏使用扩大的宽度，主体内容保持现有可用宽度。
- 窄屏恢复顶部横向滚动导航，避免侧栏挤压正文。
- 默认打开图鉴分区。

## 铭文布局

- 查询结果的天位·盾位、主属性、副属性分别占独立列；极致备注在盾位下方显示，不跨列覆盖。
- 已保存进度的弟子名称由红色改为绿色高亮。
- 个人进度主属性按“、”拆为上下两行，页面不显示顿号。

## 资料图表备注

- 盾位副属性表新增独立“备注”列。
- 龙盾、鬼盾：可洗出3/4/5速度；血属性最多双血。
- 神盾、地盾：二星橙色铭文最多3+4速。
- 人盾、虎盾：可洗血属性，并可三血。
- 其他盾位备注为空。

## 范围

- 导航只调整名称、顺序、默认分区和布局，不修改各分区业务数据。
- 铭文只调整展示与资料备注，不改变已保存进度结构。
- 不运行自动测试、lint 或浏览器验证，由用户手动验证。

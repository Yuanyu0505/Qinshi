# 界面清理与图鉴首次激活设计

## 目标

统一精简七个分区的顶部文案和全局页脚，修正装备属性配色，并让图鉴首次进入时保持空结果，只有用户主动搜索或筛选后才显示内容。

## 界面调整

- 图鉴未收藏按钮保留可点击区域，但不显示方框、外框或背景；已收藏仍使用金色星号、红色背景和红色外框。
- 装备属性分区的主属性统一使用白色字体。
- 装备属性筛选命中的属性值和结果中的排序值统一使用鲜红色 `#ff4b4b`。
- 删除以下面板标题，并让面板内现有控件自然上移：`图鉴分区`、`掉落查询`、`按属性筛选`、`视图`、`新增弟子铭文`、`题目搜索`。
- 删除全局页脚中的数据来源和本地离线运行文案，同时去除该页脚占用的空间。

## 图鉴首次激活规则

- 新增仅存在于当前页面运行期间的 `activated` 状态，不写入本地存储或备份。
- 首次加载图鉴分区时，图鉴卡片和“当前结果升至 X 级汇总”均不显示。
- 点击任意图鉴分类按钮（包括“全部”和“已收藏图鉴”）后显示对应结果。
- 输入有效搜索词，或调整搜索限制、等级范围、目标等级时，激活并显示结果。
- 一旦激活，本次页面会话中切换到其他分区再返回仍保持当前图鉴结果；清空搜索不会重新回到未激活状态。
- 收藏切换只刷新当前已激活结果，不改变现有收藏数据格式。

## 非目标

- 不更改图鉴、装备、锻造、铭文、答题等数据源。
- 不更改个人进度、收藏、备份或导入导出数据格式。
- 不调整除上述项目之外的文案、筛选逻辑和响应式布局。

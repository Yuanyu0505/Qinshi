# 装备全分类搜索与典籍详情气泡设计

## 目标

优化装备属性分区的两个交互：

1. 用户未选择装备分类、仅使用搜索框时，查询范围包含典籍、神兵典籍和其他装备。
2. 典籍各品质的阶段成长详情改为浮层气泡，不再撑高装备所在行。

本次不更新 PWA，不合并 `master`，不改动其他分区。

## 搜索分类语义

装备分类状态需要区分以下三种情况：

- `null`：用户尚未选择分类，代表全部分类。
- `""`：用户明确点击“除典籍外”，只显示非典籍装备。
- 具体分类名称：只显示该分类。

初次进入装备属性分区时，`activated` 仍为 `false`，不展示任何结果。用户输入搜索关键词后才激活查询；若此时分类仍为 `null`，搜索结果可以同时包含典籍、神兵典籍和其他装备。

重置全部条件后恢复未激活状态和 `category = null`。

## 典籍详情气泡

### 交互

- 每个典籍品质的最高阶累计摘要保持原样。
- 摘要下方保留“详情”按钮。
- 点击后打开一个共享的页面级浮层气泡，并将按钮文字切换为“收起”。
- 同一时间最多打开一个气泡；点击另一个品质的“详情”时，原气泡关闭并切换到新内容。
- 点击“收起”、气泡外部或按 `Esc` 关闭。
- 表格滚动、窗口滚动或尺寸变化时关闭气泡，避免气泡脱离锚点。

### 内容布局

气泡标题展示装备名和品质。阶段成长每个阶段固定单独占一行，阶段标签和该阶段累计属性紧凑横向排列，例如：

```text
0阶：150速
5阶：150速、23%暴击
10阶：150速、35%暴击、25%技免
15阶：150速、41%暴击、60%技免
```

属性仍使用现有累计计算结果和命中高亮规则，不重新计算或复制业务逻辑。

### 定位与视觉

- 气泡挂载在页面级容器中，使用 `position: fixed`，不参与表格布局，因此不会撑高行。
- 以被点击的“详情”按钮为锚点，优先显示在按钮上方；上方空间不足时显示在下方。
- 水平方向限制在视口内，避免超出左右边缘。
- 气泡使用深色面板、金色边框和轻微阴影，层级高于表格粘性表头和单元格。
- 气泡增加小箭头指向触发按钮。
- 窄屏下宽度不超过视口可用宽度，阶段属性允许自然换行，但每个阶段仍保持独立行。

采用页面级共享浮层，不采用单元格内绝对定位，以避免被 `.table-wrap` 的滚动与裁切规则截断；不采用居中模态框，以减少遮挡和操作中断。

## DOM 与状态

- 为详情按钮写入装备 ID 和品质标识，使用装备属性分区的事件委托处理打开与关闭。
- 页面只创建一个气泡节点，打开时根据装备 ID、品质调用现有 `Q.cumulativeBookStages(item, tier)` 生成内容。
- 当前打开项保存在装备分区本地状态中；重新查询、切换筛选、重新渲染结果或离开分区时关闭气泡。
- 触发按钮维护 `aria-expanded`，气泡使用合适的对话框语义并关联标题。

## 测试契约

- 查询核心测试覆盖：分类为 `null` 时允许全部分类，分类为 `""` 时仍排除典籍。
- 装备查询测试覆盖：仅搜索且分类为 `null` 时可以同时返回典籍和非典籍结果。
- 页面契约覆盖：详情使用页面级浮层而非原生展开内容；阶段行逐行渲染；具备详情、收起、外部点击和 `Esc` 关闭路径。
- 非典籍渲染、明确分类筛选和初始不展示结果的行为保持不变。

按照项目约定，自动测试、浏览器验证和手动验收由用户执行。

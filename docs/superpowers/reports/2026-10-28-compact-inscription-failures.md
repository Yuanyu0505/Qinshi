# 铭文失败结果合并与词条单行

用户要求直接修改并仅合并本地 master。采用每次合成一个失败结果框，框内每个结果一行，例如“失败紫一 A2：4%护盾（中档）＋1速（中档）”。单项概率写在该行末尾，入框箭头显示失败合计概率，不改变概率模型。

所有流程材料/成功品/失败品/最终目标的词条组合统一同行。根据最长组合加宽节点，沿用局部滚动缩放，不缩小字号，也不拆分词条。品质颜色及普通档位字重保留。

失败品内部仍按精确材料签名映射，各复用操作框明确标明 A2×1、B2×1 等投料种类与数量；同一个失败框到同一操作只连一条线，避免重复连线和标签叠字。规则、存档及模拟不改。

独立只读审查指出同源失败框连接多个复用操作时投料标签会叠加，已改为各操作框内列示投料；未执行运行时验证。

不推送、不更新 PWA、不运行测试/构建/lint/实机验收。建议人工检查多分支失败框、每行词条及概率、复用材料标签、长组合及移动端横向滚动。

# 铭文全路线统一阅读布局

用户已批准连续多轮参考图，并要求推广到所有路线；本次不再单独确认设计与实施计划。

## 范围与统一规则

- 所有遁位、目标品质、必中/概率方案、收藏路线均通过现有 `InscriptionFlowchart.render` 采用相同规则，不为鬼遁建立特殊模板。
- 从现有语义投影中区分主线材料、独立准备素材/晋升铭文、其他结果/失败复用。主线稳定向下，独立素材居左，失败与复用居右；合法的并行主线仍保留，不能为了三列外观伪造材料关系。
- 实际材料汇合用圆点，随机结果分叉用菱形；两者之间留出短干线。非汇合、非分叉不画节点。不同投料批次不共享误导性横线；同批晋升铭文参与同一汇合点。
- 结果概率属于具体结果支线，同一分叉的概率标签同高。直下主线、同源分支、复用回接均避免无意义弯折；箭头和标签互相避让。
- 独立洗练不画从蓝二开始的虚假制作过程。素材铭文用较浅的品质底色，普通晋升铭文保持白底并按初级蓝色/中级紫色着色。
- 其他结果与失败框整体使用对应品质浅底色、边框，不再仅左侧色条。所有词条继续按统一数值/同属性排序，用品质色加粗；图外失败明细中的符号 X 同样用品质色。
- 非最终材料保留“总共需要X枚该铭文”；确定性同款合成单独强调“下步：同款3枚合成 · 必出”。最终橙二不显示总共需要1枚。
- 只保留工具栏统一失败明细开关；说明区分条展示数量口径、单次产出、概率口径。默认90%，保留适合宽度/完整总览和触屏滚动、点选依赖高亮。

## 架构取舍

采用“现有语义模型 + 独立通用布局模块 + 现有 SVG 渲染与交互”。不采用硬编码示例模板，也不把所有方案压成一条串行链。计算模型、概率、需求累计、库存和收藏 ID 不变。

## 验证与发布边界

遵守当前 AGENTS.md：不主动运行测试、lint、构建或实机验收。补充回归用例供用户执行，审阅调用关系与差异，不声称测试通过。仅提交本任务文件，不提交用户工作簿、缓存和历史测试产物。版本由1.0.72更新为1.0.73，包含前次本地未推送提交，合并本地master，并沿用既有发布分支推送origin/main（GitHub Pages工作流仅监听main）。

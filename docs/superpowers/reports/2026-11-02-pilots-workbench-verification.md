# 机师与铭文工作台验收记录

## 实施
- 机师独立分区：60位弟子（32机师／28非机师），141条突破效果、34条机师效果、9个时装名称；原图误印已按用户确认改为神·英布。
- 机关兽参考新增0—10阶成品材料及7—10阶累计需求表，不改变计算器。
- 路径查询与模拟筛选独立存储。旧档异常先由用户选择隔离或清空；隔离副本只读可查看，清空需确认范围。

- 发布版本统一为1.0.75，机师脚本、数据和样式纳入懒加载、离线缓存及Pages产物。

## 验证环境
Windows无头Edge；浏览器隔离测试账号及独立存储，不使用真实玩家账号、不调用生产同步接口。
手机／平板以320—1440px触控视口模拟验收，并非iOS或Android真实硬件验收。
Node 24实验性全局Navigator的Web Locks在旧用例拒绝分支中停滞，单元测试使用进程级 `NODE_OPTIONS=--no-experimental-global-navigator`；不修改应用中的浏览器Web Locks逻辑。Git子进程使用进程级safe.directory配置，不修改全局Git设置。

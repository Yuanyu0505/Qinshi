# 1.1.2 界面文案精简

## 本次范围

根据2026-11-16用户要求，恢复诸子卡可见标题，采用与其他分区相同的标题／返回目录排布；撤销上一轮专用隐藏样式。AGENTS新增长期界面规范：布局和控件优先表达含义，默认不新增非必要说明；保留必要单位、业务限制、风险、缺失和异常状态。

本次不是按`.note`/`.muted`统一隐藏。原有个人备注、字段标签、数值、空状态、错误与可访问名称均不作为冗余删除。原始游戏数据、计算、库存、备份和持久化逻辑不改。

## 回归边界

按当前AGENTS，本次未运行功能验证、单元／浏览器测试、lint、格式检查或手动验收；补写／同步测试供用户执行，不宣称通过。已做独立只读静态审查，未发现Critical/Important问题；这不等同运行验证。

建议用户重点验收：

1. 诸子卡标题位置与其他分区一致，搜索／清除／返回目录仍正常。
2. 五行表格与卡片字段含义清楚，查询、品质筛选、数值及原始数据一致。
3. 锻造与铭文宽表可局部横滚，手机不产生整页溢出；图鉴卡片与汇总无重复上限提示。
4. 秘境默认不显示空提示，保存后状态／无效输入／保存失败仍有反馈，金额未改变。
5. 其他已调整模块的计算、库存与个人进度操作，以及账号切换、备份覆盖确认。

版本资源身份统一1.1.2。发布状态在合并推送及部署任务完成后补记；部署成功不代表功能测试通过。

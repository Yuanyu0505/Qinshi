# 六堂 Implementation Plan

> **For agentic workers:** 使用superpowers:executing-plans推进本计划；独立文件按明确接口并行委派，最终进行新上下文静态审查。用户已明确无需再次确认文档。步骤按复选框追踪。

**Goal:** 提供按游戏账号隔离的六堂进度、共享草/独立信物库存、临时升级规划及完整资料查询。

**Architecture:** 静态资料、无存储副作用的纯计算、注入账号存储的控制器与界面分层。沿用统一导航和账号键前缀机制。规划仅存内存。

**Tech Stack:** 原生JavaScript UMD、HTML、CSS、Node内置测试、既有Playwright测试基础（仅写用例，不运行）。

**Spec:** docs/superpowers/specs/2026-10-22-six-halls-design.md

## Global Constraints

- 六堂顺序：魁隗、蚩尤、烈山、四岳、共工、神农；每堂满级904草/435信物。
- 草共享一次抵扣，信物各堂专用；不自动分配或回写。
- 持久逻辑键qinshi_six_halls_progress_v1；规划selected/targets只存内存。
- 用户和AGENTS规定不主动执行任何测试、构建、lint、语法检查或浏览器验收；测试代码先补齐，运行由用户决定。发布后只读取部署状态与静态资源确认发布，不代表功能通过。
- 保留用户改动的Excel、截图、临时目录；只提交本任务文件，不增加依赖或云端接口。

## Review Focus

- 在未勾选堂口中填非法目标不应污染已选结果；已选非法目标不能显示旧的有效结果。
- 共享草有富余与不足时都只扣一次，六堂信物不能混抵。
- 修改真实进度使临时目标低于当前，要显示错误，不默默改目标或重复计费。
- 只读/保存返回false/存储抛错，不能先替换内存进度或显示成功。
- 切换子页/分区不能清草稿；刷新/换账号不能保存草稿。

## Interfaces

data/six-halls.js导出/挂载SIX_HALLS_DATA：{maxLevel:50,halls:[{id,name}],milestones:[{hallLevel,playerLevel}],steps:[{from,to,herbs,tokens,playerLevel:null|number}],fullCost:{herbs:904,tokens:435}}。

js/six-halls.js导出/挂载SIX_HALLS，包含：
- STORE_KEY = qinshi_six_halls_progress_v1。
- parseInteger(value,min,max,allowEmpty) -> {valid,value:number|null}。
- normalizeProgress(raw,data) -> {version:1,playerLevel:null|number,herbs:number,halls:{[id]:{level,tokens}}}。
- defaultPlan(data) -> {selected:[],targets:{[id]:50}}。
- playerCap(playerLevel,data) -> null|number。
- calculateCost(from,to,data) -> {herbs,tokens,steps}，非法抛RangeError。
- referenceRows(data) -> 步骤附cumulativeHerbs/cumulativeTokens。
- calculatePlan(progress,plan,data) -> {valid,errors:[{hallId,message}],rows,herbs:null|{need,stock,missing,remaining},playerCap,playerLevelKnown,selectedCount,hasLocked}。
- 结果rows每项{id,name,current,target,herbs,tokens,tokenStock,tokenMissing,tokenRemaining,currentCap,locked,requiredPlayerLevel,progressConflict}；非法已选目标时rows=[]、herbs=null；重复堂ID去重，未知ID返回错误；未选目标不校验。
- requiredPlayerLevel为目标级别对应最高门槛，目标<10时null；locked在已知玩家等级且目标大于max(当前等级,可升上限)时成立，progressConflict独立指示当前高于上限。

UI挂载/导出SIX_HALLS_UI：init(root)、createController({data,core,store})；controller.state包含progress、plan、mode、error。方法setProgress(field,value,hallId?)，field为playerLevel/herbs/level/tokens；toggleHall(id,selected)、setTarget(id,value)、setMode(mode)、calculate()。持久修改成功返回true，失败false，先保存成功再替换state.progress。mode取progress/planner/reference。DOM容器为partition-six-halls，界面自行首次进入生成内容。

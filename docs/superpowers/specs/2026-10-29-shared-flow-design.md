# 共享分支紧凑流程图与目标属性联动

用户连续确认A：自定义目标属性选择器，以及将有用产物识别/共享配方推广到全部路线。文档无需再次确认。

- 路径和模拟目标属性采用可访问的自定义选择器；不可选属性深灰但可点击查看“无法组成所选搭配”原因，不提交非法值；鼠标、触控、键盘均支持。判定考虑其他槽和剩余槽是否存在完整合法解，而非仅统计重复次数。旧非法目标保留提醒，不能静默改值。
- 保留规则、概率和完整路线存档。流程图作为投影视图将相同配方合并：前缀、遁位、输入品质/完整词条档位、数量、晋升材料、制作来源/符号X来源一致才共享入口，不能只因数值相同合并。
- 同一配方的不同目标结果均是完整路线需要的材料时，显示“可用产物”分支，不互称失败。每次仍只产出一枚，分支概率不改；制作次数不定，不能改为必中路线。
- 鬼遁橙二暴伤M+速度H+速度M例：蓝二1速+1%暴伤M只显示一个合成入口，两紫一分支各50%，分别×3合紫二，再稳定合橙一×3至橙二。全程从零需要两紫一各9枚，不把共享入口当成一次获得两枚。
- 重复链合并、晋升材料附属标识、确定性操作与产物同框，压缩空白。保留品质边框、彩色词条、单图和默认90%；非所需结果明细移入图下详情面板，不撑宽主图。复用分支保留真实来源连线和动态M选N。
- 增加适合宽度/完整总览、节点高亮来源去向；复杂图不承诺零滑动，不以缩小正常阅读文字替代整理。
- 收藏身份与数据不迁移，X模式/档位不可辨不推测、独立洗练不消耗其他分支材料。手机/平板触控可读。

# 可选具体X与材料准备修改记录

计划：`docs/superpowers/plans/2026-10-28-inscription-x-preparation.md`

## 实施内容

- 查询具体X默认留空：符号模板A；选定固定属性档位：具体模式B。固定值按当前目标品质显示，各阶段数值沿品质成长。
- X只用于路径查询和收藏，改变X不清除模拟材料；不合法的选择在目标切换后提示恢复符号模式。
- 代表路线保留紫二相同高中档材料×3和同X互补2＋1两个准备族。普通路线不主动要求洗紫二同属性高＋低；洗练准备不补画蓝二链。
- 显式X来源传播到继承的成功/失败产物；无X输入的随机补词条保持具体。复用按候选池覆盖说明，2＋1是可行示例而非固定ABC投料要求。
- 收藏存储X模式、完整档位及生产来源，重载校验原路线，失效原记录保留，不静默换方案。

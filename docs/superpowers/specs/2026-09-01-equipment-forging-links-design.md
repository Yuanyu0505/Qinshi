# 装备属性跳转橙装锻造设计

## 目标

在“装备属性”搜索结果中，将具备橙装锻造资料的装备名变为可点击入口。点击后进入“橙装锻造 → 查询 → 作为主锻造装备”，自动填入确认后的锻造装备名并展示材料。

同时将工具数据中的“伍德终始”统一修正为“五德终始”。

## 交互

- 仅搜索结果中的装备名可触发跳转；收藏星号继续独立操作。
- 跳转后强制切换到“查询”页和“作为主锻造装备”模式。
- 自动写入精确查询词、立即渲染结果，并将锻造查询区域滚动到可视位置。
- 没有锻造资料的“秦时周年历”“虎年勋章”保持普通文本，不提供无结果链接。
- 桌面、平板和手机共用同一事件与样式规则；键盘焦点应清晰可见。

## 名称解析规则

1. “鬼谷子”对应“鬼谷子”，“神兵鬼谷子”对应“神兵鬼谷子”。
2. 其他神兵装备若去掉“神兵”后能精确命中锻造数据，使用去前缀后的名称。
3. 非同名关系使用明确别名表，不做模糊匹配。
4. 普通装备若能精确命中锻造数据，直接使用原名。
5. 未命中锻造数据时不生成跳转目标。

## 实现边界

- 新增独立纯函数模块保存映射和解析规则，避免把大量别名散落在界面代码中。
- 不修改橙装锻造材料数据结构。
- 名称纠正在生成脚本与当前生成数据中同步完成，避免后续重新生成时回退。
- 功能确认后按后续发布要求更新 PWA、合并本地 `master` 并推送 GitHub。

## 铭文收藏：同步异常后锁未释放

在Node v24.16.0原生LockManager中独立复现：同名exclusive锁一次成功后，回调同步抛错虽然会使request拒绝，但query仍返回该锁被持有，下一次同名请求一直等待。收藏存储拒绝/异常、损坏存档等原本应当正常返回错误，随后却污染后续所有测试/写入。

新增回归先检测真实锁的held状态，并验证拒绝写入前后存储字节不变、取消故障后可再次保存。修复前该回归立即失败（held=1）；生产修复将锁回调统一包装为`Promise.resolve().then(commit)`，成功和错误都沿Promise结算，锁得以释放。业务事务内的账号、只读、raw token和revision检查完全保留，不绕过保护、不丢弃错误、不改数据结构。

修复后原收藏文件21/21通过（含新增1项）；原先9项超时自然通过，未改大超时、未skip、未删除用例。

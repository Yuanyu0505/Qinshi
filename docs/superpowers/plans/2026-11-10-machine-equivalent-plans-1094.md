# 机关兽全部同等最优组合实施计划

**Goal:** 所有实质排序指标完全相同的最优组合均可查看，放在原培养材料区域；稳定键只决定代表方案及展示顺序。

**Architecture:** 保留原主解数值与严格等级约束；跨兽DP的完全同指标状态保留压缩前驱DAG，不展开指数个数组。对获胜DAG中的单兽候选反向重建所有相同研发度/神图/改造/本体费用的材料数量向量，弥补旧单兽稳定键剪枝。序列化为无循环平面图，按精确BigInt计数、分页解码。UI不增加顶层方案面板。

## Review focus

- 本体费用同价但新增数量不同（零价、碎片覆盖）不能漏；原过滤掉的new类型需参与等价材料重建。
- 材料向量唯一：按类型计数，不能把同一库存分块选择顺序算作不同方案。
- 前驱合并必须同全部实质状态，不把更贵或不同溢出方案混入。
- 序列化不能把共享DAG展开成指数JSON，计数不能丢BigInt精度。
- 主方案排除、分页无遗漏重复，另一套主目标及合并目标均可用。

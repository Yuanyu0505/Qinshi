- 日期：2026-08-07
- 状态：已确认，待用户审阅

- 运行目标：电脑双击即用 + 同一局域网内手机浏览器访问

## 1. 背景与目标

用户有一份秦时明月游戏攻略 Excel（39 个 Sheet），需要逐步做成离线本地网页。本期只实现第一个子模块：**特殊属性装备**查询页，要求支持关键词搜索、属性分类筛选（最多 2 个）、按属性数值倒序排序（可切换取值档位），并提供手机访问能力。

## 2. 范围

本期包含：

- 特殊属性装备查询页（搜索 / 筛选 / 排序 / 展示）
- 手机访问模式（局域网 HTTP 服务 + 响应式布局）
- 数据解析脚本（一次性生成数据文件，后续可复用）

本期不包含：

- 其他 38 个 Sheet 模块
- 跨表汇总查询
- 个人进度 / 标记功能
- 数据更新机制（界面无更新入口；Excel 更新后需重新运行解析脚本）
- 测试服内容（本表无测试服数据；后续模块按同一原则排除）
- 表格底部的「锻造路线」示意图（第 72-106 行，用户确认不纳入）

## 3. 需求口径（用户已确认）

## 4. 数据源结构（解析依据）

Sheet 布局：

- 第 2 行表头：武器名称 / 防具名称 / 饰品名称，三个横向区块

- 档位列（以武器区块为例）：橙色 D/E、橙金 F/G、红色 H/I、红金 J/K；防具、饰品区块同理

- 属性类型 9 种：攻、血、防、穿透、减伤、抗暴、暴击、暴伤、减免

## 5. 架构与文件结构

方案：**纯静态多文件网页 + Node 本地服务（手机访问模式）**。

```
deepseek/
├─ index.html                       # 入口页面（双击可开）
├─ css/style.css                    # 样式（深色水墨古风 + 响应式）
├─ js/query.js                      # 查询 / 筛选 / 排序纯逻辑（可单元测试）
├─ js/app.js                        # DOM 渲染与交互
├─ data/special-equipment.js        # 生成的数据（window.SPECIAL_EQUIPMENT_DATA）
├─ serve.js                         # Node 静态服务（手机访问）
├─ 启动服务.bat                     # 双击启动服务
├─ tools/build_special_equipment.py # Excel → 数据解析脚本
├─ js/query.test.js                 # 查询核心单元测试（node:test）
├─ serve.test.js                    # 静态服务测试（node:test）
├─ tests/test_build_special_equipment.py # 解析脚本测试（unittest）
├─ README.md                        # 使用说明
└─ docs/superpowers/specs/          # 设计文档目录
```

数据流：

```
Excel → tools/build_special_equipment.py → data/special-equipment.js → 浏览器（file:// 或 http://）
```

选型理由：

- 普通 `<script>` 标签在 `file://` 与 `http://` 下均可加载，不依赖 fetch，双击打开与局域网服务共用同一套页面
- 本机已安装 Node.js，`serve.js` 仅用标准库，零依赖、离线可用
- 数据与代码分离，后续其他子表模块 = 新增 data 文件 + 模块配置

## 6. 数据模型

`data/special-equipment.js` 导出结构：

```js
window.SPECIAL_EQUIPMENT_DATA = {
  meta: {
    sourceFile: "秦时相关（更新贯侯钟离昧）20260618.xlsx",
    sourceSheet: "特殊属性装备",
    version: "20260618",
    generatedAt: "2026-08-07",
    total: 123,
    attrTypes: ["攻", "血", "防", "穿透", "暴击", "暴伤", "减伤", "抗暴", "减免"],
    categories: ["武器", "防具", "饰品", "神兵武器", "神兵防具", "神兵饰品"]
  },
  items: [
    {
      id: "w-0001",
      cat: "武器",
      name: "朔日辉光",
      main: "攻",
      tiers: {
        "橙色": [{ t: "血", v: 5 }, { t: "穿透", v: 5 }],
        "橙金": [{ t: "血", v: 8 }, { t: "穿透", v: 8 }],
        "红色": [{ t: "血", v: 10 }, { t: "穿透", v: 10 }],
        "红金": [{ t: "血", v: 10 }, { t: "穿透", v: 15 }]
      },
      max: { "血": 10, "穿透": 15 }
    }
  ]
};
```

- 属性 token：`{ t: "血", v: 5 }`；状态 token：`{ s: "无" }` / `{ s: "暂未开放" }`；无内容：空数组
- 归一化规则：`10%血量` 归类为 `血`（显示保留原文）；`减免` 作为独立属性类型保留；数值支持小数
- `max`：该属性在所有档位中的最大值，供默认排序直接读取
- id 规则：`{w|f|s}-{三位序号}`，按原始行序生成

## 7. 查询 / 筛选 / 排序规则

### 7.1 搜索

- 输入去除首尾空格并转小写；对装备名做子串匹配
- 分类关键词匹配：输入「武器」命中「武器」「神兵武器」；输入「神兵」命中全部神兵分类；输入「神兵饰品」命中该类
- 空输入 = 全部装备

### 7.2 属性筛选

- 9 个属性芯片，最多同时选 2 个；已选 2 个时其余芯片置灰
- 命中规则：`main === A`，或任一档位任一 token 的 `t === A`
- 多选为 AND：所有已选属性都命中才展示

### 7.3 排序

- 无筛选：按分类顺序（武器 → 防具 → 饰品 → 神兵武器 → 神兵防具 → 神兵饰品）+ 原始 id 顺序
- 有筛选：按排序属性的数值**倒序**；排序属性默认 = 第一个已选筛选属性，可在两个已选属性间切换；无筛选时排序控件禁用
- 取值档位三选一：最高值（默认，读 `max`）/ 红色档 / 红金档；取该档位 token 中该属性的最大值
- 该属性无数值（仅主属性命中、该档位无数据、暂未开放）→ 排序值视为无 → 排最后；同值按分类顺序 + id 稳定排序
- 主属性只参与筛选，不产生排序数值

## 8. 页面设计

### 8.1 桌面布局

```
顶栏：秦时 · 特殊属性装备 | 共 123 件 · 版本 20260618
搜索框
筛选区：属性芯片 ×9 | 排序控件（排序属性切换 + 档位 最高/红色/红金）
结果计数
表格：分类 | 装备名 | 主属性 | 橙色 | 橙金 | 红色 | 红金 | [排序值徽标]
页脚：数据来源说明
```

### 8.2 表格渲染

- 档位格：多个 token 以「 + 」连接；`无` / `暂未开放` 灰色弱显；空档显示 `—`
- 命中已选筛选属性的 token 金色加粗高亮
- 排序激活时显示排序值徽标（如「血 15%」），否则隐藏该列
- 固定表头，内容区横向滚动

### 8.3 手机布局（视口 ≤ 720px）

- 表格切换为卡片列表：每张卡片含分类徽标、装备名、主属性、4 档属性行、排序值徽标
- 搜索 / 筛选 / 排序控件竖排，触控友好
- 查询逻辑与桌面完全一致

### 8.4 主题与状态

- 深色水墨古风：墨黑背景、金 / 朱红点缀、楷体标题 + 黑体正文（系统字体栈，离线无外部字体）
- 空结果状态：提示文案 + 「清除全部条件」按钮

## 9. 手机访问模式

### 9.1 serve.js（Node 标准库）

- 静态文件服务：正确 MIME（html/js/css/json/png/svg/ico）；`/` 返回 index.html；限制路径穿越
- 端口：8000 起，被占用则依次尝试至 8010
- 启动时打印本机地址 `http://localhost:端口/` 与局域网地址 `http://局域网IP:端口/`
- 局域网 IP：`os.networkInterfaces()` 取第一个非内部 IPv4（优先 192.168 / 10 / 172.16-31 段）
- 自动打开电脑默认浏览器；Ctrl+C 停止

### 9.2 启动服务.bat

```bat
@echo off
chcp 65001 >nul
cd /d "%~dp0"
node serve.js
pause
```

### 9.3 使用说明（写入 README）

- 电脑单机：双击 `index.html`
- 手机访问：双击 `启动服务.bat` → 手机连同一 Wi-Fi → 浏览器打开窗口显示的局域网地址
- 首次启动 Windows 防火墙弹窗选「允许」；仅局域网可访问，无需外网
- 手机与电脑需在同一局域网；路由器若开启 AP 隔离则无法访问

## 10. 边界与错误处理

- 无副属性数据的装备（神兵破阵弓、神兵月华）：档位显示 `—`，搜索 / 筛选正常，排序排最后
- 同一档出现两条同类型属性：取较大值参与排序（源数据未见，防御处理）
- 搜索无结果：空状态提示 + 清除条件按钮
- 端口全部被占用：提示更换端口或关闭占用程序
- Node 不存在：bat 报错并提示安装 Node（本机已装）
- 数据文件缺失：页面提示数据文件缺失，不白屏

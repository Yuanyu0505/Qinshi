# 1.1.9 PWA注册与魂店入口修复

用户反馈1.1.8检查更新报ServiceWorker InvalidState错误，点击魂店仍停留在禁地。

代码定位：updateRegistration原先重试同一个注册对象，没有失效对象恢复路径；魂店入口仅在app主初始化到达时绑定，缺资源直接返回且没有可见错误。未运行浏览器，不能将该启动依赖断点等同于用户设备上已复现的唯一原因。

- InvalidStateError或对应invalid state消息改为重新register获取注册对象，register自带更新流程，不立即对刚注册的空对象再次update。相同对象避免重复绑定updatefound。
- 手动检查在缺注册对象时可重新注册。强制修复期间阻止并行更新和状态覆盖，注销后丢弃旧对象；不自动删除注册、缓存或个人数据。
- 魂店独立于app.js在DOM就绪时启动；入口委托点击补初始化，缺资源或结构不一致时显示可见错误，避免静默无响应。禁地用途弹窗未初始化时关闭操作安全返回。
- 新增失效注册恢复、主初始化中断下魂店入口的隔离回归用例；按AGENTS.md仅编写，未执行测试/lint/格式检查/页面验收。
- 版本及PWA身份统一1.1.9；其余业务和个人数据不变。保留用户原有Excel及无关文件。

独立只读审阅指出“空注册恢复后递归检查仍会马上update新对象”的问题，已改为本轮仅同步注册状态；新增空注册不调用update的断言，以及魂店缺数据后补齐再点击/重复点击用例。上述脚本均未执行。

用户手动检查：检查更新不再反复操作旧注册对象，魂店可切换；如仍启动失败，提供新显示的错误内容。旧1.1.8页面不能直接执行新恢复逻辑，可先用已有强制修复更新获取新版（仅清理本站离线缓存，不清个人进度）。

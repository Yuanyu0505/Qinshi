# 全工具性能检查与优化

## 已确认范围

用户同意合并连续搜索刷新、避免重复生成隐藏结果、局部更新正在编辑的内容、减少屏幕外列表绘制。计算规则、搜索筛选语义、个人进度与界面布局均保持不变。所有文案换行和横向滚动只出检查清单，等待用户另行决定。

## 诊断依据

- 覆盖十三个模块与 320、360、390、768、900、1024、1100、1200、1440 像素视口；大列表、编辑、查询、计算使用隔离浏览器及合成进度，不读取用户实际个人数据。
- 机关兽计算从零开始逐一枚举不可能满足目标的投入数量，流派计算将此成本重复多次；可采用数学上保守的下界剪枝，不改变最优解或优先级。
- 装备属性每次输入同时生成桌面表格和移动卡片，其中一套始终不可见。
- 图鉴、装备、锻造、禁地搜索每个输入事件立即重建列表。图鉴打开库存编辑和切换拥有状态也重建全部结果。
- 铭文已有查询防抖和页面失效管理，本轮保留；首次大列表绘制仍应测量。

## 实施方案

1. 机关兽最低投入数以所有可用类型的最大单位投入研发度计算保守下界，跳过空库存状态；原有比较函数、成本和库存约束不变。
2. 小型公共刷新队列支持按键合并、取消、立即刷新与中文输入法组合事件。状态同步即时执行，列表延迟 120 毫秒合并；明确点击筛选和跳转仍即时刷新。不得让旧任务覆盖新视图。
3. 装备只生成当前断点需要的表示，在越过 1024 像素断点时重建另一表示，保持条件、收藏和对比状态。
4. 图鉴库存编辑只替换目标卡片，拥有状态仅切换同行备注框；保存影响过滤或排序时继续完整查询，保证结果正确。
5. 屏幕外绘制优化仅在实测证明有效且不影响布局、页面搜索、弹层和锚点时使用；不为满足优化列表强行加入样式。

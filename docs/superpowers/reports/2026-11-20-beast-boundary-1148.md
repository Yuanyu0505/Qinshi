# 1.1.48 机关兽临界库存与首屏优化

基线为当前仓库 1.1.47（`e9b3e70`）。压缩包中的实施指令用于确定本轮范围；复审、冻结源码和旧日志仅用于对照，未覆盖现有仓库。游戏数据、库存/本体/神核守恒、定价与逐只取整、账号存储、正式优先级不改。

## 变更与等价依据

- `tools/benchmark-machine-1147.cjs`：先在独立子进程用零库存求出 17,206 张参考需求，正式测例分别使用 0／17,205／17,206／27,206 张。每次独立计时和统计进程 RSS，记录输入及完整结果 SHA-256；超时保留可用的层级诊断，不解释为无解。可加 `--diagnostics --gc` 或 `--heap-mib 512`。
- `js/machine-beast-school-planner.js` 的 `mixedFrontier`：按本体费用升序，其他维度依次按有利方向、稳定键及原位置排序。任何支配者均先被处理；二维前缀最小值查询只覆盖神图更少、效果更多的坐标，并验证溢出不大于当前状态。索引装不下或桶过小时仍使用原精确扫描，对候选数量不设上限。保留入桶前的同等 trace 合并，输出幸存者依原顺序遍历。
- 同文件 `combine`：在库存可能被跨越且未走零本体费用快速路径时，按相同 gain 和最少改造数计算后缀本体费用、神图需求各自的下界。两项最小值不必同时可达，因为这里只与单一合法见证解的实际费用上界比较。效果模式的见证先达到最大效果。只排除费用严格超过上界的前缀，费用相等不剪；从不返回见证代替精确搜索。全覆盖库存不启用该检查，避免既有同等图顺序受无意义的中间状态移除影响。
- 同文件零费用判定：二分后的 `hi` 是预算，不是所有后续前缀的最大消耗。保留二分前最大合计值，只有确实不可能越过边界时才能按溢出合并不同神图需求的前缀。新增两段构造反例：旧版会丢失可达的零费用组合；本版两种目标均返回该组合。报告将这项旧缺陷与等价优化区分。
- `js/machine-beasts-ui.js`：先生成主方案，首批同等方案通过后续任务每次解码和生成一条 HTML，首批及以后每批仍最多 10 条。批次缓存替代持续增长字符串；现有追加、焦点、展开、滚动及账号/任务序号校验保留。中途导航取消未提交批次，回到流派恢复首批加载。不是分页重写，也没有删除历史 DOM。
- `conversionCandidates` 的 Number/BigInt 编码和 Worker 复用均保留。本轮观测确定主要长尾位于混合费用合并，不将未经对照的 DP 对象重构或 Worker 强制销毁纳入发布。

## 实测记录

- 同一 Windows / Node 24 环境，差 1 张场景原扫描的独立求解 50 秒未完成。第 8、9 个合并层约 8.76 亿及 11.51 亿次扫描比较。仅加入精确索引的试验约 85.05 秒完成、峰值 RSS 2,820 MiB；加费用下界后试验约 5.96–6.86 秒、RSS 854–860 MiB，完整结果 SHA-256 相同。原扫描没有完成时间或峰值 RSS，不能计算对旧版的准确倍率。
- 真正的零费用临界缺陷由恰好 17,206 张触发；修正后的复跑约 9.85 秒、924 MiB，返回精确方案。`outputs/1148-exact-fixed.jsonl`。
- 扩展样本含霸道45/225、非攻小数价225、零价135、高阶及额外改造开关、仅0阶新增、参与兽和库存上限。初次扩展日志中的“刚好足够”失败属于上文旧缺陷，不能当作最终通过；详见独立复跑。非攻无神图库存试跑仍可达约 1.35 GiB RSS。
- 用 `--heap-mib 512` 的 Node 子进程试跑差 1 张边界约 13.57 秒完成，进程峰值 RSS 约 501 MiB。V8 堆限制不等于手机内存限制，也不是浏览器 Worker 峰值。偶发长任务与极端库存仍是风险。

## 验证与复现

- `node tools/compare-machine-conversion.cjs e9b3e70`：固定种子比较 360 单兽、180 流派、720 完整前沿及所有有界分页。原基线另行比较并标出缺陷案例84（零基索引83）；等价检查用仅纠正该一处旧条件的历史参考。独立守恒穷举、稳定键、53 位与超大域测试不依赖该更正。
- `node tools/freeze-machine-school.cjs --check`：三组旧冻档整份 JSON 对照，含主方案、同等图、来源账本及全部分页。
- `node tools/run-tests.cjs unit`：全站验证 1274/1274；`outputs/1148-unit-final.txt`。最终冻结校验见 `1148-frozen-final.txt`，三份完整 JSON 均一致；同一提交单独跑固定种子差分见 `1148-diff-final.txt`，含 690 页。
- 设置本机 `PLAYWRIGHT_MODULE` 后运行 `node --test tests/machine-beasts-pagination-browser.cjs tests/machine-beasts-worker-safety-browser.cjs tests/machine-beasts-worker-retry-browser.cjs tests/pwa-update-browser.cjs`；复跑记录在 `outputs/1148-browser-release.txt`，五档截图及分页数据在 `outputs/1148-pagination`。上一轮命令中的五档失败由新计时测试的变量作用域触发，已更正。首批数据记录的是分页区模板生成及批次可用时间，不冒充实际屏幕首次绘制时间。没有真实低内存手机或本轮独立的物理设备测量。

最终浏览器复跑 19/19；五档 768 套样本均验证 767 条替代组合的完整顺序和旧节点、焦点、滚动保留。五档分页区首次模板生成约 0.2–0.7 ms，第一批可用约 50–170 ms（包含分块等待）；这些是本次隔离环境观察，不能当作全页面首绘或通用上限。

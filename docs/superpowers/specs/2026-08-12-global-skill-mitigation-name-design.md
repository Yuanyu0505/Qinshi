# “技免”全分区统一设计

## 目标

将工具所有分区中的“技能减免”“技伤减免”“减伤”“减免”相关技能伤害减免词条统一简化为“技免”，同时兼容用户已有个人进度和旧版生成数据。

## 统一规则

- 工具内标准词条名称统一为“技免”。
- 百分比属性采用数值在前、名称在后的展示格式，例如 `20%技免`。
- Excel 原文件保持不变；工作簿中的“减伤”“减免”“技能减免”“技伤减免”由各数据生成或加载逻辑转换为“技免”。
- 不将与技能伤害减免无关的其他“免伤”词条改为“技免”，例如铭文中的 `PVP免伤` 继续保留原名。

## 装备属性分区

- `tools/build_special_equipment.py` 将“减伤”“减免”“技能减免”“技伤减免”全部归一为内部类型“技免”。
- `data/special-equipment.js` 的属性分类、token 类型、最高值键和展示文字全部使用“技免”。
- 副属性筛选按钮、命中高亮、排序属性和排序值统一使用“技免”。
- 原有装备、普通典籍和神兵典籍执行同一规则。

## 铭文分区

- 盾位可洗练副属性中的“技伤减免”统一改为“技免”。
- 查询筛选、资料图表、个人进度编辑下拉项和保存后展示全部使用“技免”。
- 旧个人进度读取时，将“技能减免”和“技伤减免”自动映射为“技免”。
- 原有旧值兼容只发生在加载和标准化阶段；重新保存后使用标准名称“技免”。

## 其他分区

- 检查所有运行时代码和生成数据；只要语义确实是技能伤害减免，均改为“技免”。
- 历史设计文档保留其当时记录，不批量改写无关的旧实施文档；本规格和相关当前规格反映最新规则。

## 缓存与兼容

- 更新 PWA 静态缓存版本，确保部署后获取新版数据和脚本。
- 不修改任何浏览器存储键，不删除或重置用户个人进度。
- 不修改 Excel 源文件内容。

## 建议用户手动验证

- 装备属性的副属性按钮、普通装备、典籍、神兵典籍和排序值是否全部显示“技免”。
- Excel 原文“减伤”“减免”是否仍能被正确筛选为“技免”。
- 铭文的可洗练属性、资料图表、编辑下拉项和保存后结果是否均显示“技免”。
- 已保存为“技能减免”或“技伤减免”的铭文个人进度是否自动显示为“技免”，且其他内容未丢失。
- `PVP免伤`等不同语义词条是否保持不变。

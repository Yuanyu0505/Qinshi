# 关卡掉落合并展示与锻造资料导出 · 1.1.16

## 展示修改

- 新增`DROPS.groupRelatedDrops()`供页面展示；旧findDrops/groupDrops保持原契约，原始掉落表不改。
- 末尾“碎片”按所属本体分组；八爪铁蜈蚣、机关蛇、破土七郎的碎片/本体共用卡片，机关蝙蝠仅有碎片时仍明确标示碎片。
- 明确的装备简称“醉梦/醉梦罗裳”“升雪/升雪凌霄衣”“星云/星云法衣”合并。没有基于模糊相似度合并“魍魉/双剑魍魉”等可能不同的道具/弟子。
- 查询完整名称、简称或碎片名，均显示同组已记载的来源；每条仍保留原item及chapter/stage，未改变位置、数量或原始记录。
- 普通/英雄/声望来源数组为空时不生成分区；全部无结果时保留页面空状态。
- 合并组内以碎片/本体或原名区分，操作仍使用原道具名称，不把“碎片/本体”当成导航查询词。

## 锻造导出

`tools/export-forging-review.cjs`仅读取项目公开源码与资料。按index数据脚本顺序合并九月/十月/十一月增量，导出有效锻造表、装备/图鉴公共资料、装备族目录、完整核心与共享UI/CSS、各分区交互说明、实际代码行号、静态布局示意及GPT评审指令，生成哈希清单。

不会读取Excel、账号存储、库存、备份或云同步凭证；不会修改橙装锻造功能。布局示意明确标注不是实际截图。

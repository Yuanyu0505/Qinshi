## 参考估价边界

非贡献兽按缺少碎片折算只数乘参考单价，已有碎片可抵减缺口，不额外凑整只。实际购买包装可能使真实支出高于参考估算。缺价只显示已知小计，不视为免费。

每个备选方案单独抵扣同一份神图库存一次；计算不消耗真实库存。神图按原有逐只研发投入规则取整，未采用截图攻略的固定方案。

神图小数单价及非贡献兽按碎片折算费用使用精确十进制向上取整，避免 100×1.1 和 11/40×45000 等整数边界多计 1 元宝。此路径使用现代浏览器的 BigInt 支持。

原流派比较中的展示元宝在旧汇率下被贡献指标完全覆盖；新汇率逐兽取整可能制造额外平局差异。因此仅移除该冗余展示金额比较，保留投入、档位、溢出、碎片、贡献、材料及稳定序的原有先后关系。

已知非阻塞限制：极大自定义金额（如 1e308）超出 Number 安全表示范围时，仍可能显示 Infinity 或失去整数精度；此类数值不属于实际游戏成本，当前未新增金额上限。请使用实际价格范围。

## 建议用户手动验收

1. 单只方案设置神图库存为 0、有库存、超过需求，切换使用库存；检查缺口与总价，不应改变投入方案。
2. 将神图单价改为 64、70、134 和自定义值，持续输入时焦点应保持，费用立即刷新；负数、空神图价格或小数库存应明确提示，不显示旧总价。
3. 蓝紫机关兽留空单价时显示成本不完整；填写 0 是显式免费参考价；橙五默认 45000，已有碎片按剩余缺口折算。
4. 流派各备选方案均独立抵扣一次库存，不应逐个递减；仅神图和机关兽计入费用。
5. 刷新、切换账号、导入导出/同步与清空账号后，检查成本设置随对应账号恢复或清空；旧进度应保留。
6. 存储只读/失败时有未保存提示，重试成功后持久化；失败的个人进度不应混入后续成本设置保存。
7. 资料页来源、六种设计图关卡、幻音宝盒说明和来源搜索；各库存/方案联合标签全角括号。
8. 手机与平板检查设置、折叠价格、费用明细的换行、触控和横向溢出。
9. 并列方案排序：非攻一阶仅白虎/朱雀参与，两者研发度750000，分别碎片13/8；不参与的铜人研发度168800，其他0，新增仅0阶。应仍选白虎20级、朱雀19级，不能因其展示元宝比另一并列方案多1而改选。

# 禁地分区实施计划

日期：2026-08-27  
依据：`docs/superpowers/specs/2026-08-26-forbidden-land-section-design.md`

## 实施目标

在不改动现有个人数据结构、不更新 PWA、不推送 GitHub 的前提下，新增完整的禁地查询与本期需求功能，并适配桌面、手机和平板。实现完成后将功能分支快进合并到本地 `master`。

## 任务一：建立禁地静态资料

新增 `data/forbidden.js`：

- 定义十种固定奖励模板；
- 逐格录入最新清晰奖励图中的贡献、排名、装备碎片、机关兽、神核和刷出橙装；
- 录入 2026-07-30 至 2026-10-14 的全部具体期次；
- 08-20～08-23、09-17～09-20 加入隐虎季布；
- 对应奖励加入影虎、白玉君子佩、黄金牡丹；
- 所有装备碎片在数据层保存规范化本名，由展示层统一追加“碎片”；
- 使用稳定模板 ID、期次 ID 和结构化弟子图鉴属性，避免依赖显示文字反向解析。

预期结果：静态资料与个人状态完全分离，重复期次共享奖励模板。

## 任务二：实现可复用核心逻辑

新增 `js/forbidden.js`，采用浏览器和 Node 均可加载的模块形式：

- 规范化关键词、名称和日期输入；
- 组合排名奖励并去重；
- 合并装备碎片、机关兽、神核等多行资料；
- 根据设备本地日期计算当前、未来、历史状态；
- 生成默认视图的当前期次、下一期和预测结束状态；
- 执行关键词、大／小禁地、只看已勾选的组合筛选；
- 返回命中字段与命中栏目，供界面自动展开和高亮；
- 按“当前 → 未来升序 → 历史降序”排序；
- 规范化本期需求记录，并处理同一期同名道具跨栏目共享状态。

新增 `js/forbidden.test.js`，覆盖核心逻辑的确定性示例，供用户后续自行运行；本次助手不主动执行测试。

## 任务三：接入导航和页面骨架

修改 `index.html`：

- 在装备属性之后、铭文之前加入桌面导航按钮；
- 在“更多”菜单加入移动端入口；
- 增加 `partition-forbidden` 页面结构；
- 页面顶部加入搜索框、大小禁地筛选、只看已勾选和完整预测表开关；
- 增加默认视图、搜索结果和完整预测表容器；
- 按依赖顺序加载 `data/forbidden.js`、`js/forbidden.js`、`js/forbidden-ui.js`；
- 更新设置区备份说明，明确包含禁地需求。

修改 `js/app.js`：

- 增加禁地分区标题；
- 将禁地加入分区映射和移动端次级分区列表；
- 初始化禁地 UI 模块；
- 不改变其他分区的默认状态和交互。

## 任务四：实现页面交互和个人保存

新增 `js/forbidden-ui.js`：

- 使用独立状态对象管理关键词、类型筛选、完整日程、只看已勾选和卡片展开状态；
- 读取与保存 `qinshi_forbidden_needs_v1`；
- 默认展示当前禁地和下一期；
- 搜索时替换默认视图，清空后恢复；
- 当前卡片默认展开，下一期和完整日程默认折叠；
- 搜索命中栏目自动展开并高亮关键词；
- 弟子、道具标签整体可点击，支持键盘与触摸；
- 同一期同名道具在多个栏目同步切换；
- 按“需要的弟子／需要的奖励道具”去重汇总；
- 捕获存储异常并回退为空需求状态，不影响静态资料。

备份无需新增白名单逻辑：`js/settings.js` 已自动收集所有 `qinshi_` 前缀键；只更新说明文字即可。

## 任务五：桌面与移动端样式

修改 `css/style.css`：

- 桌面默认视图使用双列卡片；
- 奖励区域使用自适应两列或三列网格；
- 完整日程和搜索结果使用纵向卡片列表；
- 未勾选标签使用橙色背景、橙色 2px 外框和白字；
- 已勾选标签使用绿色背景、绿色 2px 外框、白色粗体与勾号；
- 命中关键词使用独立高亮，不覆盖需求状态；
- 手机和平板改为单列、标签换行、44px 触控高度；
- 禁地分区不使用横向宽表，保证只需上下滚动。

## 任务六：集成检查与本地合并

- 检查只暂存禁地相关新增和修改文件；
- 保留用户现有 Excel 修改、`.codex-tmp/`、截图和 `答题.jpg`；
- 不修改 `service-worker.js`、`manifest.webmanifest`、PWA 版本和 GitHub 工作流；
- 提交功能分支；
- 快进合并到本地 `master`；
- 向用户列出建议手动验收项目，不宣称未经用户验证的结果已通过。

- 大／小禁地筛选与只看已勾选叠加；
- 当前卡片展开、下一期折叠和搜索命中自动展开；

- 备份导出后包含 `qinshi_forbidden_needs_v1`，旧备份仍可导入；
- 桌面双列与手机、平板单列布局。

# 机关兽布局对齐与最优性核对实施计划

**Goal:** 完成用户七张截图的展示调整，并对图4按用户提供输入独立枚举佐证，不擅自改算法。

**Architecture:** 延用机关兽UI模板及专属CSS、原事件委托与目录跳转；CSS网格统一同类卡片轨道。枚举脚本为独立本地分析产物，不进入网站、不包含账号信息。

**Constraints:** 不改核心/数据/存储；不覆盖已有Excel。遵照AGENTS不主动执行常规测试、lint、验收，用户明确要求的枚举分析除外。用户已授权直接决定布局细节、合并更新推送。

- [x] 单兽当前等级用与控件一致的正文大小、控件行高；紧凑等级列，目标等级紧随其后，窄屏合理换行。
- [x] 库存说明与价格折叠标题左侧和内边距统一。
- [x] 逐兽投入采用一致的摘要三列、已有/新增材料轨道和资源行；同一结果行按CSS subgrid对齐内容，保留全部数值。
- [x] 每个资料区标题栏右侧提供返回目录按钮；移除阶数快捷导航及仅供它使用的锚点。
- [x] 蓝紫研发度两列表格左靠、首列与橙色一致，不占满宽屏。
- [x] 只提取用户备份中的机关兽记录；独立枚举真实允许材料数量和精确等级组合，对比两套目标及图4成本，明确临时草稿不在备份时的边界。
- [ ] 添加/更新供用户执行的UI检查，不主动运行；独立代码审查后更新1.0.93，合并master、推送main。

## Review focus

- 长机关兽名称、多行材料列表与多列卡片仍对齐且不截内容。
- 320px详情标题栏与按钮不重叠；控件的原data属性和恢复身份不变。
- 删除的是1—5阶快捷跳转，非流派切换或五阶资料本身。
- 枚举不得把产品求解器的剪枝候选作为“独立穷举”；费用、库存、效果、精确等级条件完整说明。
- 不把备份中的持久化进度冒充未保存的临时计算输入。

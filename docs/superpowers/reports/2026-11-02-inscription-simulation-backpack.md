# 铭文模拟背包与路线可读性改动记录

## 本次改动
- 新增按游戏账号持久保存的虚拟背包，沿用既有账号存储键，随原有备份和云端设备快照保存；真实个人进度不受影响。
- 支持结果幂等入包、查看/改数量/移除/确认清空、勾选批次和数量用于合成。手增数量另记手动批次，不伪造合成来源。
- roll实际扣除背包投料；retry撤销本次结果并以原投料重新抽取，允许相同结果，显示次数与相同提示；next自动保存并选用产物；repeat不自动复制背包材料；back逐步撤销并检查手动编辑冲突。
- 手动材料只允许洗练词条；合成中档从背包选用。旧完整合成品显式确认后作为手动补充；旧半填写非洗练草稿原样归档并显示，确认后重新备料。
- 最终结果和背包中的模拟产物均可查看实际材料链；只追溯使用过的模拟来源，手动补充从当前品质起算。可用原有90%缩放、总览与依赖高亮。
- 全部理论路线和实际路线共用整改：删除“下一步”内框；放大准备/备料数量文字；晋升材料移至配方附近，避让投料下降线，各配方连线同色且汇合横线独立。窄屏背包改为单列卡片。
- 页面、离线资源、动态分区版本及Pages资源清单更新为1.0.74，加入新模拟模块。

## 手动验收重点
1. 不同账号背包隔离；刷新/切换分区后现场、背包、撤销记录保留；备份和同步后数据一致。
2. 从背包取3枚紫一，合成/入包/连续重新模拟/返回上一步，确认只扣一次、只存一次，原库存恢复。
3. 重复阶段时不足不自动补齐；修改数量后撤销明确提示冲突，不覆盖手动数据；清空背包要确认且真实进度不变。
4. 紫二手填无中档；合成中档可从背包选用；旧完整/半填写材料均有明确保留路径。
5. 最终品与长期背包产物的完整路线包含真实来源；手增批次不继承原链，重抽废弃品不进入最终链。
6. 云遁并行投料、鬼/龙遁速度路径以及其他遁位的连线、字号、节点高亮；手机/平板上的操作、滚动、缩放与一键清包确认。

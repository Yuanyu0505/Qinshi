# 橙装锻造个人进度材料布局设计

## 目标

调整橙装锻造“个人进度”中的剩余材料汇总与弟子装备明细：材料按品质实心高亮，汇总合并数量并以三列展示，不同装备的锻造阶段和所需装备保持横向对齐。

## 汇总展示

- 删除“品质”独立列，不再使用三列表格。
- 每项直接显示为“装备名 ×数量”。
- 紫色材料使用紫色实心背景、2px 紫色边框、白色文字。
- 橙色材料使用橙色实心背景、2px 橙色边框、白色文字。
- 排序为橙色优先于紫色；同一品质按装备名称的中文拼音字母顺序升序排列。
- 使用三列网格，浏览顺序为从左到右、从上到下；窄屏自动降为两列或一列，避免内容溢出。
- 全体弟子汇总与单个弟子汇总使用相同展示规则。

## 弟子装备明细

- 每件装备的剩余阶段表使用相同的固定列布局。
- 第一列固定为阶段列，第二列为所需材料列；各装备的两列起始位置一致。
- 材料标签复用个人进度专用实心品质样式。
- 无材料阶段继续展示“—”，不改变进度数据、阶段切换或本地存储格式。

## 影响范围

- `js/progress.js`：调整汇总结果排序。
- `js/app.js`：生成汇总标签和带固定列结构的阶段明细。
- `css/style.css`：新增三列汇总网格与固定阶段表布局。
- 不改变橙装锻造查询页、跨弟子搜索规则及其他分区。

## 验收重点

- 汇总中橙色材料全部排在紫色材料之前，同色按拼音字母顺序排列。
- 汇总为每行三项，数量并入标签文字，且不再出现品质列。
- 同一弟子不同装备的阶段列、材料列横向对齐。
- 两种品质标签均为实心背景、2px 同色边框、白色文字。

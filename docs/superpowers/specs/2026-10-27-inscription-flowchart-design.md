# 铭文示例式流程图

用户要求按三张示例直接修改并合并、推送、更新；不再就设计和实施文档重复确认。

采用独立内联 SVG 呈现而非继续叠加 HTML 树或引入在线 Mermaid：白色画布、浅蓝圆角材料节点、深蓝文字、灰色有向连线和概率胶囊，与示例一致。复用既有路线结果，不修改合成规则、路线概率、筛选、模拟或存档。

- 按依赖顺序从蓝二起分步绘图。同一中间产物用 M 编号引用，避免把相同准备流程反复套入框内；每张图以制作一枚产物为基准，后续按数量重复。
- 材料和晋升铭文独立成框，箭头明确汇入本次操作。普通步骤的成功及失败分支直接展开，概率显示在对应连线上；最终合流图遵循示例 3，将最终非目标结果合并为一个标明“汇总”的出口，并显示合计概率。
- 概率产物使用成功 S、失败 A/B/C 等稳定编号；复用支线引用同一编号。满足条件时将成功品合成与失败品复用并列汇入同一最终目标，非目标结果单列。
- X 仍仅为原路线中的统一杂词条占位；不能把不明随机属性隐含视为固定 X。所有概率来自既有 outcomes。
- 图形文字按行布局且不依赖运行时测量；手机和平板保留图形结构，画布局部滚动、缩放，避免全页溢出或强制缩小文字。
- 保留策略级折叠，删除旧图内部的嵌套树和失败分支二次折叠。SVG 有标题和文字描述，操作按钮可键盘使用。

按 AGENTS.md 不主动运行测试、构建、lint 或实机验收；用户自行检查不同目标的图形、分支编号、手机版滚动缩放。PWA 更新到 1.0.64，保留现有更新保障机制。

## 上界正确性

1. 对固定的可用库存池 `S`，转换结果新增本体数为 `max(0,n-S)`。单兽先比较该值再比较总本体数 `n`；禁用库存时先比较 `n`。因此更大的 `n` 不可能击败最小可行 `n`。
2. 从一个合法同类型方案获得有限上界，再用数值 bounded/unbounded 背包计算每个 `n` 可达到的最大研发度。原形类型保留逐来源上限，加工类型仍可重复。首个达到目标的 `n` 有真实材料组合证明。
3. 最少本体的达标组合必不可再删一只材料，否则存在更小可行 `n`，故其研究量小于目标加最大单项研究量，仍在原精确研究桶范围内。
4. 后续精确前沿只拒绝 `n>上界`，保留该最小数量下全部研发量、资源和稳定排序比较。没有用数值背包直接选择最终方案。
5. 只有单兽内部调用显式启用此优化。流派和直接调用的完整候选前沿默认不开启，因为流派先比较改造数，不能照搬单兽数量约束。同等解图、BigInt 计数和分页代码未改。

数量比较与原 16 位补零稳定键顺序一致；最终输出仍使用原稳定键格式。没有应用数量向量截短、近似算法、候选硬截断、产品超时或删除合法高阶原形。

## 浏览器与恢复

隔离上下文阻止站点外请求、使用本地测试账号，测试保存/库存读写不涉及真实账户。价格、库存转换、窄屏、账号隔离、备份导入等既有 28 项浏览器回归通过；Worker 性能、恢复、取消及一致性专项最终 11/11 通过。

首次合并运行 38/39：一条旧测试要求压力任务在 1.2 秒后仍 pending，而优化后已经有效完成。已修订为完成则校验有效、未完成则取消；状态判断和取消在同一个浏览器任务中执行，避免完成竞态。UI 取消另用真实 Worker 的可控最终交付测试，不依赖求解必须慢于 150ms。仍验证输入触发终止、主线程响应、结果不落地和库存不变，不是删除取消断言。

Worker 恢复详见 `2026-11-19-worker-retry-1142.md`：临时构造/真实加载失败、连续失败、下一次显式计算恢复、账号/sequence、旧消息/旧错误、不得主线程 fallback 均有覆盖。最终修订取消竞态后再跑安全/PWA 浏览器 7/7 通过，包含旧版 1.1.41 在当前页面发现、应用并切换到 1.1.42，0 失败/跳过。

## 未解决风险与兼容边界

- 上界仅适用于单兽；超大流派组合仍可能耗时/占内存。完整多维精确搜索没有普适固定耗时保证，不能把这七种压力通过泛化为所有输入。
- 未测所有浏览器/低内存手机；Edge Worker 精确峰值内存未测得，不声称 RSS 就是其内存。
- 显式 null 预校验、单兽蓝紫新增策略、清空默认价未来继承按报告要求保留，需另立产品契约才能调整。
- 更改了原内部候选接口的可选参数，默认行为保持完整前沿；不改变账号/库存格式。

发布版本资源统一为 1.1.42；实际提交、合并、推送和线上生效以 Git 与最终交付为准。

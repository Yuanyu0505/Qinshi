# 1.0.84 单行筛选与禁地勾选范围

## 调整

- 铭文「遁位副属性与来源」的所有筛选保持在同一行，保留上一版 44px 控件高度及 16px 输入字号。窄屏在筛选区内横向滑动，不把关键词移到第二行，不扩宽整页。其他资料子页布局不变。
- 禁地装备、机关兽碎片、神核首次勾选均仅作用于本期。机关兽碎片仍默认「上阵/流派」用途，神核仍默认「改造」。弟子勾选继续仅本期。
- 每次打开「设置用途」默认选择「仅本期」。主动选择「本期及之后每一期」后，一次性同步相同系列的勾选与用途到本期及之后已有预测的各期；从未来期设置时不回写较早预测期，更不会回写历史期。取消勾选也遵守此范围。
- 保留原有历史期清理及禁选机制，补充每次渲染、页面重新可见和 pageshow 的历史清理；过期时仍打开的用途窗口不能重新写入历史期。
- 跨日唤醒根据日期变化刷新本期/下期，不依赖于是否存在可清理的勾选，避免空勾选状态下卡片停留在昨日。
- 未新增跨预测版本持续生效的自动勾选规则，后续新增预测不隐式写入勾选。
- PWA 版本及资源引用更新至 1.0.84。

## 根因记录

此前机关兽/神核首次勾选走全系列写入分支，用途编辑器也默认选中全系列，且全系列写入未校验日期，会把勾选重新写入已清理的历史期。现已去除默认跨期写入，并统一限制同步日期范围。

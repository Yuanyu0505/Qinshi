# 其他资料九分区 · 接入与验收说明

## 范围与入口

版本1.0.100。桌面侧栏与手机“更多”增加“其他资料”；独立路由 `#other-reference`，默认九分区索引。现有路由不改名；图鉴、机关兽、铭文、秘境等旧业务源数据和算法未修改。

九区为：诸子卡、五行天枢录、橙弟子来源、灵宝、极限速度、守护神、功能开放等级、器灵、弟子相关。采用现有panel/seg与一级分区加载器；不引入框架或新账号体系。

## 文件职责

- `data/other-reference-data.js`：九区来源索引、图片哈希、28条五行、六节红卡原文、已确认卡册修订。
- `data/other-reference-tables-a.js`：诸子卡、功能等级、器灵、弟子材料，13表176行。
- `data/other-reference-tables-b.js`：五行映射、橙弟子来源、灵宝，17表288行。
- `data/other-reference-tables-c.js`：两版速度、守护神及援助，16表313行。
- `js/other-reference-ui.js`：只读表格、卡片、内存筛选草稿、等级区间、速度浏览排序、原图dialog。未调用账号、localStorage、库存或同步API。
- `css/other-reference.css`：全部规则限制在新分区内；3×3索引，触控控件，局部横滚，卡片展示，模态原图。
- `assets/other-reference/sources`：用户包完整归档，31张图原字节保留；来源说明和确认修订随包保存。
- `index.html`、`js/app.js`、`js/partition-loader.js`：只接入新入口、标题、容器、延迟脚本；其余为统一版本资源身份更新。
- `service-worker.js`、`.github/workflows/pages.yml`：将新代码与数据纳入预缓存和部署；图片不整包预取，仅查看后按需缓存。

## 主要交互

- 默认显示九区目录，每区有返回目录和全部原图索引；目录、分区浏览位置和各子表草稿只在本页内存保留。
- 中文输入只更新结果，不替换搜索框，避免IME和焦点中断；所有资料文案和输入经HTML转义。
- 品质文字标签和关键词筛选、十级区间、表格/卡片切换。联赛资料按区间相交匹配，70～100级不会误成单点70级。
- 橙弟子默认跨来源检索，原图与补图各自保留来源；可选单来源查看名单。
- 速度两版分开，保留原图行序与小数；手机先展示姓名、原图名次、面板/PVP值，其余构成展开；排序不会丢失原图名次。
- 原生dialog负责焦点约束与Escape关闭，关闭返回触发按钮；白名单限定图片路径，支持原尺寸新标签页、缩放按钮、鼠标拖动、双指缩放图片、单指平移、加载失败重试。大图点击才加载。

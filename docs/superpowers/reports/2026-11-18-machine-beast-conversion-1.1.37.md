# 机关兽可转换库存 1.1.37

用户已确认转换规则、实施方案及完成后合并更新推送。

## 实施

- 公共转换模型：同名0–7阶每只折算1只0阶本体，8/9/10阶折算2/4/8只。来源上限按原库存项执行，原形和加工共用同一额度。
- 仅0阶仍允许原形投入；原形保留改造研发度，加工时归0。0–7阶按各兽实际阶数上限重组；原有允许高阶及新增改造开关继续有效。升阶材料按充足且不计成本处理。
- 单只、流派候选、费用和同等组合重建均接入公共模型。只对扣除库存后的新增本体计碎片缺口，蓝紫仅库存不能绕过额度。
- 结果包含来源、转换投入、混合库存/新增组成高阶、0阶余量；计数与原库存记录不混用。不写回计算消耗，不改账号保存格式。
- 流派两方案继续精确累计等级、既有改造/费用/节点/溢出/神图排序。不改变游戏原始数值。
- 界面统一传入转换选项；保留旧API默认路径以兼容旧调用。上一轮库存优先修复未单独发布，随本次整合。

# 1.0.76 交接说明

## 改动

1. 铭文路线词条下方的说明统一下移 8px，节点高度同步调整；字体大小不变。
2. 正整数互补投料逐项比较完整结果池及精确概率；相同者显示两种共三枚、各至少一枚和可互换配比。示例备料总数明确标注；保存路线、收藏标识和实录投料不变。
3. 过期编辑权只在原标签页、原 token 匹配时恢复；BFCache 仅恢复实际释放且未被其他 token 替换的租约。会话账号切换或持久账号已删除时停止写入，返回缓存页面则重载上下文。
4. 账号存储的公用写入边界采用安全续期；铭文存储失败明确区分只读和浏览器存储拒绝，仍保留原有账号/存档并发检查。
5. 手填和背包材料卡共用上方操作栏，清空按钮靠右，手机窄屏可换行；占用计数、清空确认和禁用条件不变。
